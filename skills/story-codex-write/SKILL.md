# 中文小说正文写作

先按需读取 `../story-codex/SKILL.md` 的“共同约束”；同版内容已在当前上下文中则复用。此入口已完成任务选择，不执行公共入口的路由。共享工具位于 `../story-codex/scripts/story.py`，记其绝对路径为 `<tool>`；下文所有书籍命令都显式附加 `--book "<书目录绝对路径>"`。公共技能或所需工具缺失时，说明缺失路径并提示安装完整 Story Codex 套件；不假称已执行。

正文以人物的目标、选择、行动、回应和后果推进，不预设解决冲突的道具或流程。工具状态只用于核对已发生的事实，不从记录字段自动生成新情节。作品已有的专业细节按剧情需要处理，具体见 [场景指导](references/drama.md#把读者期待变成可见的戏) 与 [故事和工作记录](references/drama.md#故事先于工作记录)。

用户仅要求独立片段或声线试稿、没有要求正式续写或采用为书内章节时，读取 [场景指导](references/drama.md)，依据给定材料按 [成稿格式](references/drama.md#成稿格式) 完成正文，核对因果和用户约束；有硬性字数要求时按约定口径实际统计后交付；仅在用户要求时保存文件，不初始化书库、补建章计划或走章节提交。取材于已有作品仍定点读必要约定与原文，不改现行正文。试稿后来被要求纳入作品时，再按正式规划与提交流程处理。

书内章节若只要求候选正文、暂不采用为正式章节，先按现有书籍身份核对必要约定、细纲、前文与限制；有书库时读取 status。按 [场景指导](references/drama.md) 起草并核对篇幅与语义，已有书库时将稿件保存到 `.story/drafts/`，用户指定其他位置则按其指定；尚无书库且未指定位置时在对话交付。已有采用的工具章计划且书库状态允许时，可用只读的 context、lint、prepare 辅助核对；计划尚未采用或缺失时依据可读候选材料起草，不为候选稿初始化书库或写入正式章计划。交付本次候选稿；确有影响继续的未决问题时在正文外简述，不默认附带工作材料。不因本稿执行 commit、export 或其他正式状态写入；后来要求采用时，再按章流程复核、提交与导出。

用户要求章中续写或局部补写时，先确认目标章和已写到的位置，只写授权的后续或局部，不重复前文、补成整章或自动建立下一章。若用户只要续写片段，按 [成稿格式](references/drama.md#成稿格式) 交本次文本；若明确要求并已授权纳入托管章节，先合并成该章完整草稿，再按章流程审查和提交，不能把片段当作完整新章。已提交章节内的补写属于修订，转 [审稿修订](../story-codex-review/SKILL.md) 处理。

正式续写、开书正文或完整短篇按下述章流程进行。先读取本书 `创作约定.md` 中的当前有效约定和最新断点及 status；历史断点只在与本章相关时定点回查。确认本次是正式正文任务、目标章号与数量；仅要求候选稿时按上段处理。即使已有工具计划，仍按章流程定点核对当前章的可读细纲及采用状态；计划缺失、不一致或关键状态不足时，按需读取 [项目状态](../story-codex/references/project-state.md) 补齐并同步本章信息。沿用已有采用依据与授权，不重复确认，不把候选当已采用计划，也不重读全书或重复开书、导入。

普通长篇一章或短篇单元读取 [章流程](references/chapter.md)，完成 context、草稿、字数核对、语义审查、增量提交与导出。明确多章或完整短篇的任务持续至授权范围完成，逐章保存可恢复断点。长篇与短篇写到终章并交付完本时，都按 [全书完本审查](references/chapter.md#全书完本审查) 核对主线、主要阅读承诺与结局后果。

短篇全书完成后，按 [章流程](references/chapter.md) 的完本步骤核对现行总纲的平台分类并合并所有已提交章节，再按 [封面技能](../story-codex-cover/SKILL.md) 交付实际封面图片。完本交付包含现行总纲或等效规划、书名命名的全文文件和封面文件；仅写一个中途章节时不提前标为完本。

百万字以上、多卷、多视角、长距伏笔需要结构化世界记录时，再读取 [超长篇状态](references/long-form.md)，按实体、故事线和故事时间取回信息；旧设定不全部设为全局必读。写本章只记录本章实际变化。历史修订、外改协调、库迁移由 [审稿修订](../story-codex-review/SKILL.md) 处理，普通续写无需加载历史流程。
