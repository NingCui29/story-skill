# 扫榜、拆文验证与选题规划交接

仅在本次任务需要跨流程复用研究时加载。本文件由调研、拆文和规划三个入口共用；普通素材问答、独立点评或已有明确方向的局部设计不另建流程。沿用用户指定目录和已有断点，研究文件不放进技能安装目录。工具为 `../../story-skill/scripts/story.py` 的实际绝对路径，下文记为 `<tool>`；研究命令无需 `--book`，不会建立书库或采用规划。

## 从样本建立假设

先按 [结构化扫榜](rank-scan.md#代表作抽样与模式分析) 得到 `sample.json`。代表作指当前采样范围内值得进一步阅读的作品；标签重复、书名相似和榜位只能说明观察到的样本特征，不能证明写法机制、读者需求或成功概率。

```bash
python "<tool>" research-init --sample "<抽样目录>/sample.json" --output-dir "<新的研究目录>"
python "<tool>" research-check --input "<研究目录>/decision.json"
```

每次生成 `decision.json`、可读的 `analysis-brief.md` 与 `planning-candidate.md`，以及 `evidence-template.json`。在 `decision.json` 中填写本次有意义的候选方向：目标读者、预期阅读回报、作者可用素材与优势、原创差异、风险和下一步验证。每个方向明确选择哪些作品、为什么选择，以及可由正文检验的假设。例如“开篇通过主角主动承担代价建立信任”，比“这类题材容易爆”更适合拆文验证。空白保持待填；程序不根据频次自动编写卖点或评定商业可行性。

方向和假设分别保留稳定的 `topic_id`、`hypothesis_id`，作品沿用抽样的 `book_key`；同名作品不能互换。需要增补或替换样本时另建研究版本，并重新核对证据关联，不把旧结论直接套到新书或新假设上。

## 拆文回填

承接时先读指定的 `decision.json`，确认本次验证的方向、假设和作品。按 [拆文入口](../../story-skill-analyze/SKILL.md) 取得可合法阅读的原文，只分析用户要求且实际取得的范围；已有语料工程沿用来源与报告，不重新初始化。简介或榜单不能替代正文；缺少原文时保留待验证并明确缺项。

填写或改动候选与假设后，先用 `research-render` 另存当前版本及刷新过的证据模板，再拆文回填；初始模板中的假设为空，不能直接当作完成的验证。只保留本次实际分析的证据项，未读作品留在研究包中待验证。

完成分析后，使用生成的证据模板记录：对应方向与假设、作品身份、原文和报告位置、实际已读范围、可定位的短引文、结论及限制。`conclusion` 的合法值为 `supports`（支持）、`contradicts`（反驳）、`mixed`（混合）、`insufficient`（证据不足）；`read_scope.coverage` 用 `partial`（局部）或 `full`（全文声明），范围说明写在 `description`。支持或反驳都须说明文本如何支持判断；所读范围外的兑现、结局和读者反应保持未知。没有真人反馈或平台数据，不能把模型的阅读解释标成市场验证。

```bash
python "<tool>" research-verify --input "<研究目录>/decision.json" --evidence "<填写后的证据.json>" --output-dir "<新的回填目录>"
```

工具校验关联并追加验证记录，保留原研究包。不同作品或不同分析得出相反结果时并列保存，不以“最后一次支持”覆盖反例。假设内容或引用材料改变后须复核相关结论，不通过替换指纹冒充已核验。`quote` 保存最多 800 字符的短原文摘录；支持、反驳或混合结论必须填写，证据不足可留空。本地 `text_ref` 为 UTF-8 文本，程序核对摘录存在并记录原文／报告 SHA-256；之后检查或渲染时发现引用版本变化会拒绝沿用。HTTP(S) 引用不自动下载，`quote_checked=false`，只能作为待核对的来源声明。程序检查来源、关联和字面引用，不判断文学解释是否成立，也不能证明实际读完。

## 交给规划

```bash
python "<tool>" research-render --input "<回填目录>/decision.json" --output-dir "<新的交接目录>"
```

从用户给定路径或当前任务的研究断点读取最新版交接；存在多份分支时核对本次选用版本，不按目录名称、相同题材或修改时间猜测自动合并。交给 [规划入口](../../story-skill-plan/SKILL.md) 时保留三层内容：样本中实际观察到的特征、正文证据支持或反驳的机制、待原创设计与后续验证的候选。

规划应说明取舍与适用条件，把方法改造成原创人物的欲望、选择、代价和事件链；不复用参考书的人物关系、独特桥段或具体表达作为本书事实。局部阅读只能支持对应范围；相反证据或证据不足不阻止用户自主选择方向，但必须随候选一起交接。已有明确采用授权就直接按授权规划，未授权的候选不因工具检查通过而变为已采用。

交付给作者的是可读的方向、理由、局限和下一步；JSON 身份及校验细节留在研究材料中。研究交接不新增发布、试投或正文写作权限。
