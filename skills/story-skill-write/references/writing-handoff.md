# 写前交接与偏好召回

## 写前交接

跨会话恢复或交给另一执行者起草**已绑定的下一正式新章**时，默认用 `writing-brief --book "<绝对书根>" --chapter N --budget-bytes 24000` 集中交接。它已包含 context，不再为同一版本重复调用 context；同会话必要材料已齐且未变时直接复用。修订用原有 context／历史分支；片段、未采用候选和未建库作品按现有材料交接，不为生成简报采用候选、初始化书库或绑定规划。

简报保留本章工具计划、完整已绑定细纲、必要状态、上章承接，以及来源指纹。已有本次要求／本书文风文件时用 `--request-file`／`--style-file` 传书根内相对路径；没有文件就直接交接当前请求和有效约定，不为工具造表。状态包不替代必要前文原文；上章末尾不足以支持本章关系或世界机制时定点补读。

主会话在交接时简要说明本次范围与停笔点、适用偏好和相关文风裁决、需要保留的关键选择与阅读回报，以及真正未决的问题。复用现有请求、细纲与卡片的位置，不复制全段对话、全书设定或重写一份固定九槽表。接收者按原文完成语义核对；机器 `semantic_review=pending` 不能改称已审查、已授权或可正式提交。

必要来源、偏好和限定条件超出预算时，工具返回完整所需字节数，按该值重取，不截断细纲或删掉偏好的例外。源稿、状态或有效要求发生变化时重新核对受影响材料；简报仅绑定生成时的版本，正式提交仍走现有审查、revision、细纲与导出门禁。

生成简报前须按现行章幅核对下一新章；旧默认范围或失效的篇幅依据先同步计划并复核细纲绑定。完整章任务交接或新派发时也重核该约定；关联章号的片段和已提交旧章仍按其实际范围处理，不据此扩写。片段在交接和回流时都保留局部范围，不强制补章名；旧完整章简报损坏或范围未核清时保留记录并重新生成，不推定为片段。

## 偏好召回

复用本书现有 `kind=preference` 卡。简报自动选择有效的本书全局／当前卷、阶段、线及实体范围内、无标签或与本章计划标签相交的卡；本章 `requires` 或已有必要状态指定的有效偏好也保留。标签仅作显式检索，不从小说词句推断作者偏好。`global` 指**这本书内全局**，不自动读取别书、用户主目录或宿主记忆。

`preference_recall.cards` 给出额外召回的完整卡；`required_card_ids` 指向已在 `context.required_cards` 中的偏好，避免重复文本；`card_sha256` 为所有命中卡的规范 JSON 指纹。未命中数量只说明未选入，不证明其中没有遗漏的适用要求。已知本章依赖的偏好若标签或范围未匹配，按已有约定核对，并在已有授权内修正 requires／卡范围后重取，不能静默跳过硬要求。

召回不等于适用性或来源已认证。核对卡的 `source` 和完整限定：当前明确要求、本书有效约定、适用作者偏好、参考方法与默认的优先关系仍以 [文风统一裁决](drama.md#文风统一裁决) 为准；按相关维度处理冲突，不把所有命中项累加成绝对禁令。本次例外不自动废除长期偏好，事实、知情和权限不因文风偏好改变。

只有作者明确表示长期适用或接受长期做法时，才在获准的本书范围内用现有 notes 更新偏好卡，`source` 保留原话、来源及适用范围，例外与否定词留在同一条完整文本中。一次性要求只用于本次；含糊的长期候选留在现有约定／断点的待定部分，不登记为有效卡。不从成稿、重复修改、模型建议或检测告警自学习惯，也不把小说事实记成偏好。作者明确撤回时按 notes 将原卡标为 `resolved`；语义改变按原话更新并保留现有事件记录，不能在查询时偷偷改写。

没有偏好卡照常创作；来源、范围或冲突不明时只处理影响本次的具体问题。不得为了“完成偏好召回”收集作者画像或另建记忆状态库。
