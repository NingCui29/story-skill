# 关键情节点与新增事实

按采用计划起草、交接或发现漏纲、新增设定时取相关节。复用四项审查，不增逐章表、事实账本或提交字段；局部校对不扩成情节重审。

## 关键情节点覆盖

从本次有效要求、章细纲和工具计划 `goal`、`beats.change`、`stop` 中，取影响关键选择、承诺、结果及停笔点的内容。未采用候选、远期待定和方法示例不强制落地；已授权调整沿 [规划联动](../../story-skill/references/project-state.md#已采用规划的联动)，不机械恢复旧安排。写前交接只提示易漏的关键处，能定位现有材料就不再抄表。

写后读正文，辨别关键处：

- **未出现**：相关行动、回应或结果缺失，也无符合现行安排的延后依据。
- **仅概括**：提到结论，却跳过本章应让读者经历的选择、交锋或回应；同名词出现不等于充分展开。
- **实际呈现**：读者能经历重要尝试、回应、体验或余波，结果有支撑；场面可短、平静，不以对白量或字数判定。

先判断省略的作用，不把节点等量扩写。过场可概述，有效安静、留白和群像分工可保留；[阶段回报](drama.md#高潮与阶段兑现) 可共享或主动让渡。必写项遗漏或关键因果缺口按现有审查规则处理，单纯详略偏弱说明读感影响，不一律阻断。覆盖齐全不证明好看。

## 新增事实分级

按对承诺、依赖及授权的影响分级：

1. **非承诺细节。** 与已有事实相容，仅服务眼前动作、环境或感受，如挪开杯子；可直接写，不逐件登记。若后来成为证据、资源或承诺，再按用途复核，已有位置和归属仍须连续。
2. **可复用新事实。** 授权内新建且后文确需召回的关系、地点、归属、线索、规则用法或承诺，先核对事实与知情。托管章随现有 `delta.changes`／`world_changes` 记录实际发生的内容及最终稿原句；已有卡按 ID 更新，下章必读才加 `requires`。未来打算仍留计划；非托管候选不为登记建库，不为所有细节补卡。
3. **超授权结构改变。** 改变主线、核心规则、采用结果或正式事实而超出本轮权限时，先协调具体设计，可继续不依赖它的已授权部分。用户已授权探索、规则调整或正式修订的直接按范围推进，不重复请示；候选与采用版分开，正式改变仍走既有联动、绑定及修订。补卡或加引文不能让临时解法获得因果依据。

作者真相、未来规划、人物相信／猜测与正文证实事实分开；线索登记不升级为真相，人物不无渠道获知，不因交接泄露本章不应揭示的内容。

## 边界示例

以下虚构示例不作本书事实。

- **概括交锋**：细纲要写拒绝提前清场及买方撤回加价；“他据理力争，终于保住演出”跳过取舍。可展开拒绝、撤价与仍坚持演出的过程，出门则可概述。
- **有效安静**：妹妹调整走位，哥哥试过后请替补旁听，她当场约人。有限合作已呈现，无须添事故，也不能据此记为“彻底和解”。
- **临场能力**：只能隔墙听声的人突然读心破案，精确引文和新卡只证明稿里写过。须处理规则、支撑及授权，不能登记后就称合理。
- **授权探索**：已获“保留已发生事实，试写不和解路线”的授权，可改原细纲中的和解，不再次请示；候选不覆盖正式稿，正式采用按已有权限处理。
- **候选与群像**：旧候选为主角独救，现行安排为队友救人、主角守出口；按后者展开并共享荣誉不算漏纲或回报失败。

结论并入 [四项审查及问题清单](content-review.md#结论反证与未决问题)，保留原文定位、支持／反证及未决项，改后回读受影响内容与依赖。脚本不判断文学展开是否充分。
