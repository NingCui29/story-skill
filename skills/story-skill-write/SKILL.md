# 中文小说正文写作

先读 `../story-skill/SKILL.md` 的“共同约束”；此入口已经完成任务选择，不再执行公共入口路由。共享工具为 `../story-skill/scripts/story.py`，记绝对路径为 `<tool>`，书籍命令总是显式传 `--book "<书目录绝对路径>"`。缺公共技能或所需工具时说明实际缺失，不假称已执行。

以下按范围、阶段和症状读取。带锚点只读适用节，同版已读且未变化的规则、裁决和作品材料复用；必要原文不能用摘要代替，也不为省读取跳过适用要求。

## 范围与基线

先确认书根、本次对象、正式／候选身份、授权终点和停笔范围。已有有效约定、规划及正式前文直接复用，不重复开书、导入或索取已有授权。已提交章的补写和改写转 [审稿修订](../story-skill-review/SKILL.md)；独立片段、未采用候选、章中补写只读 [候选与片段](references/chapter.md#候选与片段) 中的对应情形，不自动采用、绑定或写入托管导出。

正式新书先核对定位、关键人物、世界规则及规划基线；缺必要前置时按 [开书与规划](../story-skill-plan/SKILL.md) 补齐。长篇先有开端到结局的全书走向、分卷粗纲和本卷安排，再展开近期细纲；短篇先有结局与关键选择，可用一份等效规划，不强建固定设定文件。目标已包含正文时，补齐必要规划后直接回到写作，持续到原授权终点。

正式续写先读 `创作约定.md` 的当前有效约定、最新任务断点及 `status`，确认章号和数量；历史断点只在相关时回查。核对当前可读细纲的采用身份及工具计划；缺失、不一致或状态不足才补读 [项目状态](../story-skill/references/project-state.md)，不把候选当已采用计划。按 [规划质量验收](../story-skill-plan/references/outline.md#规划质量验收) 定点核对本章所依赖的目标、因果、阅读回报和后续条件；缺口先在授权范围内处理，候选任务仍保持候选身份。

## 起草最小路径

1. **统一本次写法。** 按 [文风统一裁决](references/drama.md#文风统一裁决) 核对表达选择与来源；按 [题材写法卡](references/drama.md#题材写法卡) 的选用说明只取适用主卡及必要辅卡，不整库加载或为套卡改变已采用设定。没有匹配卡时沿用本书目标和通用指导。
2. **交接必要材料。** 跨会话接续或向写手分派**已绑定的下一正式新章**时，默认按 [写前交接](references/writing-handoff.md#写前交接) 用 `writing-brief` 只读组装，并按 [偏好召回](references/writing-handoff.md#偏好召回) 筛选来源与适用范围；表达裁决和必要原文仍由执行者核对。同会话简单接续且材料完整、版本未变时复用，不重复组装。候选、片段及已有章修订不为简报补建绑定；书内适用偏好仍按当前要求核对。
3. **建立本次行动依据。** 定点核对 [主要人物](references/drama.md#主要人物定义与核对)、[关键结果支撑](references/drama.md#关键结果的剧情支撑) 及 [视角与转接](references/drama.md#叙述视角与场景转接)，区分人物定义、当时知情及状态。正文以目标、选择、行动、回应和后果推进，工具状态只记录已发生事实，不从字段生成新情节。
4. **让关键处实际发生。** 按 [场景展开与情绪层次](references/drama.md#场景展开与情绪层次) 及 [人物在场与去 AI 味复核](references/drama.md#人物在场与去-ai-味复核) 安排详略，复用有效声线和关系，让读者经历现场而非只看节点完成。依据规划写完整单元时按 [关键情节点覆盖](references/chapter-continuity.md#关键情节点覆盖) 核对实际过程；临场引入可复用人物、物件、机制或重要变化时按 [新增事实分级](references/chapter-continuity.md#新增事实分级) 处理，不把局部细节全部登记，也不把探索性发现压回旧方案。

## 按阶段和症状补读

只取符合本次触发条件的行；普通续写不重提主题、不全读诊断或历史流程。

| 阶段或实际需要 | 读取与执行 |
|---|---|
| 首章；连载承接或章末；明确多章；高潮 | 分别取 [开篇切入](references/drama.md#开篇切入与代入)、[钩子的承诺与兑现](references/drama.md#钩子的承诺与兑现)、[主线跨章推进](references/drama.md#主线怎样跨章前进)、[高潮与阶段兑现](references/drama.md#高潮与阶段兑现)。终章以兑现和收束为准；群像、合作、主动让渡按本书承诺判断。 |
| 关键交流或声线试写 | [人物对话方式](references/drama.md#人物对话方式)，结合双方当时处境、回应与原有声线。 |
| 关键结果依赖能力、资源、制度、时空或人物知情；引入重要世界机制 | [世界设定与自洽](references/drama.md#世界设定与自洽)，连读实际尝试、回应和后果；不能拿未来规划补眼下依据。涉及目击、证据载体、设备时间或路线，再取 [证据与空间连续性](references/suspense-evidence.md)。 |
| 专门要求表达、平淡、去 AI 味诊断，或自审发现疑点 | [表达与场景诊断](references/content-review.md#表达与场景诊断)，再按实际缺口取 [平淡时修哪里](references/drama.md#平淡时修哪里) 等段；普通起草不预读全部诊断。 |
| 新作开篇、声线试写或实质调整全篇叙述 | [作品的观看方式](references/drama.md#作品的观看方式)；寻找故事方向时再取 [生活观察与核心追问](references/drama.md#生活观察与核心追问)。关键关系、自我判断或主题表达取 [作品的复杂性](references/drama.md#作品的复杂性)。 |
| 写作中发现原方案忽略了重要人物需要、关系或重心 | [在重写中发现故事](references/drama.md#在重写中发现故事)，区分文本发现与修改假设，在授权内验证；涉及已采用规划或正式正文仍走联动与修订。 |
| 明确要求想象力、新意或试写创新构思 | [创新构思与持续展开](references/drama.md#创新构思与持续展开)，将差异落实为体验、尝试、回应和后续条件；普通续写不为新意重做设定。 |
| 明确追求经典品质、文学深度或整部作品表达 | [整体品质与重读价值](references/drama.md#整体品质与重读价值)，按本作选择有关维度，不变成逐章公式。 |
| 阶段关键选择落地、连续章重复或篇幅失衡；设计多线与揭示顺序 | 分别取 [全书节奏与篇幅重心](references/drama.md#全书节奏与篇幅重心)、[多线与信息编排](references/drama.md#多线与信息编排)，只回看相关阶段，不自动重排全书。 |
| 实际目标为番茄、起点或七猫 | [三平台创作要求](references/drama.md#三平台创作要求)。番茄／七猫移动端商业网文或明确商业连载目标再取 [商业连载要求](references/drama.md#番茄与七猫商业连载)；方法按需，不逐章套齐六步。 |
| 短篇开书、整体重构或明确平台适配、商业情绪节奏与付费断点 | [短篇平台化设计](../story-skill-plan/references/short-platform.md)，仅取本次有关段；非商业、安静、非反转作品沿用其目标，不自动增加付费结构。 |
| 本次涉及七猫 AI 使用、征文限制或声明 | [七猫 AI 辅助创作与声明](../story-skill-review/references/qimao-content-review.md#ai-辅助创作与声明)，核对实际允许范围和真实分工，不以完成稿保证平台结果。 |
| 明确比较开篇、试写方案或阶段吸引力 | [试写与阅读反馈](../story-skill-research/references/reader-validation.md) 的适用部分；普通续写不附加多稿或真人试读门槛。 |
| 百万字以上、多卷、多视角或长距伏笔确需结构化记录 | [超长篇状态](references/long-form.md)，按实体、故事线和故事时间取回，只记录本章实际变化，不全载旧设定。 |

## 审查、提交与交付

交付前按 [正文内容审查](references/content-review.md) 的核心四项，连读本次完整范围及必要衔接，核对因果、连续性、约束和读感；专项方法仍按症状补读。完整章按 [命名吸引力](../story-skill-research/references/reader-validation.md#小说命名的吸引力) 核对章名及采用边界，依 [用词与语意](references/drama.md#用词与语意)、[成稿格式](references/drama.md#成稿格式)、[小说标点校对](references/punctuation.md) 检查实际成稿，并按 [章幅与计数](references/chapter.md#章幅与计数) 实测。片段只报本次范围；重复解释、同质对白等问题按处境修正，不机械换词或加动作；保留有功能的安静、留白、直写及专业细节。

正式新章或短篇单元按 [正式章节流程](references/chapter.md#正式章节流程) 完成 context、草稿、字数核对、实际语义审查、增量提交及导出回读。多章按 [多章连载](references/chapter.md#多章连载) 循环至授权范围完成，逐章保留可恢复断点；候选、历史修订、完本等流程仅在适用时加载。

长篇每个完整章须自动随章交付 [作者有话说](references/drama.md#作者有话说)，包括完整章候选和补完当前章；是否配图先由用户确认，已有明确且适用的选择直接遵循。未确认或选择不需要时先交付正文与附言文字，不列缺图。保存时按 [随章保存与核验](references/chapter.md#作者有话说的保存与核验) 执行。确认需要的配图默认每章一张、9:16，并核对视觉重点与缩略图；附言 Markdown 只保留文字，图片独立保存。短篇默认不写、不保存、不展示附言及其配图，用户明确要求时按指定范围提供。

长短篇终章都按 [全书完本审查](references/chapter.md#全书完本审查) 核对主线、主要阅读承诺、结局后果与已采用创作关注。短篇完本按 [短篇完本与修订交付](references/chapter.md#短篇完本与修订交付) 核对平台分类、合并正式全文并交付规划、以书名命名的全文文件及实际 [封面](../story-skill-cover/SKILL.md)；中途章不提前标完本。

目标已包含整书优化或终稿打磨时，完稿后继续按 [整书改稿与终稿打磨](references/content-review.md#整书改稿与终稿打磨) 及 [审稿修订](../story-skill-review/SKILL.md) 完成实际全文阅读、修订和交付，不在初稿收束时提前结束。只要求写完则按原目标交付，不自动增加多轮改稿。
