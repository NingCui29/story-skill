# 起点作品分类（作家助手实采）

采集日期：2026-10-11（北京时间）。在登录的[阅文作家助手网页版“创建作品”页面](https://write.qq.com/portal/dashboard/create-novel)依次选择发布站点“起点-男生”“起点-女生”，展开“作品类型”的两个下拉菜单，逐个大类收集全部子类。下表保留后台名称、菜单顺序和父子关系：男频 15 个大类、79 个子类；女频 11 个大类、73 个子类。仅查看和切换未提交的表单选项，未创建或提交作品。

## 使用范围

- 本表用于涉及起点的作品定位、分类拟选与资料核对。发布站点先区分“起点-男生”或“起点-女生”，再从该站点选择作品类型的大类与其子类；本文将这两个下拉栏分别称为一级分类（大类）和二级分类（子类）。
- 这是本次账号在创建作品菜单中的可见选项快照，不保证其他账号、其他入口或未来页面完全相同。已有作品以其实际设置为准，投稿前按当前后台复核；有来源的新选项可补录，不仅因本表未列就判定不支持。
- 本地选择与后台核验按[共享分类状态规则](../../story-skill/references/project-state.md#大纲中的作品类型与平台分类)分别记录：尚在比较的标建议／拟选，有内容依据且已采用的本地方案可标已选定，分类适配本身未决的保留原因；后台是否核对菜单、是否核实本书实际设置单列。菜单可见不等于本书已保存；只有本书实际后台设置经核对才标“后台已确认”。保留已有确认值，建议变化另列。
- 保留原字形和父子关系，不跨频道借词。同名词不代表相同入口或用途，例如男频轻小说的“衍生同人”和女频轻小说的“同人衍生”分别记录。
- “短篇”大类、“短故事”等子类不能代替作品的长短篇定位，也不据此推定另有独立短故事入口。作品篇幅类型仍按本书约定单独记录。
- 本次只采集作品分类，没有核对题材标签、分类 ID、最终创建校验、已有作品修改或签约后的修改限制。不套用番茄、七猫的标签栏目，也不把平台分类写入工具章计划的 `plan.tags`。

## 写入总纲

在现有全书总纲或短篇等效规划中保留独立的起点定位块，只填写本书有依据的拟选或实际选择、内容依据和核对状态，不复制整份词表。整份总纲按[分类与作品分析覆盖规则](../../story-skill/references/project-state.md#大纲中的作品类型与平台分类)默认包含番茄、七猫、起点；起点分段也须体现读者期待、具体看点与剧情支撑、适配结论及待调整／待验证项。分析覆盖不决定实际投稿平台，本轮明确限定单平台时按该范围处理。

```markdown
## 作品定位与平台分类（起点）

- 篇幅类型：长篇／短篇；依据：本书整体定位。
- 目标平台：起点；作品阶段：按本平台实际情况填写，已确定拟投且尚未创建的写拟投，仅作分析比较且尚未创建的写备选（未创建），未查看现状写待核对。
- 作者名称／笔名：本平台本次指定或拟用值及状态；未提供写待确认；依据与日期：……
- 平台入口：作家助手网页版“创建作品”，或本书实际使用的其他入口及核对状态。
- 本地分类决策：建议／已选定／内容待定；明确本轮方案及依据。
- 后台核验：当前菜单与本书实际设置分别说明是否核对。
- 发布站点：起点-男生／起点-女生（分别注明本地选择及后台核验状态）。
- 分类频道：男频／女频，与发布站点对应。
- 平台栏目：作品类型。
- 一级分类（大类）：……（注明核对状态）。
- 二级分类（子类）：……（属于当前发布站点的所选大类，注明核对状态）。
- 选择依据：对应本书人物、事件、关系或世界设定；尚未写成正文的注明规划中。
- 作品分析：拟面向的读者与阅读期待、主要看点及对应的主线、关系或阶段安排。
- 适配结论与待调整：本入口及分类的选择理由、现有支撑、具体待调整位置与待验证判断。
- 来源与核对日期：本表快照／本书实际后台及页面；YYYY-MM-DD。
- 待核对：未确定分类、其他入口适用性或修改限制；无则写无。
```

## 与公开分发分类表的差异

[阅文开放平台《文学分类 ID 和名称》](https://open.yuewen.com/docsv2/wxhz/1029.html)仅作交叉参考，覆盖阅文体系的分发分类，不替代作家助手当前创建菜单：

- 公开表在男频“都市”和女频“现代言情”下均列“官场沉浮”；本次后台两个菜单均未显示该项，故不补入。
- 公开表在女频“悬疑侦探”下列“规则怪谈”；本次后台原名为“奇妙世界”，故保留“奇妙世界”。男频“悬疑灵异”下的“规则怪谈”仍按实采收录。

后续更新时分别核对发布站点、作品类型栏和来源日期，不用前台书库或公开分发接口覆盖已采集的后台词表。
