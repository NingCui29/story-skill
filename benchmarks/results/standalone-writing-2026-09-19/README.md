# 2026-09-19 独立试写与局部设计分流

本轮修正一个实际出现的范围问题：用户只要一段小说试稿，旧写作入口仍把任务带进书库、章计划和正式提交。现在独立片段直接创作、核对并交付；正式续写、完整短篇和已采用规划的修改继续使用原有流程。改动未发布，也未更新本机安装。

## 修改范围

- 写作入口增加独立片段与声线试稿的直接出口，保留篇幅、因果、用户约束检查。涉及已有作品仍读必要原文，试稿不替换现行正文；要求采用时再进入正式流程。
- 公共规则将分卷保存和 `context` 明确限定为托管正文，独立试写不查书库状态。
- 规划入口允许独立局部设计直接交付，没有总纲时不补建整书。更新已采用规划仍同步原有工具计划。
- 章流程只补充“正式托管”的作用域说明，其提交步骤和完整短篇验收内容未改。

同时复查了上一轮“误判偏密、对白工整”的反馈。现有创作与审稿规则已有覆盖，本轮没有据两份样稿增加误判次数、对白形式等通用禁令，也没有改变共同场景指导。

## 同题实际试用

两个新代理分别读取修改前、后的冻结技能，在独立空目录完成同一份[请求](request.md)：写 450—600 个中文字的社区泳池门口师生相遇片段，“先试试这个声音”“只交这一段正文”。任务没有额外提醒不要建库，也没有提供预期路线。评估要求另存交付与过程记录，以便核验；这两份留档文件不等于产品要求用户保存文件。

| 观察项 | 修改前 | 修改后 |
|---|---|---|
| 正文汉字数 | [481 字](baseline/output.md) | [459 字](candidate/output.md) |
| 代理记录的书籍命令调用 | 11 次 | 0 次 |
| 帮助、模板查询 | 另有 2 次 | 无 |
| 实际书库与规划 | 建立《浅水区》书库、约定、细纲和章计划 | 无 |
| 正式章节 | 已提交第 1 单元，导出到具名卷目录 | 无；仅独立试稿 |
| 是否要求用户澄清 | 否 | 否 |
| 实际读取技能/参考文件 | 5 份 | 3 份 |

调用次数来自代理的原始[修改前过程记录](baseline/process.json)和[修改后过程记录](candidate/process.json)，不是独立采集的完整命令追踪。11 次中含欠字重检、引文修正和一次路径拼写错误，不能把这些偶发重试当成旧规则必然造成的固定成本；但初始化书库和正式提交是本次明确观察到的额外工作。

主代理独立检查了[实际文件与哈希](observed-files.json)：修改前确有数据库、可读细纲和分卷正文；修改后目录仅有评估用的 `output.md`、`process.json`。[只读状态回查](baseline-status-verification.json)确认旧流程已提交第 1 单元、revision 为 2。工具的 `full_book_verified` 表示该小书库文件核验，并不证明这个试写片段构成完整小说。

原始输出、过程记录、修改前后规则文本均已归档。基线额外生成的文本保存在 `baseline-created-text/`；数据库只登记哈希与回查结果，不作为新书发布。对照的目的仅为核对任务分流，没有进行文学优劣评阅或账户成本测量。

## 正式流程边界复核

独立审查代理只读复核四份技能，未发现下列五类任务被错误合并：

| 任务 | 保留的处理方式 |
|---|---|
| 独立片段、声线试稿 | 核对所需原文和本次要求后直接交付，不改现行正文 |
| 已有书正式续写 | 状态、采用计划、上下文、审查、提交与导出 |
| 完整短篇 | 正式章流程及总长度、结局兑现、完整交付检查 |
| 局部修改已采用细纲 | 同步原有工具章计划，不走独立设计出口 |
| 后来要求采用试稿 | 回到正式规划与提交流程，不自动变为已采用章节 |

这部分是静态一致性复核，未逐一执行五类任务；本轮实际前后试用仅覆盖独立片段。局部设计分流没有另作生成试用。

## 核验与限制

[完整核验记录](validation.json)保存规则快照、产物哈希、文件与链接检查；[技能格式验证](skill-validation.json)覆盖修改的三个入口。运行程序未改，沿用此前同一程序哈希的 551 项通过、7 项跳过记录，未重新运行全量回归，也不将旧结果称作本轮新增通过。

主代理复算和只读回查使用 Python 3.12.14。基线代理记录的命令使用环境中的 `python3`，任务后复核该命令为 3.9.6，低于项目支持的 3.10+；因此这次结果只证明观察到的任务路线与文件，不作为 Python 版本兼容验收或运行时性能对照。

这是两个代理、每版本一次交付的合成场景；没有重复采样、真实读者、长篇续写或文学增益结论。没有改真实作品、已安装技能、旧试稿、旧发布包或全局配置。
