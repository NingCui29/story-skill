日期：2026-10-19。范围：Story Skill 0.6.19 开发源码；用户指定番茄、七猫、起点，只自动保存草稿。

后续范围：用户要求接上工作台入口，并将本轮真实后台验收限定为番茄，使用 Google Chrome。以下初轮命令结果保留；本轮界面、后台和浏览器新建能力的增量验收单列。

共享执行核心和可配置浏览器适配器已实现，命令为 `publish-draft-run`、`publish-draft-status`。默认仅本地预览，显式执行才打开浏览器；复用已审查正式稿的冻结清单，按账号和作品逐章保存标题、正文并重新打开回读。已有不同内容或非草稿同章阻断，未决写入先对账，持久记录避免换清单后直接重复创建。起点也加入离线材料与 ZIP 核验。

原离线清单及作者副本比较继续保留原证据含义，远端观察另记，不修改创作 revision。浏览器依赖为可选项；独立会话不保存登录状态，不使用私有发布接口。

工作台新增“平台草稿”工具栏入口和四个认证 HTTP 操作。界面可遍历全部冻结清单、预览目标及章序、异步保存和只读对账、查看阶段及本次全文核对进度、关闭重开续接任务；保留编辑缓冲。预览签名绑定书、清单、页面配置与操作模式，正式稿变化或预览失效会阻止新写入。分析项目不开放此入口。

浏览器配置新增精确登录 origin 范围、可选 Google Chrome、仅创建阶段使用的新建按钮与弹窗流程。点击即创建空云稿的行为受既有持久发送意图保护；弹窗丢失不重试。保存完成须重新打开并完整比对，不能只凭“已保存”徽标。

## 初轮待验收记录（后续结果见下文）

番茄已有由本轮真实页面采集的私有配置，纯构造验证通过，未随公开包分发。新增稳定账号守护页、完整 URL 身份模板、草稿／非草稿目录和动态分卷、完整表格／分页证据、草稿 ID 与目录状态再次确认。实际多段采样及首尾空行保存后重开观察见[段落证据](fanqie-richtext-observations.json)；原第11章功能草稿已恢复54字说明。严格段落读写仅移除已观察的一个编辑器哨兵，不裁剪正文。后台现场只有一卷十章且无分页，多卷和真实多页仍待另行实测。

独立复核另发现未命名草稿可能已有章号。最终补丁在查找时遇到未编号旧稿即停止，不跳过后新建；创建阶段只按明确远端 ID 识别本次空稿，其他未命名稿仍阻断。新增联动故障注入证明点击已产生空云稿后遇此情况会持久记录 unknown，后续列表没有稿也不直接重发。新增浏览器及正文专项最终77项通过，未写真实平台。

真实工作台已使用隔离功能书、真实冻结清单、生产默认目标锁和日志启动任务，正文是83字符说明，非小说内容。首次在身份核对前因登录导航 DOM 超时退出，仅 blocked，没有 sending 或远端 ID。修复后真实只读诊断完整等待60秒期限，最终 login_required，未创建或编辑。工作台人工登录期设为十分钟；第二次独立会话任务仍未取得登录。作者随后指定仅用既有已登录 Chrome，已安全停止服务及独立临时浏览器，最终两条 blocked、零 sending、无远端 ID，原日志未改。后续转为当前助手浏览器工具驱动的 `host_assisted_cua`，保留生产核心与发送记录；该模式依赖已连接的助手执行工作器，不能声称是无助手的无人值守执行。当前尚未取得完整账号确认、创建、保存和全文回读结果，不能将直控第11章、配置验证或测试框架计作完整自动链路通过。

完整自动链路仍需已有同章冲突、会话失效、中断恢复及重复执行的真实验收。七猫、起点本轮按用户要求暂缓，公开登录页不计入草稿保存通过。
