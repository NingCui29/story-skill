# 非执行功能与静态 HTML 惰性边界复核

基线为上一轮 `development-20261024-five-fixes-loop` 的冻结源码。本轮保留全部已有未提交改动；没有操作真实书稿、账号、网站或安装目录。

## 已确认并修复

本轮发现 **1 类惰性容器解析遗漏，包含两条路径**：

1. `<template>` 里的 `</ul>`、`</body>` 等结束标签会被简单标签栈匹配到模板外的祖先。模板因此提前退出，后续模板书卡、排序、页码或标题文字进入实际证据。隔离真实 Chromium 与基线解析的对照确认：浏览器只有书 100，基线却返回 900、100。现在结束标签只在最近的 template 作用域内匹配；嵌套模板正常闭合，真实外部内容继续解析。hidden 元素不被错误升级为独立解析作用域。
2. `<template/>`、`<div hidden/>`、`<script/>` 等 HTML 非 void 惰性容器被误当作已经闭合，浏览器实际会忽略该斜杠。现在对这类输入拒绝整页并明确提示重新导出带完整结束标签的 HTML，避免生成不可靠快照。此检查仅针对惰性容器，未扩为一般自闭合标签限制；合法 SVG/MathML 自闭合、HTML void 元素保留。HTML integration point 和会退出 foreign content 的 HTML 标签不能绕过检查。

这两条路径均存在于本轮开始基线；它们是上轮排除 template/hidden 后仍未覆盖的解析边界，不是本轮补丁新产生的问题。未改变抽样身份、历史研究文件、正文或技能规则。

独立复核又发现并修复了本轮第一版补丁引入的 **namespace 判断回归**：仅按祖先标签猜测 SVG/MathML，会在 foreign breakout 后继续把后面的 HTML 当成 foreign，从而放行惰性自闭合；也会把另一 namespace 中同名的 `mi`、`annotation-xml`、`foreignObject` 错当作 HTML integration point。第一批 12 个隐藏误录和 3 个正常误拒均被真实 Chromium 对照证实。最终实现显式记录 namespace、在 breakout 时弹出 foreign 栈、按 namespace 判断 integration；进一步复核又补齐 `</p>` / `</br>` 的同一退出分支，修复另外 4 个邻域遗漏。这里仅补充惰性判断所需的上下文，不声明实现完整 HTML5 建树。
