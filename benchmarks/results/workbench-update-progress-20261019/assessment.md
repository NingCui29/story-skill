# 工作台更新进度验收

Mac 开发候选 0.1.9 / build 10、Windows 开发候选 0.1.3；内嵌运行时沿用 0.6.19。此记录不创建正式 Release，不改变最新正式客户端附件。

## 实现与边界

- 原生检查状态与下载进度窗口：真实字节、百分比、速度、预计剩余时间，取消、清理与失败重试。
- 官方 HTTPS Release 附件及 GitHub CDN 白名单、重定向次数、大小及超时限制；使用官方 digest 或同名 `.sha256`。
- 下载完成后读盘校验；Mac 打开包前再验 SHA256，Windows 安装交接前再验文件身份。取消、中断和校验失败不会交给安装器。
- Mac 打开已校验 DMG／ZIP，Windows 打开可见安装向导，便携 ZIP 仅打开目录；阶段明确标为等待手动安装和重启，不冒认安装已完成。
- 保留编辑页与作品服务。正常退出时先等待下载取消清理；Windows 启动安装器前还会核对全部标签的文字。
