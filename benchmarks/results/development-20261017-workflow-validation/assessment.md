# 2026-10-17：按任务读取、改稿结论与开发验证

本轮针对当前 v0.6.17 未发布工作区实施，保留既有未提交开发内容。这里记录源码、程序与小样本执行证据，不作为发布、安装同步或文学质量认证。

## 实际改动

- 写作入口将独立片段、候选与章中补写移至既有章流程的对应小节；普通正式章按标题读取章幅与提交操作。审稿入口将托管替换、对账与历史操作移至既有历史参考，普通文件审查按任务取用内容审查专项。保留同版复用、必要补读及已有正式稿保护。
- 去味指导补充短碎句、逗号清单和问答提纲的信息主次判断；内容审查沿用因果、连续性、约束、读感四项，区分表达、场景体验、行动依据和实际变化。结论绑定最终稿与实际范围，保留已修、未解决、需设计选择、资料不足或未检查的实际状态。
- 新增标准库读取预算工具与显式清单，覆盖六类任务、八次角色调用、102 个基础／条件／组合变体，按实际标题切片计 UTF-8 字节与去空白字符；预加载和条件叠加登记，调用内去重、跨角色分别计量。基础路径与已登记分支上界分别设限，已接入 CI 和 release verifier。
- 新增五个原创合成开发案例及两臂准备／冻结核验工具，复用现有执行与用量验收。相同题目、输入、模型设置、次数、篇幅及授权先固定，技能快照分臂；原稿、旧说明、产物和失败分别保留。真实作者反馈提供空记录模板，本轮没有真实作者否定或真人试读数据。

入口去空白字符：写作 6,023 → 5,023（减少 16.60%），审稿 11,447 → 8,533（减少 25.46%）。这是入口文本变化，条件参考仍在；不等于总规则、实际上下文或账户用量同比减少。

预算是对显式登记路径的审计，不自动发现全部 Markdown 依赖，也不证明模型实际读取。正常长篇基础路径仍有 38,237 去空白字符，短篇完本写作路径为 56,916；没有为追求较低数字删掉现有义务。动态正文、状态、宿主提示、工具输出与实际 token 不在此计量内。

## 真实 CLI 开发试用

在运行前固定本轮修改前与候选技能、五个任务、选择范围、配置模型 `gpt-6.1-sol`、`ultra` 推理设置、相同宿主与每条件一次生成。每次为新 CLI 进程，显式提供对应冻结入口，禁用用户配置与 rules，保存完整启动参数、任务哈希、JSONL、stderr 和进程结果。不能由此推断所有宿主隐含指令都不存在，也没有检验桌面自动发现。

预定执行两题两臂及三题候选边界，共七次；实际六次完成，一次修改前版本在预设 600 秒内未完成。没有重试或挑选更好产物；三题未选中的基线仅保留准备状态，不计为执行。
