# 小说标点校对

用于新写正文的交付复核，以及用户指定的标点、对白格式审校。先连读本次范围与必要前后句，确认说话人、引语边界和句意，再改标点；不靠符号频次判断语言质量。

## 适用依据与修改范围

简体中文横排叙述和普通对白默认使用中文标点。英文原文、网址、邮箱、代码、数字、仿聊天文本、书信及原样引文按各自语境处理，不全局替换半角字符，也不把所有引号内容都认成场景对白。用户和本书现行约定优先；没有特别要求时，不自行添加禁用某种标点的规则。

通用用法参照 GB/T 15834—2011《标点符号用法》：[国家标准信息](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8)、[教育部标准全文](https://www.moe.gov.cn/ewebeditor/uploadfile/2015/01/13/20150113091548267.pdf)、[全文转录](https://www.shsmu.edu.cn/yywz/info/1026/1526.htm)（2026-10-05 核对标准状态及相关条款）。主要查 4.2、4.3、4.7、4.8、4.10、4.11 和附录 B.2；具体疑点以标准原文和实际句意为据。下文例句为自拟。

结论分清三类：明确的标点错误、本项目或本书的写作约定、可选择的表达偏好。风格约定不能冒充国标；存在正常解释的特殊用法先保留并说明语境。只审不改时给位置、原句、判断和建议；只获准改标点时保持字词、事实和说话人，不借校对删改人物的商量、推辞或承诺。仅排版仍不改标点。

## 对白提示语与引号

先分辨提示语属于发言前、发言后、同一句话中间，还是独立动作。位置相似不代表用法相同。

| 语境 | 例句与判断 |
|---|---|
| 提示语引出原话 | 她说：“明天再来。”冒号引出后面的发言。 |
| 提示语放在话后 | “明天再来。”她说。／“还来吗？”她问。话已结束，提示语自己收句。 |
| 同一句话被提示语隔开 | “你先走，”她说，“我随后就到。”提示语后用逗号，不套用冒号。 |
| 前半句的疑问或感叹不能抹去 | “你还去吗？”她问，“路已经封了。”保留前半句真实语气，再判断后半句与提示语的关系。 |
| 插入独立动作 | “你先走。”她把钥匙放进他手里。“我守着门。”动作自成句；不能因夹在引语中间就写成“她把钥匙放进他手里，”。 |
| 引文作句子成分 | 她只留下“明天再来”四个字。句号收束叙述句，不给短引文补句号。 |

普通直接对白外层用中文双引号，内层引用用中文单引号，例如：她问：“你说的‘明天’，是哪一天？”完整独立引语的句末点号通常留在引号内；作为句子成分的引文按句法判断，原有问号、叹号不能一概删掉，也不在已有句末点号的后引号外重复补句号。

核对成对符号时检查顺序、层级和作用范围。独立跨段引语可以每段开头有前引号、只在末段末尾有后引号；不能只按左右引号数量相等判定。摘录从话中开始或结束时先核对片段边界。括号、书名号也看实际包围的内容，不把书名号和引号互换来凑配对。

## 本项目的直接对白约定

本套件沿用的写作约定是：同一对外层双引号包围的直接对白，中文句号“。”至多出现一次，而且只能收束整段发言。这是正文组织约定，不是 GB/T 15834 对所有引语的通用限制；不机械套用到书信、聊天记录、心理描写、作为句子成分的引文或必须原样保留的引用。

新写或已授权调整对白内容时，先删并重复信息，保留需要逐字说出的部分；确有对方回应或话题转折时按真实交流分轮，非关键原话可以转述。不能只把句号换成逗号、分号、问号或省略号，也不另造动作、拆开引号规避。改后回读人物的语气、承诺和接话是否仍成立。

仅校正标点时，若符合该约定必须改动对白内容，保留原话并把约定冲突与标点错误分开报告；不把多句直接引语本身说成通用语法错误。嵌套引用需要自己的句末点号时，先保持引用完整，不为符号数量删掉必要标点。用户另有明确要求时遵循本次要求。

## 句法、语气与符号形态

- 逗号、句号、分号按句子是否结束及复句层次选择。不要把已完结的句子一路用逗号粘连，也不因句长就强拆；分号可以组织复句，出现分号不等于不自然，但不能靠它掩盖冗长对白。
- 问号看实际疑问或反问语气。叙述她不知原因时写“她不知道他为什么离开。”，不因“为什么”加问号；若整句在追问或质疑这一事实，结合上下文判断；“你去，还是我去？”是一个选择问句，不在每个选项后都加问号。独立追问则可以分别收句。
- 冒号看提示范围，不能让本不属于原话的动作或旁白被包含进去。顿号用于合适的并列成分，不把分句停顿、概数中的“三五个人”一律改成顿号；并列引号、书名号之间也不机械加顿号。
- 普通中文省略号写作“……”，依省略、迟疑、断续、未尽或沉默选用；一段话中每次犹豫不必都标。不要为收句固定补成“……。”，也不要把“……？”“……！”一律删成“……”。省略后的点号依语气和结构复核；表示诗行、段落省略时可有独占一行的“…………”。
- 正文中表示解释、转折、中断或声音延长的破折号使用“——”。先确认确为破折号，再修正单个“—”或“--”；连接号（如“北京—上海”）、范围、负数、型号和网址不按破折号替换。用户为某书禁用破折号时遵守该约定，旧稿不因默认规则变化自动改写。
- 问叹号叠用及“？！”连用结合强烈语气判断，不能见到连续符号就报错，也不靠堆叹号补足缺少的情绪。普通叙述中的英文逗号、冒号等先确认是否误输入；小数点、时间“08:30”、比例“1:2”及英文原句保留其专用符号。

## 工具提示与交付复核

`lint` 在现有 `warnings` 中提供 `punctuation_review`：仅提示中文语境中的部分半角点号、省略号和破折号形态疑点，给出原稿行列、命中字符和附近片段。提示是待语境复核项，不自动替换、不阻断提交；总数和截断信息用于确认是否还有未展示的命中。脚本排除部分明显代码、网址、邮箱和纯英文语境，但不能可靠辨认仿聊天、原样引文或全部专用符号。

`ok=true` 仍只表示脚本硬检查通过。没有标点提示也不证明标点合格：句法、引号层级、跨段引语、提示语与动作归属、直接对白句号约定和符号语义都须通读。不得把警告数量当质量分数，也不得把零警告当标点审查凭据。

对每个疑点回到完整句和必要相邻句，确认是修改还是保留；修改后回读发言边界、停顿与说话人。交付按实际覆盖说明结果，未读部分不称通过。标点说明留在正文之外，用户只要成稿时不附加无关报告。
