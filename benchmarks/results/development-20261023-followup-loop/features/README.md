# 非浏览器功能循环复核

本轮范围为八技能入口与读者规则、规划/正文/审稿/历史/世界状态/存储/检索、拆文/榜单/研究/封面及源码分发契约。浏览器、工作台和平台草稿执行由同轮其他审查者负责。未改真实作品，未采集网站、执行安装或发布。

## 确认问题与修复

七猫公开书库 HTML 解析曾在每个元素边界插入空格。`样本<span>&amp;</span>书名` 被记录为 `样本 & 书名`，作者和分类也会发生变形；`按<span>点击</span>量` 则被误判为无法确认点击排序。变形的标题进入结构化快照后，用真实标题的连续片段筛选抽样会得到零候选。

修复限于 `story_rank_sources.py` 的文本提取：先连接行内文字片段，再统一归一空白；保留原始空白与明确的换行/块边界，继续忽略脚本和样式文本。没有更改历史快照、抽样算法、样本版本或研究证据校验。

- `rank-markup-red.log`：修复前新用例的失败证据，包含标题变形、排序误拒绝和下游原书名筛选失败。
- `rank-markup-green.log`：新增 5 项回归方法全部通过；覆盖行内嵌套、真实空格、实体、换行和块边界、脚本样式排除、矛盾排序/状态仍被拒绝，以及采集→抽样→研究交接。
- `rank-research-green.json` / `.log`：5 项新测试与既有来源、榜单、历史兼容、研究和长理由验证共 **105 项通过，零失败/错误/跳过**。
- `rank-markup-intermediate-fixture.log`：实现修复后发现新增测试误把样本的 `observation.title` 写成顶层 `title`。已修正测试取值；该中间日志不作为通过依据。
- `probe.py` / `probe-result.json`：另外执行 100 组嵌套行内标记等价探针、20 组样本排序/重复输入/研究交接不变性探针。它们是合成场景数，不另加进 unittest 用例总数。

同轮根审查者独立执行的额外 HTML 等价对照记录在上级目录；本目录不把自测称作独立审查。
