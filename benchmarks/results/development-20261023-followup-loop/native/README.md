# Native 浏览器复核与修复

本轮在上轮已完成的源码基线上继续检查，修复普通编辑回读的到达地址绑定、终端观察和相邻预览/写入边界。未安装插件、操作真实账号或发布作品。

- 普通回读先校验实际到达地址符合已配置的草稿 URL 模板及目标 ID，再固定该地址。正常同稿重定向通过；到达后的回跳或换稿拒绝。修复前两平台各出现正常重定向误拒绝、回跳反而接受，见 `redirect-red.log`。
- 快照后的逐 selector 唯一性/同节点检查也可能让页面变化。增加最后一次同页完整快照，与之前观察比较，后面不再读可等待 DOM。独立红证据见 `../independent/native-snapshot-tail-red.json`；回归覆盖标题、正文、章号、状态及 ID。
- 番茄预览在最终账号检查后也取得同页标题、正文与身份快照，避免同址正文更新、消失、重复或格式改变被当成成功。`preview-red.log` 的 20 个反例均原先返回成功。
- 保存及新建按钮在最后一次身份检查后，使用已绑定元素的一次脚本读取可见标签、aria-label、title 与连接状态，之后直接点击。`write-action-red.log` 和 `create-action-red.log` 保留原先实际产生发布点击事件的反例；最终覆盖保存两处、新建三处身份观察时机。
- 段落输入的最终焦点检查移到所有身份观察之后，避免再读账号时焦点转移仍键入其他字段。焦点归属保留同一可编辑根内的 P/SPAN 正向，拒绝独立输入控件、不可编辑祖先隔断和开放 Shadow DOM 内的工具输入。红证据见 `write-action-red.log`、`focus-owner-red.log`、`shadow-focus-red.log`；另有主线程真实 Chrome DOM 红/绿复核。

两种正文序列化规则保持原样。预览表达式提取结果与上轮最终分发副本逐字节一致，且该副本 SHA256 匹配本轮开始前源码清单；详见 `preview-serializer-extraction.json`。当前快照的实际 JavaScript 同时经过 Node 执行验证，包含严格预览段落和 ProseMirror 段落的正反向案例。

最终定向验证：`final-green.log` 共 **131 项通过，零失败、错误、跳过**，本轮新增 8 个测试方法。覆盖普通编辑回读、Native 创建/保存、只读预览、段落序列化与输入四个测试模块。正常按钮保存、自动保存、contenteditable、新建 popup/同页入口、首次分配 ID、保留空行、保存后只读回读等既有正向用例均保留。较早 green 日志只记录中间轮次，不能相加为总数。
