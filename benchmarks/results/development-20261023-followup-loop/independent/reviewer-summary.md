# 浏览器收口的独立复核

本审查者只读产品源码及测试，在本目录新增探针和证据；没有修改浏览器实现或产品回归测试。根线程的真实本地 Chrome DOM 验证另有 `real_dom_probe.py`，这里不重复计数。

## 独立发现并闭环的问题

1. **Chrome 路径快照遗漏选择器漂移。** 获取后续字段的 DOM 路径期间，先前选择器可能增加重复匹配，或唯一转移到另一个节点；旧节点仍连接时，快照沿旧路径取值，仍可报告成功。`chrome-snapshot-selector-red.json` 保留 2 个负向错误接受和 1 个正向。实现方增加选择器数量/路径复核，并在复核之后再次读取同页快照；独立原样重跑 `chrome_snapshot_selector_probe.mjs` 后 3 场景全部符合预期。
2. **Native 快照后的定位核验遗漏正文变化。** 初始同页快照之后，逐字段 `evaluate_all` 核对节点身份会继续让出执行；该核验期间正文改变时仍返回旧正文。`native-snapshot-tail-red.json` 保留七猫/起点各 1 个负向错误接受及各 1 个正向。实现方在定位核验之后增加最后一次完整同页快照并比较；独立原样重跑 `native_snapshot_tail_probe.py` 后 4 场景全部符合预期，回读期间零写入。

这些是应用自身后续读取造成的可观察间隔，不以写入 RPC 已开始后的任意页面变化要求不可兑现的跨进程原子性。

## 其他具体复核范围

- 静态核对两后端的合法同 ID 初始跳转与后续 URL 固定、普通编辑器/番茄预览最终字段范围、账号检查时序、段落序列化和缺失/重复选择器的拒绝路径。
- 核对 Native 使用已绑定 ElementHandle，最终按钮语义核验在最后身份读取之后；Chrome 使用公开 locator `evaluateAll`，通过只读 DOM 路径保留宿主选择器支持，最终字段回调自包含。没有插入页面标记、额外网络请求或私有传输调用。
- `chrome_action_contract_probe.mjs` 将生产 `readActionState` 单独序列化后运行，验证正文根/普通可编辑后代正向，以及表单控件、不可编辑隔断和外部焦点反向；并检查最终新建按钮的文字、可访问标签、标题、disabled 与 href。共 **16 场景通过**，安全正向只有 `final-state → click`，已观察不安全按钮均零 click。仅本地模型和被记录的 click 方法，不声称真实网站点击。
- 当前隐藏/禁用按钮的自动等待属于验证边界：Chrome 最后状态拒绝 disabled/aria-disabled；Native 最终语义快照未单独核对 enabled/visible，两后端未统一加入可见性判定。未证明该差异自身造成错误发布，因此未列为已确认缺陷，也没有为此要求扩大修复。
- 根线程另外发现 Native 可编辑 shadow host 内工具控件的焦点遗漏并交由实现方修复。其原生 DOM 证据与最终结果属于根线程记录；本目录汇总在最新源码上重跑本审查者的 Native 回读探针，避免沿用旧 hash。
