# Chrome 独立循环复查与修复

本目录为离线公开 CUA 契约验证。没有访问真实网站、账号或作品，没有安装、发布或提交。

本轮复现并修复六类边界问题：

- 普通编辑器最后读取正文后，账号、章号、标题或状态的异步读取期间正文改变，仍返回旧正文成功。
- 番茄只读预览最后读取正文后，账号或标题读取期间正文改变，仍返回旧正文成功。
- 上轮固定请求 URL 的检查误拒绝已配置、同作品同草稿 ID 的初次合法重定向。
- 段落编辑器已检查焦点，但实际粘贴前还有 URL 读取；期间焦点转移会把正文粘贴到其他字段。红灯断言检查了实际写入副作用。
- 新建和保存按钮在账号刷新前已经检查，但刷新期间变为“发布”后仍会被点击。
- 正文容器中的独立输入框、选择框、按钮、iframe 或不可编辑工具获得焦点，旧检查仍允许粘贴，错误改写工具控件。

当前实现用公开 locator 引擎解析字段，再以只读 DOM 路径在末尾一个 JS 执行回合读取当前 URL 和全部字段；兼容属性值、普通输入框、ProseMirror、只读预览和开放 Shadow DOM。独立复核发现初版路径方案可能漏掉较早 selector 的新增重复匹配或唯一目标转移，已补一次 count/path 重验及末尾完整快照，并通过原样独立反例重放。路径只用于读取，没有向页面添加标记或引用私有句柄。最终观察针对当前字段值，不宣称 ElementHandle 同一性或跨标签事务。

初次跳转按配置模板确认同作品、同草稿 ID 后固定实际到达地址；之后的回跳或换稿仍失败。`previous-final-bridge.mjs` 是上轮最终打包探针中的精确源码副本，`previous-final-redirect-red.log` 用同一反例确认合法重定向误拒在上轮最终版本已经存在。动作前最后一项 DOM 检查确认当前 URL、同一正文编辑根内的可编辑焦点或安全按钮文本/ARIA/标题/href，检查与粘贴/点击调用之间没有额外账号或 URL 等待。普通可编辑段落后代仍保留，独立工具控件、不可编辑屏障和另一个编辑根不获得粘贴授权。

`red-final-body.log`、`red-preview-redirect.log`、`red-action-boundaries.log`、`previous-final-nested-control-red.log` 保留修复前反例。`full-driver-worker.log` 中 driver 150 项、worker 94 项，共 **244 项通过，零失败、零跳过**；相对上轮新增 13 个 driver 顶层测试，参数化场景不重复加入该计数。自包含回调测试覆盖开放 Shadow DOM、属性、严格预览段落解析一致性和最终快照超时不重试。

命令、实际结果和源码哈希见 `validation.json`。主线程统一运行的完整 Python 回归、独立真实浏览器本地 HTML 检查和打包结果另由上级目录记录，不能与本组件测试计数相加。
