# 离线章节材料导出验证

2026-09-23，v0.5.11 开发源码。接续批量查看与状态复核，增加可供作者手工填写平台的章节材料包。本轮未发布 GitHub、Release 或 Packages，也未替换日常安装。

## 交付能力

`publish-export --book "<绝对书根>" --id "<清单ID>"` 在书根生成 `.story/publishing-exports/material-<UUID>.zip`，回执包含真实路径、文件大小和 SHA-256。

- 导出前在同一操作锁内重新核对正式版本、审查证明、登记路径及导出状态，仅 prepared 且当前匹配的清单生成材料。
- 改稿或外部改动会使清单过期，并持久保存检查结果；过期清单即使后来恢复匹配也不自动复活，已取消清单跳过检查。两者均不生成 ZIP。
- 每章的 `标题.txt`、`正文.txt`、`作者的话.txt` 原样保存冻结字段，使用 UTF-8，不添加章头、BOM 或换行，不清洗标点及正文格式。
- 包内包含 `使用说明.txt`、按数值章序排列的 `目录.txt`、完整冻结 `manifest.json` 和本次本地核对 `receipt.json`。说明与清单不属于小说正文。
- 写完后逐成员回读核对，再发布到全新文件名。重复导出不覆盖旧包，路径链接、目标冲突和校验失败会阻止成功交付。
- ZIP 只反映导出时的核对结果；之后改稿或取消不会更新、撤回旧包。平台账号、作品身份、上传、审核及排期仍未核验。

## 实际尺寸试用

[独立 CLI 试用](cli-trial.json)使用 12 章隔离样例，每章 2,470–2,471 字，共 29,643 字。材料包包含 40 个文件，完整冻结清单及所有章节字段逐字节匹配，目录与成员章序均为 1–12。

19 项检查全部通过，覆盖 ZIP 校验、正文完整性、中文与 CRLF、章序、来源核对及平台标志。导出前后创作 revision 均为 24，创作数据库的文件哈希和逻辑内容均未改变。本地合成样例不代表真实平台验收或文学质量验证。
