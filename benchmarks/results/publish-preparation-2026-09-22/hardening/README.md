## 保留的能力边界

仍只支持离线逐章材料，账号核验、平台上传、提交、排期、远端全文核对及短故事整篇投稿未实现。

本机为 Intel macOS，Python 3.10.21。Windows 原生连接保护已实现并附条件测试，但此次未在 Windows 或 Linux 原生 CI 执行；不得将本机通过扩展为跨平台已验收。

POSIX 连接身份检查需要 `/dev/fd`。同进程外部 SQLite 客户端使缓存描述符无法归属时返回 `publishing_connection_unverifiable`，关闭该客户端或使用独立工具进程重试。此保护不声明可对抗任意恶意同进程代码。

首次放置账本的 link/unlink 极窄中断窗口仍可能留下双链接，届时保留现场并拒绝继续；事务恢复入口不用于从备份覆盖账本，不构成完整断电容灾。
