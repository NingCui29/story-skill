# Chrome 本轮循环复核与修复

本目录只验证离线公开 CUA 契约；未访问真实平台、账号或作品，未安装、发布或提交。

本轮确认并修复三类遗漏：

- 同页创建与保存按钮仅标签复核，账号刷新期间 href 改成另一操作后仍可点击。现在把初始 href（含不存在的 null）绑定到最终按钮快照，继续兼容稳定的空/相对/绝对链接。
- `same_page` 创建消耗了管理标签，但 `state.list` 仍把该标签当目录。现在创建前清除管理引用，保留 owned 所有权，后续目录扫描独立创建管理标签，避免导航掉正在填写的编辑器。
- 已确认的新建编辑器在逐字段填写或保存前，DOM 草稿状态可变成已发布、消失或重复。现在每次动作前读取当前状态和 URL，不等待、不重试；失败时不执行下一次填写/保存，也不重发创建。

`red-original-source-replay.log` 用本轮开始时精确源码 `before-bridge.mjs` 重放，五个顶层用例均红；包含实际危险点击次数和后续字段写入副作用，并非只检查错误返回。

本轮初版状态检查又引入两处问题，均已在交付前修复：同 ID 的配置内 newdraft→modifydraft URL 切换被字面 URL 比较误拒；新增状态查询的 await 使最后目标核对变早，快照后换稿会使下一次 fill 改到旧稿。现以作品+已分配草稿 ID 验证配置内 URL，再在实际操作前重核当前绑定目标。红灯分别保存在 `red-state-compatibility.log`、`red-state-await-target.log`；后者明确记录旧稿章号被改，当前版本相同反例旧稿保持不变。独立代理另有原样重放记录。

最终组件回归为 **160 driver + 94 worker = 254 项通过，零失败、零跳过**。相对本轮起点新增 **10 个顶层测试**，含 **49 个参数场景**，参数场景不重复加入总数。验证还覆盖属性读取、省略/null/dom 状态来源、普通与段落正文、原创建重试禁令、同 ID 合法切换，以及不同作品/不同 ID/未配置 URL 拒绝。最终定向十项通过见 `green-state-target.log`。

完整命令、文件 SHA-256 和边界见 `validation.json`。目录型草稿状态保持原有目录核对边界，不在每次按键扫描整本目录；没有宣称跨标签原子事务或对任意工具调用开始后的外部变化具有原子保证。根线程负责最终完整仓库回归、独立浏览器与打包检查。
