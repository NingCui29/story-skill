## 确认问题与修复

七猫 HTML 解析把 `<template>` 内惰性书卡、排序/页码标记和书名文字，以及带 `hidden` 的子树当作榜单实际证据。结果可能在列表中加入并不存在的可见作品、污染标题/作者，或仅凭模板里的“按点击量”确认排序。该遗漏在本轮开始版本及原始实现中都存在，不是上一轮行内文本连接新引入。

修复统一作用于节点遍历和字段取文：忽略 `template`、`script`、`style` 与显式 `hidden` 子树；不能仅去掉文本却仍把模板内的卡片算入榜单。`hidden="false"` 仍作为 hidden 属性处理；`aria-hidden` 仅影响无障碍语义，不作为视觉隐藏依据。静态解析无法执行 JavaScript 或计算 CSS，对 hidden 采取保守排除；快照的 limitations 明示这一边界，不能声称采集等同完整浏览器可见性计算。

保留原始 HTML；旧快照、抽样算法与历史研究验证身份不重写。可见矛盾状态或排序仍拒绝；仅含惰性卡片时拒绝，不生成空榜成功。
