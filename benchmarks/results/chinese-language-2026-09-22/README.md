# 中文语法与标点专项审查

本轮审查 Story Skill 的中文写作与校对规范，并复核主要活动文档。修订已落入仓库：补齐语法标点校对入口、澄清只审与改稿的区别、修正 4 处文档病句或表达歧义。没有对用户的真实小说逐句审读，也没有发布或更新实际安装。

## 发现与处理

| 问题 | 修正 |
|---|---|
| 写作与审稿只笼统要求语句自然，缺少具体的语言校对指引 | 在已有 [场景指导](../../../skills/story-skill-write/references/drama.md#中文语法与标点校对) 中补充搭配、成分、修饰语、指代、关联词、否定范围及常见用字；写作和审稿通过已有文件按需使用 |
| 对白提示语、引号内外点号、跨段引语和省略号等缺少统一说明 | 补充简体横排正文的常见判断及短例，并明确英文、网址、代码、聊天形式和用户约定的特殊格式保留原有用途 |
| “只校对”与“只审不改”一并要求交问题清单 | 分开处理：只审不改交问题；已授权校对修正语言和标点，保留剧情与声线；有歧义则标疑点 |
| 章流程的“核对章名”可能使人误以为脚本会比对文首标题 | 明确脚本检查计划中的名称与导出路径；文首标题一致性、Markdown 排版标记、语法和标点由读稿核对 |
| 4 处活动文档存在病句或歧义 | [上手指南](../../../docs/中文小说上手.md) 补明核对主体及相符关系；[评估指南](../../../docs/evaluation.md) 将“接待核对问题”改为“接着处理待核对问题”；[目录指南](../../../docs/目录结构.md) 改正“修改……到……”句式；[恢复指南](../../../docs/recovery.md) 明确由迁移工具自动生成备份 |

新规则保留口语省略、倒装、重复、说话中断和有意修辞，不以句子长度或符号数量判定错误。需要核对的是真实句意及其作用范围，不能把全角化、逐段闭合引号或强拆长句当作通用处理。

## 依据与核验

2026-09-22 查询[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8)，GB/T 15834—2011《标点符号用法》列为现行推荐性标准。相关用法核对了北京师范大学出版科学研究院提供的[国家标准扫描全文](https://pub.bnu.edu.cn/docs/20171102100137826379.pdf)，重点包括 4.7、4.8、4.10、4.11 及 B.1.5、B.2；没有将通用标点规范写成平台后台的投稿要求。[来源记录](sources.json)

- **一次独立代理校对执行：** 12 段开发样本中，5 段确定错误得到修正，1 段指代疑点保留并说明，6 段正确或有语境依据的写法保持原样。随后逐项回读完整输出，未见新增错改。[输入](proofreading-input.json) · [原始结果](proofreading-result.json) · [复核](proofreading-review.json)
- **规则语义复核：** 跨段引语、嵌套引号、语气中断、技术符号、口语及授权范围未发现新矛盾。[复核记录](rule-review.json)
- **结构检查：** 写作与审稿入口通过基础格式校验；本地引用及新增锚点检查、改动格式检查通过。[入口校验](skill-validation.json) · [最终检查](final-checks.json)
- **运行时边界：** 已核对实际代码并运行临时小样本。合法中文标点在导出与全文合并后保留；未闭合引号、ASCII 省略形式、正文 Markdown 以及文首章号与计划不一致，也可能通过 `lint`。它不自动完成语法标点校对或正文去格式；`prepare` 仍要求实际审查。

本轮只改 3 份技能说明/引用与 5 份活动文档，没有新增包内文件或修改 Python。先前全量回归和静态 token 报告保持各自快照，不追认为本轮新规则的结果，也没有为文字调整重跑全套工程测试。[规则改动](rule-edits.json) · [文档改动](document-edits.json) · [运行时未变核对](runtime-stability.json)

12 段样本属于一次开发试用，没有修改前对照、重复抽样或真实整书校对数据；结果不证明整体文学质量或真实稿件的全面纠错能力。
