# 停止保护与宿主执行回执开发验收

当前为 **0.6.29 未发布开发源码**，八技能73个载荷文件。0.6.28的72文件和已发布0.6.27的69文件清单保持固定。本轮保留既有工作树，不更新真实安装或用户作品服务。已建立的开发编号保留，正式发布前按[版本规则](../../../docs/版本管理.md)统一定级。

## 交付范围

- 停机前逐页挑战：当前服务登记的页面冻结编辑并返回本次 nonce ACK；旧心跳不代替新鲜确认。已知未保存、保存中、恢复中和未提交任务表单阻止停止；失联页保留指纹绑定的单次人工确认。
- 停机状态以短 TTL 租约、作品操作锁和 CAS 与协作进程的新派发互斥；取消、过期、服务退出及新服务独占锁恢复各自核对所有权。瞬态租约不进入整书备份。
- 首个受控宿主适配为本机 Codex CLI：显式发起，冻结输入，只读沙箱，原生轨迹、进程和本机签名终态相互关联。只有控制器保存文字候选和审稿回执，正式采用仍走现有流程。
- 请求标识和参数形成幂等边界；相同请求只返回原尝试，参数冲突拒绝。活动、取消未确认、未知结果不能重新派发；确认退出但结果版本冲突不冒充仍在运行。确定尚未启动与未知启动结果分开，不编造退出码，不自动重试。
- **平台实页验收已由用户明确暂缓**。本轮仅做初始只读通道盘点，没有新增平台案例、打开编辑页或写入远端；既有平台验收不追认为本轮完成。

## 循环复核与修复

独立复核及真实前向发现并修复：缺少head对应账本被误判空闲；公开账本可伪造执行状态；已结束冲突错误阻止停机；临时原始材料缺失导致已结束调用重新变unknown；跨重启时钟域混淆；候选改写超出只审授权；运行账本原子发布与状态读取竞争；心跳每次保留历史副本导致目录无界增长。历史签名退出摘要与当前原始证据可读性分开，控制器后续更新不会抹去已经核验的调用。

首轮完整回归3263项揭出5个失败和3个错误，记录保留于[原始结果](unit-tests-before-compatibility-fix.json)：三处旧清单别名断言仍指向0.6.28；三处平台停机测试尚未回传本次挑战ACK；两处真实兼容性回归为目录被替换后旧服务无法正常退出。已修正测试，并为最后一类修复加入原目录描述符与操作锁保护：不接触替换作品，原作品存在宿主执行记录即按未知阻断。另补持锁、取消、拒绝、服务关闭、过期核对和目录恢复验证。

随后完整回归3269项仅剩1个真实Chrome目录选择失败（3243通过、25跳过），[失败记录](unit-tests-before-directory-race-fix.json)与[确定性复现](stop/directory-focus-race/focus-race.json)均保留。初始目录响应恰在用户选中与输入绝对路径之间改写输入框，导致路径拼接；已将回读期间的路径设为只读，并仅由当前轮结束恢复编辑。[修复验证](stop/directory-fixed/verification.json)4项通过，覆盖取消、旧响应晚到、导航替换、成功与失败恢复及不误建书。

## 边界

页面覆盖限当前服务实例登记范围；旧服务、未登记页和其他历史平台进程不被认证为全系统静止。旧服务不支持新鲜确认时明确阻断，不自动降级或按PID强杀。宿主只读限制写入，不是文件读取白名单；显式调用使用宿主账号及模型用量，不证明文学判断或真人反馈。原始执行证据和签名密钥在本机；跨机器或密钥缺失不冒认退出。没有重新构建/安装或完成Windows、macOS原生客户端验收。
