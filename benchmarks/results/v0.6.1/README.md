# v0.6.1 验证证据

本目录记录 v0.6.1 的实际验证；远端发布状态以 `release/` 回执为准。本机安装不随源码发布自动升级。

- `verification.json`：最终源码全量工程验证，包含测试数量、失败、跳过及各项证据。
- `scaling.json`：400 章／2000 卡及 4000 章／20000 卡的 strict、local 合成容量探针。
- `migration.json`：三个 schema 1 夹具的迁移与旧运行时回退副本检查。
- `tokens.json` 和 `tokens.md`：固定上游提交与当前指令文件的计数，不代表账单或模型实际用量。

三栏工作台的浏览器人工验收尚未完成。CI 通过只证明对应环境中的自动检查，不代表桌面浏览器交互验收。
