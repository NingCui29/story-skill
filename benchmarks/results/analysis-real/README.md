# 完整真实短篇：第二轮结果

日期：2026-09-10。本轮比较两份尚未发布的 v0.5.1 开发快照：第一轮结束时的版本（baseline），以及只增加一句动作情境核对要求的版本（candidate）。精确字节由 [manifest.json](manifest.json) 区分。

**两名匿名模型评阅者在《孔乙己》上均微弱偏好修订版；《命命鸟》均判为各有优势。** 没有明显质量落差，也没有证据证明普遍、稳定提升。每篇每版只有一份报告，不能把差异直接归因于新增的一句话。

## 材料与实际条件

使用 [固定来源文本](../../analysis-real/sources/README.md) 的完整页面正文：魯迅《孔乙己》与許地山《命命鳥》。保留异体字、诗行与段落，记录提取过程和正文哈希；不称校勘定本。主页面版本可能引用变化的转录依赖，本轮实际输入以正文 SHA-256 为准。原作和网页贡献的授权边界见来源目录。

四份报告由四个新代理上下文分别生成，使用相同任务、原文和继承的宿主设置，未显式覆盖模型；平台未提供的型号、推理档、温度和实际用量记为空值。报告正文要求 1,200—1,800 字，去标题和空白、包含标点与引文。生成者实际建立独立分析目录，以 1,600 字符上限切块，保存逐块发现，定点回读后提交最终报告。没有以语义质量不佳为由换一次生成挑优。

技能快照与设置先冻结，最终来源和任务哈希在生成开始前补齐；manifest 的初始冻结时间不是原文下载时间。两名新评阅代理只收到原文、任务、匿名 A/B 稿及 [中性评阅说明](review-task.txt)，不接收规则改动说明或版本映射。随机种子 20260911 在生成前确定。两位先各自完成《孔乙己》，再追加《命命鸟》；[第一题原判断](review-stage1-cases.json) 与冻结摘要一致，没有随第二题改写。全部完成后解盲，见 [映射](blind-mapping.json) 和 [逐项比较](comparison.json)。

两篇经典可能已在模型训练或既有阅读中出现，主代理取得来源时也看过部分原文。本轮不是训练未见或严格留出实验，没有人类编辑、重复采样或长篇小说，不估计生成波动和通用质量。

| 命命鸟 | 各有优势 | 各有优势 | [修订前](reports/baseline/mingmingniao/report.md) · [修订后](reports/candidate/mingmingniao/report.md) |

《孔乙己》的共同依据是：修订稿用“這一回是現錢，酒要好”保留人物末次出场仍有顾客要求的主动性，并把先听见声音、向下发现身体、后来理解泥手用途的顺序解释得更细。修订前对教字动机并存、分豆中的给予与匮乏也有优势。两稿的主线和迁移方法接近，差异只在少数具体解释。

《命命鸟》中，修订稿更细地追踪敏明从想过岸到庆幸未过岸，以及明知觉悟不同仍容许同行的选择；修订前更突出加陵先决定同行、后听异象的次序，以及结尾“軀殼”容纳的不同读法。这些优势分布不同，不能强行换成单一胜者。

两位对两稿的五个宽等级均给出“充分”，同时列出具体限制。这表明该分档在本轮没有拉开差距，不能读成满分或“大师级”。完整理由见 [评阅者 1](reviewer-1.json)、[评阅者 2](reviewer-2.json)。

## 保留的语义争议

两位均未登记确定的硬事实错误；这不表示所有解释都已被证实。下列五处是合并重复提及后的待复核问题，不换算成错误率，也不改写原始报告：

| 报告 | 表述或判断 | 尚需明确的边界 |
| --- | --- | --- |
| 孔乙己，修订前 | “后来只请求停止取笑” | “只”是否仅限于回应羞辱；末次仍强调付现钱，并要求酒好。 |
| 孔乙己，修订后 | “实用性只是随后补上的理由” | 先后顺序不足以证明后一个理由只是借口；用途不合也可能是独立顾虑。 |
| 命命鸟，修订前 | 心理门槛过渡偏薄 | 需依本作建立的期待，说明迅速决断何时构成缺点，不能只用写实渐进标准评价寓言与抒情效果。 |
| 命命鸟，修订后 | 梦中男女心理层次较薄 | 群像简化可能服务于寓言；须说明在本文中实际损失了什么。 |
| 命命鸟，修订后 | 对出路发生“误认” | 需界定误认对象，区分彼此动机、死亡的表述与彼岸是否真实；原文没有统一裁定。 |

本轮没有据这些结果继续增加规则。现有规范已要求限定推断、核对文类期待和说明判断代价；下一次验证应观察这些要求是否落实，不能仅通过堆叠措辞证明改善。
