# 小说改剧本：开发验收

日期：2026-10-27。范围是当前仓库源码的技能完善；没有更新用户安装、发布版本、改动真实小说或生成媒体。沿用八技能结构与现有文件清单，运行时版本仍为 0.6.27，本目录不是新版本发布回执。

## 功能变化

- `story-skill-plan` 承接“小说改剧本”：按请求范围交付动作、对白与必要声音齐全的成稿；明确只规划时仍停在规划。
- 成稿指导覆盖载体、可表演动作、人物回应、来源与新增安排、时限与知情顺序、场次格式、时长估算和连续交付。补齐已有剧本的审查、改稿、润色与排版边界。
- 总入口及写作、审稿入口同步分流；剧本不套用小说章幅、段落、附言和章节提交规则。README、上手示例与规划技能界面说明同步。

## 隔离执行

使用本目录的合成小说 [source.txt](source.txt)，不是用户真实作品。成稿与 A/B/C 边界试跑由未继承本次开发结论的独立子代理执行；实际改稿由参与文档工作的子代理执行，随后收到主代理的定向反馈。这里记录实际执行及回读，不称盲评或读者验证。

| 请求 | 实际产物与核对 |
|---|---|
| 全文改成一集真人剧本 | [四场成稿](draft/关门以前_第01集_真人剧本.txt)，覆盖两章，保留父亲原话、知情次序、人物选择与受伤限制；估计4分30秒，未经排演。 |
| 只做改编规划 | [规划](planning/adaptation-plan.txt)，一集三场，估计150秒，没有交付剧本动作对白成稿。 |
| 对照小说，只审不改 | [报告](review/report.txt)，定位知情、送表与拆修顺序、伤势、虚构修复结果、概述代替合作等九项问题；[输入剧本](review/input-script.txt)未变。 |
| 小说局部直接拆分镜 | [分镜](storyboard/storyboard.txt)，只覆盖短信至敲门，五镜估计19秒，没有强制先写整集剧本，也没有生成媒体。 |
| 实际修订已有剧本 | [修订稿](<rewrite/第01集 最后三天_修订稿.txt>)修复主要错误；主代理回读发现遗漏十点交钥匙期限，反馈后补回一处对白，保留[反馈前版本](<rewrite/第01集 最后三天_修订稿_反馈前.txt>)。 |

成稿试跑曾把“修改前保留旧版”理解为新稿每轮内部自审也要归档；已澄清为修订已有交付稿须保留旧版，新稿交付前内部自审无需逐轮另存。实际改稿遗漏期限后，成稿指导明确补入“影响选择的时限与约束”。前者为规则澄清，后者已在产物中修复，均保留首次结果的证据，不将有反馈修订报成首轮无问题。

源小说与审稿输入的 SHA-256 前后相同。主代理已阅读五项实际产物，并复核反馈修订。没有初始化 `.story`、提交小说章节或改写源稿；估算时长不是实测，可读性与拍摄效果仍需作者审定及实际制作验证。
