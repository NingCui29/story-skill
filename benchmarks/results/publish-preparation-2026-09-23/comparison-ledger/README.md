# 发布比较留痕与材料核验（2026-09-23）

本记录对应 v0.5.11 开发工作区。没有更新本机日常安装，没有推送 GitHub、创建 Release 或发布 Packages，也没有接入七猫、番茄后台。

本轮新增三个显式离线命令：`publish-compare-record` 保存作者副本的本地比较摘要，`publish-compare-history` 按清单分页找回，`publish-compare-inspect` 查看一条历史。原 `publish-compare` 仍只读。记录只含书籍／清单／章号、字段 SHA-256、覆盖范围、保存时正式稿核对结果和 `user_supplied_copy` 来源；不含正文、密码、Cookie 或平台保存状态。旧 schema 1 发布账本无需迁移，账本备份与事务恢复会校验、计数这些记录。

同时修复了材料 ZIP 在复核临近结束时被原地改写或替换，工具仍可能返回 `artifact_verified=true`、`usable_now=true` 的竞态。现在返回前再核对原 ZIP 路径、身份和 SHA-256；损坏时拒绝给出可用结果。包外回执的独立竞态修复见[上一轮记录](../manual-handoff/README.md)。

验证：

- 全量回归 `python3 -B -m unittest discover -s tests -q`：753 项，736 通过、17 项按环境条件跳过，0 失败、0 错误。
- 发布专项：131 项，130 通过、1 项按环境条件跳过。新增测试覆盖只读比较不写账本、显式记录、历史分页、改稿和取消后的旧记录、预算不足不插入、损坏记录拒绝恢复与备份，以及 ZIP 改写／替换两条复核入口。
- 独立临时书根试用：正式提交两章，准备清单，作者副本比较并保存，历史查看，修订第二章、取消清单、备份和事务恢复；备份实际含 3 条记录。各本地回执未回显正文，远端状态保持 `unknown`。针对性测试 48/48 通过。
- `story-codex`、`story-codex-publish` 技能校验及 `git diff --check` 通过。本地开发 ZIP 含 38 个载荷文件，SHA-256 `5d778dbafaf934450e0f6df46c243de3a53ea200792b94d48097a2a9dc90d665`；隔离安装有 8 个技能、38 个文件，新命令帮助可调用。

限制：这些都是本地结果，未在 Windows 原生环境或真实作家后台验收。历史里的“保存时可用”不能代表现在仍可填报；`publish-recover` 只恢复并校验 SQLite 事务，不提供从备份覆盖还原。作者副本可由提供者自行修改，记录和自带哈希也不是独立防篡改证明或平台回执。
