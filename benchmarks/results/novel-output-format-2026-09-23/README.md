# 小说成稿格式审查与修正

2026-09-23，Story Codex v0.5.11 开发源码。对照用户给出的小说输出格式，审查公共入口、写作、审稿、章流程、短篇合并器及现有校验。源码仍在本地开发工作区；未推送 GitHub、发布 Release／Packages，也未替换日常安装。

| 范围 | 原状 | 本轮结果 |
|---|---|---|
| 任务与授权 | 已区分规划、写作、审稿，但未单列章中续写、仅排版和修改对照 | 明确新写、章中／跨章续写、润色、排版、审校、修改对照；局部任务不复述前文或自动建章 |
| 纯文本成稿 | 已要求自然段和无 Markdown；对白每轮独立成段的表述过严 | 成稿只留必要章名和正文；普通段间空一行、不缩进或加装饰线；换人默认换段，紧密动作与同一人物短对白可同段 |
| 引号与标点 | 已有外双内单和一般中文标点指导；一般规则允许破折号 | 增加直接对白每对外双引号内句号最多一个且只用于发言收束；问叹省略号按语义处理；正文含对白禁用标点性破折号，保留编号、负数、网址等专用符号 |
| 仅排版与载体 | 未单列零文字改动及特殊载体保护 | 仅排版只动普通段落边界和手工缩进，全文字符对照并人工保护特殊空白；书信、聊天、心理、系统提示分别按原有载体判断；格式冲突在正文外说明 |
| 短篇全文 | 合并稿首行重复书名，章节正文特殊换行被规范化 | 新稿从第 1 章章名开始，书名保留在文件名和元数据；正文原有换行与特殊空白保留，仅补必要章际分隔。旧格式只读显示 stale，下次 `export` 或明确合并时备份并刷新，外改不覆盖 |

`lint` 只检查字数、损坏字符、占位符和重复行，不辨认对白身份、引号层级、句号语义或破折号用途。本轮将这些列为写作与审校时必须通读的规则，不能把脚本通过解释为格式或文学质量通过。短篇合并加入的章名和章节边界是新字符；章节正文原有字符保留。Windows／Linux 原生测试本轮未运行。
