## 按优先顺序完成的内容

1. **写前交接与偏好召回。** 跨会话或分派已绑定的下一正式新章，默认用已有 `writing-brief` 一次取得 context、完整细纲、必要状态和书内适用偏好。同会话材料完整且未变时复用。偏好复用现有卡片，保留来源、例外、撤回状态与指纹；不新增数据库，不从正文自动学习，不把本次例外永久化。候选、片段和修订保持原流程。
2. **关键情节点覆盖与新增事实分级。** 将未出现、仅概括、实际呈现区分开；对关键选择和回应检查正文证据，同时保留过场概述、安静场景和群像分工。新增内容分为非承诺细节、需后续召回的事实、超出授权的结构改变，复用已有状态增量和四项审查。补卡不能代替设定与因果依据，已授权探索可以继续。
3. **精简执行路径。** 正文入口改为最小起草路径加条件读取，保留语义审查、提交及交付要求。入口 UTF-8 字节减少 18.56%；普通长篇路径静态规则量基本持平。没有提高既有预算上限，也未把静态字节当作 token 或实际成本。
4. **短篇平台化设计。** 按实际平台与入口处理目标、阅读期待、人物选择、后果和完整结局；付费停笔位置仅在需要时设计。平台未定不阻断独立可做的构思，不把非商业、安静或非反转作品改成统一商业模板，不将叙事候选称为后台设置。

现有题材写法卡、文风统一裁决、兑现归属、正文与候选隔离、版本和细纲绑定、四项语义审查、导出核验继续使用。长篇附言配图的 9:16 与视觉重点要求、附言 Markdown 纯文字规则、短篇默认无附言配图及完本封面要求均保留。本轮没有生成图像，因此没有新增视觉验收结论。
