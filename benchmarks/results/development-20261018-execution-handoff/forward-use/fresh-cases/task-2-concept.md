# 任务二：标本室搬家的短篇构思

状态：独立构思候选，仅含人物选择、推进与完整结尾；与任务一无关。

**人物与开端。** 双主角都是毕业生。周衡想按学名整理，让下一届不再靠猜找标本；李禾负责过校园导览，舍不得大家叫惯了的旧名。搬家前，两人打开多年未贴签的柜子，发现老师们口中的“雨伞草”居然指着三份不同标本。李禾笔下还有一个旧名叫“别拔，老师的”，周衡怀疑那根本不是名字。故事跟随他们边整理边接话，幽默来自各自认真的地方不同。

**选择与期待推进。** 最初让读者等：这两人能否给同一柜植物取好名字？周衡先编学名目录，却遇到缺少花果、无法可靠鉴定的旧标本；李禾请师生回忆，又发现同一份标本有几个旧名，连命名的理由都对不上。两人都得放弃“自己这张表足够用”的打算。周衡保留未鉴定项，不为整齐硬填；李禾留下不同口述及讲述者，不替众人编出唯一正确的往事。他们给每份标本一个固定编号，让学名检索和旧名检索都能找到同一件东西。读者的期待随之变成：毕业以后，没有他们在旁边解释，这套东西还能不能用？

**决定性场面与结尾。** 搬到新室后，两人请下一届学生各拿一张便条找标本，一张写学名，一张写旧名。学生找到同一个抽屉，却反过来指出：他们会找，未必知道取出后怎么放回。两人于是给托纸补上编号，把尚待鉴定和口述有分歧的项目一起交接。钥匙交出去，下一届独立完成第一份归位，搬家与传承的主线就此收束。周衡仍觉得展签上学名应占第一行，李禾仍嫌旧名印小了像注脚；他们没有统一意见，只把两种展签样稿留给接手的人。离开前，新生问“别拔，老师的”该写在哪栏，周衡指向旧名栏，李禾补上讲述者姓名；它的学名那格仍空着。
