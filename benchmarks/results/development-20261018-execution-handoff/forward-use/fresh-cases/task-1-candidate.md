# 任务一：矿井救援候选片段

状态：独立试写，暂未采用。下列“片段”范围为正文；末尾自审不计字数。

## 片段

照明一灭，阿岚先听见了管子里的水声。水从停转的排水管往低处倒灌，漫过她的鞋，前面搁着伤工的平台很快只剩窄窄一角。

“绳放下来！”老邵朝上喊。

“先别动人。”阿岚把帽灯转向墙边的手动闸。她的左手裹着纱布，指头蜷到一半就疼得松开，只能收在胸前；右手抓住手轮下缘，背抵石壁，一点点转过去。轮缘湿滑，第一次脱了手，她踉跄半步，鞋底在水里擦出短响。

上层传来梁队的声音：“我下来帮你？”

“你守绞盘，等我关死。”

她换了站位，右掌擦过衣襟，再攥住铁轮。最后一圈格外沉，她停了两次才拧到头。管中的轰响断成几下闷撞，脚边的水不再往上涨。老邵把灯照过去，平台上那工人正紧紧扶着岩壁，裤腿下的一只脚悬着，不敢落地。

阿岚望向平台中央的吊口，又把灯转到靠墙的旧检修斜道。

“从这边上，省得挪他过吊口。”她问老邵，“脚下哪一段还能承人？”

老邵蹲下，照了照斜道入口的枕木底下，又沿壁看过去。

“靠墙这两排，底下坐着石台，咱们三个人都能站；外沿那块板悬空了，谁也别踩。”他把靴子退回内侧，“我扶人，你看他的脚。”

“梁队，绳走旧斜道。”

上面答了声好，绞盘随即响起来。牵引绳穿过斜道口原有的定滑轮，沿坡放下；老邵接住吊带，踩着靠壁的枕木过去，替工人穿好，再把带扣翻给阿岚看。

“别让我撞那根横木。”工人说。

“看见了。”阿岚蹲在他脚边，用右手托住伤脚，“疼就喊，别忍着。”

绳子绷直。梁队摇动绞盘，吊带托着人沿坡上移。到了横木前，阿岚喊停，上面的棘轮立刻咬住；老邵护住工人的肩，让他侧过身，阿岚把那只脚送过木沿，才又喊了一声。

“上！”

工人的帽灯终于越过坡顶，光斑从他们脸上移开。梁队在上层把人接到平地，朝下面喊：“出来了！”

老邵坐在石台边，伸手来拉阿岚。她把右手递过去，左手还护在胸前。

“梁队，今天记你一功。”他喘着气说。

“记三个。”上面传来回答，“关闸的、认路的，还有摇绞盘的，一个也不能漏。”

阿岚笑了一下：“那摇绞盘的，先别歇，我们还没上去。”
