# 书架状态识别边界巡检

2026-10-06 07:26 UTC 轮次；0.6.11 本地开发源码。增量检查上一轮后的书架卡片、正式章数和本地作品状态功能，没有改写小说或新增写作规则。

## 已确认并修复的问题

1. HTML 注释及 Markdown 引用的惰性续行中的“作品状态：已完本”被当作现行状态。现复用已有 Markdown 非示例行解析器，并保留实际行号。
2. “完本计划／目标状态”区块和分号后的候选限定可能被忽略。现排除这些明确计划区块，并检查后置限定；封面、分类或标签待办仍与正文状态分开，但不再连带豁免“该状态仅为候选记录”。
3. 明确的未完本、未连载或“不是／并非／不算”状态原先被跳过，导致其它正向记录继续被确认。现保留对应的负证据；同一文件或不同现行材料中的矛盾显示待确认，并保留来源。

正例仍成立：“连载中＋尚未完本”保持连载，“已完本＋尚未连载”保持完本；单独的否定不能推出另一种状态。“尚未宣布／未确认”不直接等于反向事实。正文完本后仍有封面候选、分类待核对时，不因此撤销正文完本记录。作者手动标记的范围未变。

本轮仅修改 `story_workbench.py` 的状态读取与聚合，以及对应的 `test_workbench_writing_status.py`。原有未提交工作保留；参见[基线与最终哈希](baseline.json)和[本轮最小补丁](minimal.patch)。
