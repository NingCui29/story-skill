## 已实现

- 在既有调研技能内按需加载[扫榜参考](../../../skills/story-skill-research/references/rank-scan.md)，不增设技能入口，不让普通素材问题承担整套研究流程。
- 新增 `rank-template`、`rank-check`、`rank-collect`、`rank-aggregate`。快照记录来源、采样方式、时间、覆盖、作品身份及指标口径；输出原始 HTML、规范快照和 JSON／Markdown 报告。无需 `--book`，只写新目录。
- 同平台按 ID 或明确 URL 去重，保留逐次观测和出处，不合并同名不同书。按来源、记录日期、采样方法、新老书群体及指标口径分组；缺失不补零，冲突保留并排除本组统计，分类缺失纳入有效样本分母。
- 七猫固定公开书库适配支持最多 10 页有界 GET 和有源 URL 声明的 HTML 导入。检查筛选标题、当前排序、页码及已知字数／状态矛盾；完整标题进入来源名称，跨页标题变化会停止。该来源是低字数活跃连载观察样本，不是正式排行榜，也没有公开点击数。
- 发布载荷登记为 67 个技能文件；v0.6.21 的 64 文件清单保留。同步标准包、Claude、Codex、npm 包装及安装器清单，桌面运行时载荷包含两个新模块。
- 更新上游对照、工作台比较、文档导航及评估说明；0.7.9 的旧 token 测量继续作为历史证据，不套用到 v0.9.0，也不推导文学效果或实际账单优势。

## 独立复核带来的修复

1. 原 HTML 导入可能把不同题材的页面都归到同一个固定来源。现在要求逐页提供实际 URL 并匹配适配范围，完整页面标题进入分组名称，跨页标题不一致时拒绝合并。URL 仍是导入者声明，不能凭程序证明文件与地址的原始对应关系。
2. 原解析只检查标题条件，可能接收“200 万字／已完结”的矛盾书卡。现在已知字数达到 30 万或明确非连载状态会失败；未知字段保持空值，限制说明准确区分标题证据与逐书字段。
3. 独立试用确认日内正常数值变化也会触发冲突排除。报告已说明：合并结果只描述剩余有效记录，分类分布也会受排除影响，不能把它当作某一时点完整榜单；需要时点比较时分别汇总快照。

独立试用输入归档于 [first.json](synthetic/first.json)、[second.json](synthetic/second.json)。原试用说明中的“上级目录”指执行时临时目录；执行记录的本机绝对路径已替换为 `<REPO>`、`<TRIAL>`，命令次序与回执保留。最终重放沿用同一输入，不冒称新增独立样本。

## 真实来源的范围与限制

直接 HTTP 探测中，七猫返回 WAF 挑战，起点移动月票榜返回 HTTP 403；番茄响应含动态字体私用区字符及含义不同的零值字段。未绕过挑战，未据此把拦截页、乱码或占位零当有效采集结果。

随后普通浏览器成功打开七猫[第 1 页](https://www.qimao.com/shuku/a-a-a-1-1-a-0-click-1/)，通过页面分页进入[第 2 页](https://www.qimao.com/shuku/a-a-a-1-1-a-0-click-2/)。实际 HTML 导入得到 30 本；作品 ID、顺序、字数与可见页面核对一致，作者与分类均可读，数值指标全部保持 `null`，覆盖保持 `partial`。这证明本次两页浏览器保存／导入路径可用，**不证明脚本直连成功、全库覆盖、长期稳定采集或其他平台适配可用**。原 HTML 含完整简介与脚本，只保留在临时验证文件中，仓库归档来源地址、核对字段及页面哈希。

工具记录的 `collected_at` 是 HTML 导入时间，通用导入路径不知道页面原始采集时间；本次会话另有实际浏览器观察记录。新书群体以低字数和近期更新筛选作为观察入口，不证明首次发表日期。番茄、起点及其他来源仍需通过可读页面整理规范快照；没有相应直连采集器。
