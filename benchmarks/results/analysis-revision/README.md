# 语义争议修订与教学补充

本次继续完善未发布的 v0.5.1：把上一轮五处争议落实为四份可阅读的修订分析，补充一个按需加载的教学对照，并完成一次新的分析修订试用。四份作品修订稿经独立模型复核后均可交付；这表示本次核对未留下必须先修改的问题，不是人类编辑认可、全无错误或“大师级”认证。

这些是依据已知评阅意见制作的新副本。目录中的 baseline／candidate 仅指上一轮原稿来自哪个快照，不能当作本轮新旧技能的对照输出。上一轮原稿、匿名判断、来源与工程回执保持原样。

[逐项复核建议](adjudication.md) 记录原表述、证据区间、替换建议和仍不能证明的内容；[修改记录](changes.json) 保留实际替换的文字。十三处精确证据区间已核对。四稿现为 1,654—1,777 个非空白正文字符，86 处引号内文字均可在原文定位；带块号的段落也核对了对应原文块。[引用与位置检查](quote-check.json) 只确认文字和位置，语义判断仍依赖阅读全文。

两名未参与修订的代理各核对一篇作品的两份稿，读取完整原文和前后报告，不接收前轮评阅结论作为答案。这是独立复核，评阅者知道哪些是修订稿，不能称为匿名盲评。

第一轮复核另发现《孔乙己》第二稿沿用了“无法逆转的身体损伤”：原文能确认严重伤残，未说明能否恢复。已收窄为“严重的身体损伤”，并经同一评阅者限定复核后通过。[初次意见](reviews/review-kong.json)、[当时稿件](reviewed-drafts/candidate/kongyiji/pass-1.md) 与 [修正后复核](reviews/review-kong-followup.json) 均保留；没有覆盖首次未通过的结论。《命命鸟》两稿的 [独立复核](reviews/review-ming.json) 没有提出必须修改的问题。

这些分析新副本没有替换旧书库的已定稿报告，也没有重新宣称完成一次导入、逐块记录或故障恢复试验。所用原文、块范围与来源授权沿用 [第二轮固定材料](../../analysis-real/sources/README.md)。

## 技能只补示范与入口条件

[教学缺口审查](teaching-audit.md) 认为原有深读规则已覆盖五处问题，无需逐条增加禁令。实际修改只有两个文件：

- `examples.md` 增加原创《借影》对照：说话先后不能单独证明借口；赠影决定迅速不自动构成人物缺点；批评应说明本文反复建立的行动条件为何没有得到展开，同时避免把未展开误说成设定矛盾。
- 分析入口把按需阅读样例的条件扩展到推断过强和评价尺度不明。普通深读仍不必加载整份教学材料。

`deep-reading.md` 和运行时代码均未改变。新增教学故事不进入试用材料，也不称留出题。修改后的字节在新试用生成前冻结，见 [manifest.json](manifest.json)。

## 一次独立迁移试用

另一名未读技能或教学稿的代理创作《最后一笔》及一份有可用观察、也有争议判断的点评。原点评是练习材料，不是旧技能的输出；没有提供标准答案。技能编写方在冻结前未读这份文本。

一个新代理按自然任务修订点评，实际读取了共同入口、分析入口、深读规范与教学样例。它将“反抗数字管理”改为补充记录尺度，将“经验已完整保存”改为保存尚未完成，并依据纠错、扫描及征求同意的行动，重新评价手续的作用。另一名只看原文、任务、前后点评的代理认为这些修订改变了论证和建议，不只是添加谨慎词，未发现需要强制修改的问题。

材料和产物： [完整短文](transfer/source.txt) · [原点评](transfer/commentary.md) · [任务](transfer/task.md) · [修订点评](transfer/revised.md) · [实际读取记录](transfer/process.json) · [独立复核](reviews/transfer-review.json)。正文 800 个非空白字符、12 处引文精确匹配，见 [检查记录](transfer/check.json)。本任务只修订给定分析，没有建立书库或运行 CLI；前轮试验包装将所有命令都附加 `--book` 的问题没有带入本次任务。

这只是单次、单版本、原创微型材料上的行为观察。没有旧技能基线或重复采样，不能证明新增样例导致了改善，也不能外推为复杂长篇、真实作者作品或实际账户消耗的提升。
