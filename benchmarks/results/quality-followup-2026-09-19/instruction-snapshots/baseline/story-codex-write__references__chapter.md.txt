# 正文单元的写作与提交

起草前读取 [冲突、看点与中文场景](drama.md)，同版已在上下文中则复用。使用共享 `<tool>`；下列所有书籍命令均附加 `--book "<书目录绝对路径>"`。本章计划和授权范围已确定后执行。

1. `context --book "<目录>" --chapter N --budget-bytes 16000`。它完整保留本章工具计划、匹配范围的 critical 卡和到期承诺、requires 卡及上章摘要/末尾，不读取可读细纲。定点读取本章已有细纲及采用依据，与返回计划核对；不一致时按 [项目状态](../../story-codex/references/project-state.md) 同步已采用内容，再重新取得 context，不用候选覆盖现行计划。核对本章所需硬限制卡已在 required_cards 中；`volume_dir` 不建立 scope 关联，缺卡先修正对应稳定 ID 或 requires。预算是 UTF-8 字节，不是假称的模型 token；仅不相关的可选卡可被省略。过期/已完成伏笔也可按 requires 显式召回。查历史原因用 `recall --query "<人名或线索>"`，必要时读取精确原文。
2. 在 `.story/drafts/` 按已读场景指导展开章计划，保留本书声线与有功能的安静，不提前用尽终局底牌。衔接不清时定点补读原文。核对章名及所属卷的完整 `第X卷 卷名` 目录；草稿使用 `# 第N章 章节名称` 标题，章计划 `title` / `volume_dir` 的取值规则见 [项目状态](../../story-codex/references/project-state.md)。
3. `lint --chapter N --draft "<草稿>"` 核对章名、带卷名的导出目录、长度、损坏字符和重复段落；`prepare` 也会预先检查名称，缺失时先补齐。`plan.length` 指定范围，`count_method` 默认 `visible_nonspace_v1`（含标点的可见字符）；`letters_numbers_v1` 只计 Unicode 字母与数字，中文/英文均逐字符；`han_v1` 只计 Unicode 已命名汉字及〇。默认排除首行 Markdown H1 标题、空白及控制/格式字符；`count_title: true` 计入标题文字，但不计开头的 `#` 和可选的尾部闭合标记（如 `# 第1章 夜门 ###` 中末尾的 `###`）；标题内容中的 `C#` 等文字仍按所选口径计数。导语算正文，正文文件不混入作者说明或审稿意见。报告所选口径及实测数，不能冒称平台后台字数。欠字补足已授权场景过程，超字压缩冗余，不增造新剧情凑数。
4. `prepare --chapter N --draft "<草稿>"` 返回 lint 及绑定当前书籍、状态版本、稿件哈希的 delta 骨架；把其中 `delta` 另存文件，由 Codex 填写摘要、changes 和因果/连续性/用户约束/文风四项观察与原句，并处理问题清单。在因果与文风观察中具体核对阻力是否有效、关键应对是否展开、阅读期待是否获得回报；用原句说明得失，不新增机器评分或“冲突数量”门槛。骨架含待审阻断项，不能直接提交；工具不代替审稿。changes 仅记正文实际发生的变化，引文必须在草稿中；`blocker` 未解决不能提交，普通建议可注明取舍。
5. `commit --chapter N --draft "<草稿>" --input "<delta.json>"`。正文、审查凭据、增量状态在同一 SQLite 事务中保存；随后按分卷导出为 `chapters/第X卷 卷名/第N章 章节名称.md`，N 不补零，使用回执给出的实际路径交付。已有章的旧导出路径不自动批量迁移。重复同一提交不会推进两次。版本冲突先刷新上下文并复核，不能只改 revision 数字重试。导出失败运行 `export` 恢复，不能把未导出的章说成交付完成。外部改稿冲突转 [审稿修订](../../story-codex-review/SKILL.md) 的 reconcile。

短篇同样放入带卷名的首卷目录，可整篇作为第 1 单元，也可按用户要求分单元提交；范围对应当前单元，整篇交付时另核对合并后的总长度和导语重复。整篇验收核心冲突、主角关键选择、付出代价与结局后果的联系，以及开篇阅读期待是否兑现；开放结尾可留未知，不能把首章悬念停笔当完篇。不自动把一章要求扩成全书。

多章连载按近期摘要和当前承诺，核对本章是否承接先前选择、阻力和解法是否重复。对手根据已知事件调整，旧办法留下后果；升级可改变合作条件、关系或责任。阶段所得要实际体验并影响后续，安静章容纳余波。摘要不够判断时定点补读原文，不把同一轮拖延或强塞新危机当推进。明确多章请求按章循环到授权范围完成。
