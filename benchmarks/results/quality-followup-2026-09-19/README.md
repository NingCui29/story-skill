# 2026-09-19 人物选择指导续修

本轮只澄清共同场景指导中的一句话：人物选择既受认知和本事限制，也受欲望与性情影响；可以误判、嘴硬或自欺，但要有情境依据，不为制造波折强加缺点。规划、写作和针对性审稿沿用已有引用，不新增表格、评分或提交门槛。改动尚未发布，未同步安装副本。

## 为什么试这一处

规则审查没有发现已证实会使作品普通的硬冲突。修改前的两份新稿已包含认知修正、真实取舍和安静的关系分歧，因此不能宣称旧规则禁止人物犯错或只能写办事过程。这次是小幅澄清及试用，不是修复一个已证实的文学能力缺陷。[规则复核](rule-review.md)保留判断范围。

## 材料与方法

两道新编的合成题目分别要求[港口代写家书的开篇两场戏](inputs/01-opening-plan.md)和[父女整理老裁缝铺的安静正文](inputs/02-quiet-scene.md)，不采用真实小说或已知评阅稿。

先冻结修改前技能，再由两个独立代理各完成一题；只改共同指导的一句后冻结候选，由另外两个独立代理完成相同题目。每个任务、每个版本只有一次代理交付，作者可以自审；内部起草次数和账户用量未测量。生成代理不读取另一版本输出。

评阅者是第五个独立代理，只看到每题的原始用户要求及匿名完整交付，不读取技能或版本映射。第一题顺序随机，第二题交换新旧排列；评阅后再解释标签。模型及推理设置沿用父任务、未指定覆盖，精确服务端模型修订未单独冻结。模型评阅不能代替真实读者反馈。[预先记录的方法](protocol.json) · [候选改动及依据](candidate.json) · [评阅任务](reviewer-brief.md) · [匿名映射](anonymous-mapping.json)
