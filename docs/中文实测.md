# 历史中文小说实测范围

v0.2.0 曾使用原创长短篇检查逐章提交、最新章修订、外改恢复和拆文续跑，并发现 Windows exFAT 导出问题。历史版本的机器回执仍可查阅，但按用户要求，旧示例小说、草稿、大纲、评阅与保留工程已从当前仓库移除，本地另有备份。

当前仓库不再提供这些小说的正文下载，也不能仅凭历史机器回执复现文学评阅。历史记录中的字数、标题和路径描述的是当时样本，不代表当前仍公开原文。

## 当前工程检查

`scripts/chinese_acceptance.py` 默认在临时目录生成简短的中文事务测试文本，检查长短篇保存、两轮最新章修订、外改恢复、幂等重试、分块分析和报告保存。它不依赖 `examples/`，不把合成文本当作小说质量证据。

```sh
python -B -X utf8 scripts/chinese_acceptance.py --output dist/ci-chinese.json
```

如需在本地重放已备份的原始样本，可以显式指定包含各书 `scenario.json` 的目录；源文件哈希校验仍保留，空输入不会报告成功。

```sh
python -B -X utf8 scripts/chinese_acceptance.py --scenario-dir /本地备份/examples --output /临时目录/chinese.json
```

作者试写原文应保存在仓库外或已忽略的 `.local-writing-samples/`，不提交到 GitHub。程序测试继续保留；工程检查通过不代表文学质量、平台审核或连载效果通过。
