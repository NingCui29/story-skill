更新日期：2026-10-26。目标：以创作者的写作和草稿同步任务组织界面，采用 Material Design 3 的色彩角色与反馈方式，保留天空蓝品牌色、紧凑布局及明暗模式。参考设计原则，不复制参考图布局。

## 执行与验收规则

- `[ ]` 表示未验收完成；实施进度和未覆盖边界记录在下方，不能以源码完成代替真实验收。
- 保留作者数据和已有编辑保护；候选、恢复副本、正式稿、平台草稿与正式发布保持独立。
- 比较时只删除本地 MD 空白行，保留段落换行、文字及缩进；远端按原样严格比较章名与正文。
- 未知写入结果先只读核对；不得自动重复发送。修改已有草稿保留 ID、修改前备份、保存后独立完整回读。
- 禁止 Qt、PySide、PyQt、Shiboken、Qt WebEngine、PHP。Windows 继续使用 C# / WPF / WebView2，Mac 使用 Swift / WKWebView。
- 本轮以现行数据和代码实现，不增加旧版界面兼容分支。真实平台写入与公开发布不作为界面验收的默认动作。
- 构建、原生运行、真实后台验收分别记录。没有 Windows 执行证据时，不标记 Windows 原生验收完成。

### 2026-10-26：实现与已验收范围

- **共享界面**：采用统一的 Material 色彩角色、天空蓝品牌色和浅／深／系统主题；删除 Mac 额外定义的颜色变量。浅色主按钮使用深蓝和白字，深色主按钮使用浅蓝和深字，文字对比度回归通过。书架卡片、按钮、输入框及聚焦提示共用样式。
- **平台流程**：选择范围 → 自动准备本地快照 → 整批只读检查 → 展示章名、正文差异 → 明确确认同步。每次检查只对当前作品、批次、配置、正文版本有效，10 分钟失效；已使用的检查不能重复授权下一次任务。
- **变化保护**：实际写入前重新读取远端，检查之后又有变化则停止；新建与修改继续保留持久化意图、修改前备份及独立全文回读。仅去除本地 MD 空白行，远端空行和末尾换行仍计入差异。长差异仅截短展示，不截短校对内容。
- **状态与停止**：本次检查、实际同步、历史观察分开显示；具体章号、停止原因与下一步动作同时显示。关闭面板可重新跟踪任务；停止请求等待当前保存及回读结束，不强制截断写入。窄窗口运行任务时优先显示结果区。
- **日常入口**：已有绑定默认收起；批次明确区分最新与历史。新建、添加和恢复成功后提供“打开作品”；恢复中心提供“先对照文字”；保存与停止面板提供作品处理入口。
- **沿用并复核**：候选／恢复／正式稿的保存语义、搜索与筛选持久化、目录选择、失败保留输入、上次位置恢复、审稿任务与实际采用的区分均由既有实现保留，并经过工作台回归。
