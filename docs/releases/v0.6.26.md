# v0.6.26：番茄草稿章号与章名输入修复

Story Skill **0.6.26** 修复番茄草稿编辑页中章号、章名填写后被页面重新渲染恢复的问题。Windows 工作台 **0.2.5** 内置同一修复。

## 本版变化

- 番茄章号、章名改用真实键盘输入并完成失焦提交，避免仅看到输入框值变化就继续写入正文。
- 清空、输入和失焦后均逐字核对；内容发生变化立即停止，不重试写入或重复创建草稿。
- 输入控件类型、可编辑性、键盘能力和标题控制字符不符合要求时，在清空前拒绝操作。
- 保留原有作品身份核对、草稿 ID、未知结果先只读对账和保存后独立全文回读。

新增回归覆盖新建与更新、受控输入框重新渲染、输入中途变化、失焦回退和不支持的控件。既有书稿、状态库及历史回执格式不变。

## 分发

[v0.6.26 主发行](https://github.com/NingCui29/story-skill/releases/tag/v0.6.26)提供标准八技能 ZIP、Claude Desktop 单入口 ZIP、Codex 本地插件 ZIP 及各自 SHA256，共六个附件。

[Windows 0.2.5 独立发行](https://github.com/NingCui29/story-skill/releases/tag/windows-v0.2.5)提供 x64 EXE 安装程序、便携 ZIP 及各自 SHA256，共四个附件。Windows 保持独立更新通道；主发行使用 latest。

本次没有重建 Mac 安装包。Intel Mac 继续使用 [v0.6.25 的 0.1.37 / build 38](https://github.com/NingCui29/story-skill/releases/tag/v0.6.25)，其中内置运行时仍为 0.6.25。
