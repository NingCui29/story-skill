# v0.5.6：拆书恢复、试写分流与策划目录

本版面向 macOS／Linux，沿用七个技能入口、33 个载荷文件和 schema 2。Windows 的既有 `WinError 32` 导出问题尚未修复，Windows 安装仍固定 v0.4.0；已用 0.5.x 写入的书先完整备份，不直接降级。[安装指引](../../INSTALL.md) · [本版验证](../../benchmarks/results/v0.5.6/README.md)

## 本版变化

- **拆书与报告恢复：**区分一次性点评和可恢复分析，识别缩进的章名、卷名与番外标题，处理混合换行；并发读取与报告导出恢复按已保存状态继续。长篇聚合沿返回的 `next_offset` 分页，不以摘要代替跨章证据。[审查与开发验证](../作品深读与评估.md)
- **开书与目录：**参考分析和原创新书分别保存；只给写作父目录时，默认使用 `作品分析/<参考书名>/` 与 `<书名>/`。新书独立策划资料默认放在 `00_项目策划/`，全书总纲、具名卷纲和逐章细纲放在 `01_大纲细纲/`；已有等效目录继续沿用。[目录规范](../目录结构.md)
- **写作与审稿：**独立片段试写无需先建书库；候选稿、未提交新章、已提交章节及外部改稿按各自状态处理。新写正文的 `.md` 文件使用纯文本章标题和自然段，不带 Markdown 排版标记；旧章不自动改写。人物选择指导补充欲望、性情及有情境依据的误判。[试写记录](../../benchmarks/results/standalone-writing-2026-09-19/README.md) · [审稿分流](../../benchmarks/results/review-routing-2026-09-19/README.md) · [人物选择试用](../../benchmarks/results/quality-followup-2026-09-19/README.md)
- **使用说明：**README 以安装、拆书、借鉴开书、续写和可见目录为入口，并将详细验证与历史记录留在专题文档。[README](../../README.md)
