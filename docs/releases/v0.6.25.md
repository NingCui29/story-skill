# v0.6.25：工作台保存恢复与草稿同步

Story Skill **0.6.25** 改进工作台保存、恢复、继续编辑与作品管理，并统一平台草稿的已有章节更新和缺失章节补齐。桌面分发版本为 **Intel Mac 0.1.37／build 38**、**Windows 0.2.4**。

发布状态：已正式发布，10个附件齐全。Windows 独立发行状态：已正式发布，4个附件齐全。

## 本版变化

- 保存状态、工作候选、恢复稿、重新加载和关闭保护相互衔接，处理异步保存、切换作品和迟到回执造成的竞态。
- 书架显示作品正在编辑的状态，支持继续上次工作、系统目录选择、作品创建与管理操作反馈；分类记录与平台实际状态分别显示。
- 草稿同步按确认的正式稿范围更新已有草稿的章名和正文，并补齐缺失草稿。修改前备份原稿，保留已有草稿 ID，保存后逐章独立完整回读。
- 新保存统一去掉正文空白行，保留非空行的字符、缩进与段落换行，严格核对标题及转换后的全文。该规则固定使用 `plain_paragraphs_v1`；原稿和旧回执保留。
- 同步面板分开显示本次进度、停止原因与历史核对记录，避免把历史完成状态当成本次结果。
- 番茄目录按页读取并核对总数，完整表格扫描后再次确认分页状态。已知读取超时最多恢复一次；创建、填写和保存动作不重放。创建失败但已分配草稿 ID 时保留标识，结果未知先对账。
- Mac 增加独立编辑安全脚本；Mac 与 Windows 的添加作品、新建作品表单均支持系统目录选择。

新旧书稿、正式状态和历史回执沿用既有格式。升级前保存全部页面编辑并退出旧客户端，安装后重新打开；本轮发行验收没有替换日常安装，也没有重启作者作品服务。

## 平台草稿的实际范围

本轮公开验收覆盖软件测试、隔离合成书稿、安装包及宿主发现。它不代表本版已完成番茄、七猫、起点真实多平台的全书、分页或多卷草稿验收，也不代表真实作品已被修改、保存或发布。

平台动作限已授权的草稿保存及独立完整回读。结果未知时先对账，不自动重发；不修改已发布章节，不提交审核或定时发布。操作前仍需核对当前页面、登录连接、作品身份与正文范围，见[平台草稿说明](../../skills/story-skill-publish/references/platform-drafts.md)。

Mac 为 Intel x86_64 构建，使用临时本地签名，未经 Apple 公证，Apple Silicon 未验证。原生关闭提示、下载保存面板和日常已安装应用的升级操作不属于本轮 Mac 自检覆盖范围。Windows 工作台及安装程序未做代码签名；原生验证在隔离 Windows 环境完成，不替代其他用户环境的兼容性验证。
