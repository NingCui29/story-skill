# v0.6.25：工作台保存恢复与草稿同步

本版整合工作台独立工作树中的修改，分发版本为 Story Skill 0.6.25、Intel Mac 0.1.37／build 38、Windows 0.2.4。此源码快照处于发行验证阶段；正式下载与验收结果以 Release 页面和后续验收记录为准。

## 本版变化

- 保存状态、工作候选、恢复稿、重新加载和关闭保护相互衔接，处理异步保存与切换作品时的竞态。
- 书架显示作品正在编辑的状态，支持继续上次工作、目录选择、作品创建与管理操作的明确反馈；分类记录与平台实际状态分别显示。
- 草稿同步统一更新已有章节、补齐缺失章节；本次进度、逐章完整回读和停止原因与历史记录分开显示。
- 新保存使用 `plain_paragraphs_v1` 去掉正文空白行，保留非空行字符、缩进和段落换行，并严格核对转换后的标题与全文；原稿和旧回执保留。
- 番茄目录按页顺序完整读取并核对总数；已知读取超时最多恢复一次，创建和保存动作不重放。创建失败但已分配草稿 ID 时保留标识，结果未知仍先对账。
- Mac 加入独立编辑安全脚本，Mac 与 Windows 均支持表单内系统目录选择；Windows 保持 C#／WPF／WebView2。

新旧书稿、正式状态和历史回执按既有格式读取。平台动作仍限已授权的草稿保存及独立回读；结果未知时先对账，不自动重发，不修改已发布章节，不提交审核或排期。工程测试与安装包验收不替代真实平台批次验收。

## 分发范围

主发行提供标准八技能、Claude Desktop 单入口包、Codex 插件市场包，以及 Intel Mac ZIP／DMG，各附 SHA256；Windows 独立提供安装程序、便携 ZIP 及各自 SHA256。

Mac 使用临时本地签名，未做 Apple 公证；本轮不据此声称 Apple Silicon 已验证。Windows 与 Mac 的构建、原生验收和完整载荷检查分别记录，发布标签固定后不移动。
