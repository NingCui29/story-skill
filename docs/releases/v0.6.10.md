# Story Skill v0.6.10 发布记录

本版包含八个技能、45 个载荷文件。发布前本地验收已完成；固定标签、远端 CI、Release 与 Packages 的最终状态将在实际核验后补录。本机安装副本不会随 GitHub 发布自动更新。

- 写作与审稿共用因果、连续性、约束和读感四类复核，补齐人物欲望、认知与行动边界、叙述视角、场景转场和连续章节衔接。检查按本次任务范围展开，局部修改与纯排版不自动扩大为全章重写；这些指导不构成自动文学评分或质量保证。
- 新计划采用 `visible_nonspace_v2` 计数，排除组合附加字符及指定不可见填充字符，防止靠不可见字符凑够章节下限。原 `visible_nonspace_v1` 保持原定义，原文未变的旧正式稿保留历史计数；新写或改动的稿件继续检查填充问题。
- 新写完整章节要求首行为与计划一致的纯文本章名，使用未补零的阿拉伯数字编号。工作台字数与章名检查沿用核心规则，补齐篇幅例外、细纲绑定及候选稿保存后的复核。
- 修复带 BOM 的候选稿误报版本变化：分别核对原文件字节与解码后的正文摘要。版本保护仍会拒绝文件在检查期间变化。
- 严格 `audit` 只核对状态与导出完整性，不再隐式恢复导出或写入审查记录；恢复导出须执行明确的写入操作。初始化先完成暂存数据库，再以不可覆盖的方式发布，失败的暂存现场保留供诊断。
- 新增 `outline-audit --file`，检查大纲的必需结构；结构存在不代表平台分类、人物逻辑或故事内容已通过语义审查。
- 平台分类区分投稿入口与长短篇篇幅类型，分类和标签各栏单独记录已确认、拟选或待核对。离线投稿交接补齐书名、简介、封面、素材权利与 AI 使用核对；本地材料不代表平台已上传、审核或签约。
