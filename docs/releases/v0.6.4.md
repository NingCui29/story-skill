# Story Skill v0.6.4

八个技能、39 个载荷文件。已公开发布；固定标签、Linux／Windows CI、Release 附件、隔离安装与 Packages 回下载已核验。

- 工作台每章一个入口，中栏按本章切换正式稿、候选和计划材料，保留按文件浏览。
- 三栏支持拖动宽度、独立收起与恢复默认布局；窄窗口侧栏、键盘操作和菜单层级完善。
- 阅读排版分离行距与段距，阅读设置集中收纳，编辑与阅读宽度协调，隐藏章名时保留原始文件内容。
- 独立对照及差异导航、全文搜索定位、未保存内容查找、阅读位置和编辑选区恢复。
- 完善异步请求顺序、外部文件保护、候选保存与恢复提示；目录刷新和重新读取文件分开。
- 支持明确登记的外层只读材料目录；旧计划缺少标题时仍能阅读，无效计划返回明确错误。
- 重写 README，按安装、开书、拆书、续写、改稿和工作台操作组织文档。

候选保存不覆盖正式稿，审稿入口不自动调用模型或批准采用。只读导出不具备服务版编辑能力。书库继续使用 schema 2，不自动迁移小说。侧栏设置按浏览器地址保存，重启换端口后不保证继承。

本版不包含作者测试篇或旧示例小说。程序与合成事务验证不代表文学质量，Windows CI 不代表 Windows 桌面浏览器人工验收。
