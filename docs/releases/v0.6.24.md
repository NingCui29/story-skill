# v0.6.24：工作台草稿同步

发行候选：Mac 0.1.29 / build 30，Windows C# 0.2.3，内嵌 Story Skill 0.6.24。完整源码 CI、两端构建及分发验收完成后发布；README 当前正式链接在发布后更新。

- 按所选范围的最新正式稿，同步更新已有番茄草稿的章节名称和完整正文；修改前备份，保留草稿 ID，保存后独立回读。
- 读取已核实错字标记中的原文，不采纳纠错建议；完整重填正文清除标记，剩余标记阻止成功状态。
- 同步状态显示最新持久化记录，区分历史核对与本次访问；正式稿章节范围自动刷新，旧批次保留。

默认保存与只读对账不覆盖草稿。未知结果先对账，缺失草稿不自动创建；已发布章节不修改。软件发行不代表真实平台批次已执行，不自动替换日常安装。

完整使用方法见[平台草稿说明](../../skills/story-skill-publish/references/platform-drafts.md)。
