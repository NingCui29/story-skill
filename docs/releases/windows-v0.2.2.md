# Windows 工作台 0.2.2

**本版正在准备，尚未完成本轮构建与发行验收。** 当前正式下载为 [Windows 0.2.1](windows-v0.2.1.md)。0.2.2 沿用 C#／WPF／.NET 10／Microsoft WebView2 桌面层，内嵌 Story Skill 0.6.23 Python 作品服务；不要求转换既有作品数据。

本版将与 [Story Skill v0.6.23](v0.6.23.md) 分别发布。Windows 使用独立 `windows-v0.2.2`，安装程序、便携 ZIP 与各自 `.sha256` 共四附件；主发行提供技能与 Mac 的十附件并保持 latest。Windows 0.2.1 起的应用内更新读取 `windows-v*`，旧版本继续按固定链接手动升级。

## 用户可见变化

- 恢复中心按作品分批读取，每页最多100条，可继续加载尚未扫描的目录。扫描未完成时保留提示，读取失败时已列记录仍可核对。
- 整书恢复保留文件、作品身份与原 Chrome 会话证据，但恢复副本不能继续使用旧执行端连接；执行平台草稿前须重新连接。
- 平台草稿在填入、点击和回读期间再次核对当前目标、草稿状态与正文；页面变化或结果不明时停止并先只读对账。番茄缺少独立只读预览配置时在启动或连接前阻断。
- 内嵌运行时提供采用新书名的 `book-title` 命令，保留书 ID、书根、章节与短篇全文路径；研究命令修正静态来源解析、重复标签抽样和旧研究材料兼容性。完整创作与研究规则需在所用助手中另行安装。

本版沿用 0.2.1 的安装交接、旧目录备份、失败回退、编辑保护、偏好保存与独立更新通道；具体新构建结果须重新验证。试读设计、回报呈现与封面联动规则详见[主版本记录](v0.6.23.md)，不据此声称已验证真实读者或平台效果。

## 构建与验收状态

固定源码提交、C# 合约测试、Windows 原生构建、安装与跨版本升级、完整载荷、项目禁止技术扫描、正式资产摘要及公开请求均待本轮实际回执。不能以 0.2.1 的测试数量、文件清单或成功结果替代本版验收。

原生 CI 运行在 Windows Server 2025 runner；它与 Windows 10/11 各用户设备的人工使用分别登记。合成更新进度截图不证明真实网络升级完成，WebView2 已存在时的安装也不能替代缺失时首次离线补装验收。应用安装器未做代码签名。

## 安装和数据保留

正式附件可用后按[安装说明](../../desktop/windows/README.md)下载并核对 SHA256。安装前保存所有工作台与外部浏览器编辑、退出客户端，书稿保存在应用目录之外。安装器经确认后核验并正常停止相关服务，无法确认的占用会阻止继续；静默安装不代填保存确认。

覆盖安装保留相邻 `.previous-*` 旧目录，失败时尝试恢复；恢复受阻时保留备份并提示。卸载保留应用目录之外的书稿与共享 WebView2 运行时。不要运行备份目录中的旧卸载器回退当前安装。便携包须完整解压，缺少 WebView2 时按说明运行随包微软安装程序。
