# v0.5.8：番茄短篇作品分类

> **历史名称遮盖：** 本页记录 v0.5.8 发布时的结果，但当时的固定标签、附件和包身份并未更名。下文名称替换后的路径仅供阅读，不能当作该版本可执行的安装地址；记录中的来源路径与哈希可能无法用遮盖后的文件复验。实际旧版资源请到[该版本 Release 页面](https://github.com/NingCui29/story-skill/releases/tag/v0.5.8)核对。

面向番茄规划短篇时，现行总纲或等效规划按本书已采用的内容记录“主分类、情节、角色、情绪、背景”，并写明选择依据和拟选／平台已确认状态。五栏只从用户提供的短篇选择页面截图中可见的词项选取；参考书标签或尚未采用的情节不算本书依据。长篇继续使用阅读标签和内容标签，不能把两种页面的选项或数量限制混用。

短篇截图共显示 102 个不重复的词项：主分类 24 项、情节 34 项、角色 26 项、情绪 8 项、背景 10 项。[选择表](../../skills/story-skill-plan/references/fanqie-tags.md#短篇作品分类写入总纲)只覆盖截图可见内容，不声称是完整平台列表。截图没有展示短篇各栏的可选数量或签约后修改规则，因此投稿时仍要以实际页面核对。已发布作品先查平台现值，不擅自改写。

本版仍为 7 个技能、34 个载荷文件，运行时 schema 2 与既有书库格式不变。Windows 既有 `WinError 32` 导出问题未修复，Windows 安装目标仍为 v0.4.0；已经使用 0.5.x 的 Windows 书库需保留原状态，不自动降级。
