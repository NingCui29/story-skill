# v0.6.27：DeepSeek Harness 适配与本地插件包

Story Skill **0.6.27** 增加 DeepSeek Harness（DSH）宿主安装与本地 Cordis 插件包，并纳入 v0.6.26 之后的章节配图确认规则修订。

## 本版变化

- 安装器新增 `--host dsh`：项目安装到 `<工作区>/.dsh/skills/`，用户安装到 `~/.dsh/skills/`，八个技能保持同级；DSH 按一层目录发现，自动出现在会话技能目录。
- 新增 DSH 插件包 `story-skill-dsh`：通过 `bundledSkillDir` 提供八技能，`providerName: story-skill`、`includeDefaultRoots: false`、`watch: false`；包含 Plugins 页面标题、说明和图标。构建命令为 `python3 -B -X utf8 scripts/package_dsh.py --output dist/dsh-plugin --archive dist/story-skill-dsh-<版本>.zip`。
- 长篇自动配套的章节配图改为先由用户确认；已有明确且适用的选择直接遵循，待确认或不需要不算缺图。短篇默认不要求附言及其配图，用户明确要求时按指定范围处理。
- 补充 DSH 安装、插件优先级、更新与本地 profile 说明，并增加安装与插件包回归。

## 使用入口

- 安装到 DSH：`python3 -B -X utf8 scripts/install.py --host dsh --user`，或只用单个工作区时使用 `--project`。
- 构建 DSH 插件包：`python3 -B -X utf8 scripts/package_dsh.py --output dist/dsh-plugin`。
- 会话内使用 `/story-skill` 或由模型用 `skill` 工具加载；完整说明见 [安装指引](../../INSTALL.md#deepseek-harness)。

本次发布不自动替换本机正在运行的 Harness、工作台服务或已安装技能。
