## 开书先建立书名目录

只给写作父目录时，新书默认保存到 `写作父目录/书名/`。例如要求“在 `/Users/作者/小说` 下开一本《雾港来信》”，实际书根为 `/Users/作者/小说/雾港来信/`；创作约定、策划、设定、大纲与 `.story/` 状态都在其中。书名未定时先采用并注明暂定书名，完成时给出实际目录和规划文件路径。

用户已明确最终书目录或继续已有作品时沿用原位置，不重复嵌套同名目录。技能先选定最终书根，再调用初始化；`--book` 仍原样指定最终目录，`--title` 只登记标题，不会自动追加路径。已有文件误放在父目录时，先核对和保留原内容，再按需求整理，不自动搬书或重新初始化。[目录规则与示例](../目录结构.md#小说一书一目录状态与可见稿件分开)

## 从拆书推进到原创规划

重写的 [README](../../README.md) 以安装、开书、目录与常用操作为入口，并新增 [从拆书开始，新起一本书](../../README.md#从拆书开始新起一本书) 的完整可复制请求：

1. 核对参考作品的原文范围，在独立分析目录保存拆书证据与结论。
2. 提炼写作方法，写清适用条件和失败风险。
3. 重新设计新书人物、关系、矛盾、事件链与结局，参考剧情不登记成原创事实。
4. 建立书名目录，完成策划、全书总纲、具名卷纲和近期逐章细纲。
5. 保存已完成范围、实际路径和下一断点；只授权拆书和规划时，不自动开始正文。

这是既有分析与规划技能的组合用法，本版没有新增文学分析能力，也没有将旧试用结果当作新质量认证。大纲仍按“全书总纲 → 第X卷 卷名／本卷大纲 → 第N章 章节名称”保存，章细纲一章一文件；写作获授权后，正文另存 `chapters/第X卷 卷名/第N章 章节名称.md`。[上手说明](../中文小说上手.md) · [文学评估范围](../作品深读与评估.md)
