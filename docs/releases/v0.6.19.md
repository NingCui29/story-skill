本轮发布版本为 **v0.6.19**，计划固定标签为 `v0.6.19`，版本分支为 `version-0.6.19`。本版发布验收正在进行；固定提交、最终包体、测试结果及远端分发尚待核验，以下清单不表示附件已公开或检查已通过。

[本版 Release](https://github.com/NingCui29/story-skill/releases/tag/v0.6.19) · [安装升级](../../INSTALL.md) · [工作台操作](../工作台需求与进展.md)

## 变化

- **工作台界面。** 统一天空蓝主题与明暗外观，集中搜索筛选，收起卡片低频信息，完善菜单收起、空态、返回书架刷新和耗时操作反馈。
- **作品管理与恢复。** 提供新建、移出／撤销、重新定位、系统废纸篓／回收站删除、整书备份恢复、恢复中心和保存全部候选；保留作品身份、保存状态及候选采用关系的核对。
- **桌面更新。** Mac 与 Windows 可检查正式版本，显示下载百分比、大小、速度、预计剩余时间，支持取消、重试及 SHA256 核验；核验后交给手动安装或系统向导，下载完成与安装完成分别提示。
- **平台草稿。** 正式章节冻结清单、预览、受控保存、全文回读、重复执行核对与只读对账接入工作台；番茄增加作者自助配置入口，保存与配置分别记录。
- **安装与分发。** 保留标准八技能、Claude 桌面单入口 r2、Codex 本地市场与 npm 内容包，新增本版双端安装附件。桌面目标为 Mac **0.1.18 / build 19**、Windows **0.1.9**，内嵌运行时均为 **0.6.19**。

写前交接与偏好召回、关键情节点覆盖、短篇平台化设计、题材写法、语义审查、事务提交、历史依赖、世界状态与已采用细纲绑定继续保留。书库仍使用 schema 2。安装包不会迁移真实书稿、采用候选或自动停止已运行的作品服务。

## 平台草稿的实际范围

发布技能可为番茄、七猫、起点准备已审查正式章节的离线材料。平台保存只处理草稿，须核对账号、作品、正式章节快照、目标清单、页面配置及完整回读；审核提交和定时发布仍由作者在后台完成。[操作与约束](../../skills/story-skill-publish/references/platform-drafts.md)

番茄的既有开发证据覆盖作者指定测试作品与隔离合成书：冻结 81 字符功能稿，预览后由生产执行器新建草稿，再从独立只读预览页完整回读，标题和正文一致，保留首行换行及内部空段；重复执行同一清单时核对已有一致草稿，没有重复新建。该样本没有额外尾换行。原 83 字符稿丢失额外尾换行的失败、冲突与旧未知记录保留，不能通过裁剪冻结稿追认成功。[既有开发记录](../../benchmarks/results/development-20261019-platform-drafts/)

当前宿主模式复用助手已连接、已登录的 Chrome，需要活跃的助手工作进程持续执行；缺少工作进程或可靠的只读回读配置时阻止保存。仅打开或重载编辑页曾出现正文增长、原因未确定，既有成功链路使用独立只读预览，不能将编辑页打开当作无副作用回读。它不是无人值守发布。

实页证据仅覆盖单卷完整表格；**真实分页、多卷、七猫及起点仍待实页验收**。番茄自助配置表单的验收只证明能生成受控本机配置与冻结清单，不表示后台已核对或草稿已保存。合成测试也不证明真实小说已完成正式审稿。本版包体中的相同行为仍须按最终源码及实际安装结果核验。
