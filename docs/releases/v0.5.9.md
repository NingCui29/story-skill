# v0.5.9：协作交接与正文分段

> **历史名称遮盖：** 本页记录 v0.5.9 发布时的结果，但当时的固定标签、附件和包身份并未更名。下文名称替换后的路径仅供阅读，不能当作该版本可执行的安装地址；记录中的来源路径与哈希可能无法用遮盖后的文件复验。实际旧版资源请到[该版本 Release 页面](https://github.com/NingCui29/story-skill/releases/tag/v0.5.9)核对。

本版收紧独立代理协作的触发条件和交接范围。默认仍由当前会话写作、审查和交付；需要独立代理时，交接本轮目标、必要原文与状态、关键约束和交付位置，当前会话核对结果后再采用。交付时区分自审、独立复核与盲评，不能把已知创作过程或先前评价的复核称为盲评。

正文场景指导补充分段判断：说话人更换时另起段；行动焦点或人物判断转移时，考虑在意义转折处断段。交付前检查密集长段是否把动作、解释和内心反应挤在一起；有连续阅读作用的长段仍可保留，不设统一字数上限，也不要求一句一段。本版没有给 `lint` 增加机械段长门槛。

套件仍包含 7 个技能、34 个载荷文件，运行时 schema 2 不变；既有书库与正文不自动迁移。Windows 既有 `WinError 32` 导出问题未修复，Windows 安装目标仍为 v0.4.0；已使用 0.5.x 的 Windows 书库应先保留完整状态，不自动降级。

## 验证与限制

本地 Python 3.10 验证运行 560 项测试，553 项通过、7 项按条件跳过；34 文件 ZIP、本地 npm 包、四项运行命令、合成容量与迁移及 v0.5.8→v0.5.9 隔离升级均已核对。[v0.5.9 Release](https://github.com/NingCui29/story-skill/releases/tag/v0.5.9) 的附件、固定标签隔离安装与 GitHub Packages 注册表回下载也已核验；远端 Linux 成功，Windows 在既有 `WinError 32` 处失败。分项证据见[本版验证记录](../../benchmarks/results/v0.5.9/README.md)。这些检查可验证文件、版本与流程一致性，不能证明实际小说的阅读体验已改善；分段仍须结合具体正文审阅。
