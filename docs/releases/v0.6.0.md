# v0.6.0：统一使用 Story Skill 名称

本页记录 v0.6.0 的本地与远端验证结果。2026 年 9 月 24 日，该版固定标签、Release 附件及 GitHub Packages 已发布并核对；标签中的文档是发布前快照，本页是随后补充的结果记录。[安装条件](../../INSTALL.md) · [发布验证导航](../github-release.md)

## 本版变化

- 八个技能入口统一为 `story-skill`、`story-skill-plan`、`story-skill-write`、`story-skill-analyze`、`story-skill-review`、`story-skill-research`、`story-skill-cover`、`story-skill-publish`。界面显示名、默认提示、相对链接和共享运行时使用同一名称。[目录职责](../目录结构.md)
- 套件 ZIP 使用 `story-skill-0.6.0.zip`，npm 包身份使用 `@ningcui29/story-skill@0.6.0`。两项现已分别发布并完成回下载验证。
- 升级时须先核对旧安装并将旧入口移出技能扫描位置；项目安装器会拒绝新旧入口混装。旧版 v0.5.11 的固定标签、附件和包身份不会因本次更名而改变；旧标签不提供上述新入口。历史记录中的旧名称已遮盖，来源路径和摘要可能无法以编辑后的资料逐字节复验。[历史资料说明](../../benchmarks/NAME_REDACTION.md)
- 小说书库仍使用 schema 2，离线发布准备记录仍使用独立 schema 1。升级技能不自动搬动书根、正文、历史导出或平台上的章节。发布准备仍只生成本地材料及核对回执，不登录或上传到七猫、番茄。[功能边界](../platform-publishing.md)
