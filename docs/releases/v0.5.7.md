# v0.5.7：番茄标签写入全书总纲

> **历史名称遮盖：** 本页记录 v0.5.7 发布时的结果，但当时的固定标签、附件和包身份并未更名。下文名称替换后的路径仅供阅读，不能当作该版本可执行的安装地址；记录中的来源路径与哈希可能无法用遮盖后的文件复验。实际旧版资源请到[该版本 Release 页面](https://github.com/NingCui29/story-skill/releases/tag/v0.5.7)核对。

本版为面向番茄的开书规划增加两套标签的选择规则。正式新开一本书或维护全书总纲时，根据本书已经采用的人物、主线、关系和世界设定，在现行 `全书总纲.md` 靠前位置分别记录**阅读标签**与**内容标签**、选择依据、拟选或平台已确认状态。已有等效全书大纲沿用原位置；明确不用番茄的书不添加。已签约标签先核对平台实际值，不自行更改。标签不写进用于状态检索的工具章计划 `tags`。

选词范围整理自用户提供的两张番茄选择界面截图，收在[标签选择表](../../skills/story-skill-plan/references/fanqie-tags.md)。阅读标签的主分类提交时必选且只能选一项，主题、角色、情节各最多两项；内容标签的情节、人设各最多四项，情感最多两项，世界观最多一项。依据不足时保留待定，不为凑满上限乱贴；投稿前仍须核对平台现行页面。截图日期未知，词表只覆盖截图可见选项，不宣称平台全部标签或当前规则永久不变。

七个技能入口、运行时 schema 2 与既有书库格式不变。新增一份规划参考文件，因此 v0.5.7 发布套件为 34 个技能载荷文件；ZIP、项目安装器和 npm 包的显式清单按版本区分，旧版 31／33 文件布局保持原样。Windows 既有 `WinError 32` 导出问题未在本版修复，Windows 安装目标仍为 v0.4.0；已用 0.5.x 写入的书先完整备份，不直接降级。

## 验证与限制

本地 Python 3.10 的 560 项测试中 553 项通过、7 项按条件跳过；34 文件的 ZIP 和本地 npm 包逐文件一致，隔离运行时四项命令通过。[完整回执](../../benchmarks/results/v0.5.7/verification.json) · [打包回执](../../benchmarks/results/v0.5.7/package.json)。[v0.5.7 Release](https://github.com/NingCui29/story-skill/releases/tag/v0.5.7) 的附件、固定标签隔离安装与公开 GitHub Packages 注册表回下载已核验；远端 Linux 成功，Windows 在既有 `WinError 32` 处失败。[逐项记录](../../benchmarks/results/v0.5.7/README.md)。文件与状态一致性验证不证明标签适合某本书，也不代替平台投稿时的最新选择页面。
