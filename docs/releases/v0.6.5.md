# Story Skill v0.6.5

八个技能、40 个载荷文件。已公开发布；固定标签、Linux／Windows CI、附件、隔离安装及 Packages 回下载已核验。

- 新增七猫作品类型与标签参考表：6 个一级类型、25 个二级分类值；现实主义仅有“现实故事”，由用户补充确认。
- 收录用户后台截图中的 405 个标签：风格 33、角色 148、情节 158、背景 66；该页面每栏分别必选 1～3 个，按作品实际内容提供依据。
- 开书与总纲流程接入两级作品类型及四类标签，保持父子分类关系和平台差异，待定项明确记录；截图范围不推断为全部频道通用规则。
- ZIP、npm 和托管安装同步增加参考文件；保留 v0.6.0 的 38 文件、v0.6.1～v0.6.4 的 39 文件历史清单，覆盖从 v0.6.4 升级时的新增文件和备份检查。

分类来源为用户后台截图及补充确认，不代表系统已登录七猫核对某本书。没有自动修改既有小说的分类或正文，平台发布仍为离线材料准备。

本次不包含作者测试篇、旧示例小说或截图原件。本机技能安装与正在运行的工作台不会随 GitHub 发布自动更新。

本地完整检查通过：813 项回归中 796 通过、17 条件跳过；八技能格式、40 文件隔离安装、ZIP 与 npm 包的一致性及运行命令通过。400／4000 章的四组合成容量、三类旧库迁移、托管安装替换和回滚通过。

首轮完整检查发现两组旧安装测试将新版 40 文件清单与旧版号混用，已修正并重新执行完整检查。npm 最初因本机缺少可用工具而失败，在临时目录校验并准备 npm 后构建通过；未修改系统环境。首轮失败记录保留。
