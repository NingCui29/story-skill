# Story Skill v0.6.21

本版正在执行发行验证，运行时／插件为 **0.6.21**，桌面客户端为 Mac **0.1.24 / build 25**、Windows **0.1.11**。各项结果将在实际完成后回填；本页不将旧版通过视为本轮发布成功。

[Release](https://github.com/NingCui29/story-skill/releases/tag/v0.6.21) · [安装升级](../../INSTALL.md) · [上一版](v0.6.20.md)

## 变化

- 番茄草稿可从预览显式启动受控 Codex 工作进程，连接既有已登录 Chrome。使用账户默认设置与额度，已登录的外部 Codex CLI、官方 Chrome 插件（含 SDK）和已连接的 Chrome 会话需事先具备；权限拒绝即停止。
- 正文编码与比较策略独立：默认逐字严格核对，可选择段落兼容编码及明确授权的末尾换行数量变化。保存回执保留来源、编码与观察摘要；等价采用与逐字一致分别报告。
- 偏好按书籍、清单和配置保存，变更需重新预览；未知结果先回读对账，退休记录不自动重发。
- WorkBuddy AI 默认目录修正为 `.workbuddy-ai/skills/`；Qoder CN 个人目录为 `.qoder-cn/skills/`，项目与国际版共享 `.qoder/skills/`。历史开发调用的范围见[脱敏摘要](../../benchmarks/results/v0.6.21/host-compatibility-summary.json)。
- 旧版 v0.6.20 清单固定为 62 文件；本版增加两个 worker 文件，为八技能／64 文件。Claude 单入口包 66 成员，Codex 市场包 69 成员／67 插件文件，npm 包 67 成员。双端运行时 17 模块。

## 平台草稿的实际范围

本轮发行测试使用隔离合成夹具，不执行新的真实作者后台写入或模型会话。番茄既有实页证据的范围沿用[历史记录](v0.6.20.md#平台草稿的实际范围)。七猫、起点沿用外部已连接助手流程，实页、多卷与真实分页仍待验收；不执行提交审核或定时发布。
