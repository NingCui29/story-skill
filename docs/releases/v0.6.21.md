**v0.6.21 已于 2026-10-22 09:46:06 UTC 正式发布，共十四个附件。** 运行时／插件为 **0.6.21**，桌面客户端为 Mac **0.1.24 / build 25**、Windows **0.1.11**。固定源码与全部实际构建源统一为 ebabd8b，包含 Windows 会话锁、编辑器拒绝 POST 响应及失败诊断发布顺序修复。全部发行包、Codex 隔离安装、两端原生、三组完整源码 CI、真实固定标签安装、公开附件请求、GitHub Packages 发布及注册表下载物的独立核验均已完成。Windows／Python 3.10 初轮超时与一次同源重跑分别保留，另外两组沿用实际成功的原执行日志，不追认失败或继承旧候选结论。

**锁修复与失败历史：** 第三轮 f4d7cf0 的 Windows／Python 3.12 在真实跨进程 transport 回归中，五个合成 `verify_target` 请求完成四个后，发送进程进入生产会话锁时抛出 `OSError: [Errno 36] Resource deadlock avoided`。be14c3a 将 Windows 锁获取改为身份复核下的有界非阻塞重试，仅重试获取竞争；不重放锁内操作，也不放宽未知写入保护，并新增八项回归。原 91e49d8 包体、原生回执及前三轮失败证据保留为[锁修复前历史](../../benchmarks/results/v0.6.21/before-windows-lock-fix/)，不作为修复后最终产物的通过依据。 随后的 1e38ff0 完整回归又发现编辑器权限拒绝 POST 未读请求体，Windows 客户端可能在收到 403 前断连；c165520 复用书架已有的有界拒绝处理，仅消费长度明确的小请求体，不解析或执行未授权内容。be14c3a 构建及 1e38ff0 结果保留在[编辑器 HTTP 修复前历史](../../benchmarks/results/v0.6.21/before-editor-http-fix/)。 c165520 的完整回归随后发现明确 SDK 失败诊断发布前已暴露错误标志，后台可能先固化笼统失败阶段；ebabd8b 调整为诊断在先、错误与终态在后，并保留诊断存储失败时的停止保护。c165520 构建与失败结果保留在[诊断修复前历史](../../benchmarks/results/v0.6.21/before-worker-diagnostics-fix/)。

## 变化

- 番茄草稿可从预览显式启动受控 Codex 工作进程，连接既有已登录 Chrome。使用账户默认模型设置与额度；已登录的外部 Codex CLI、官方 Chrome 插件（含 SDK）和已连接的 Chrome 会话需事先具备，客户端不捆绑这些外部组件。通道健康不等于账号、作品或正文已核对，权限拒绝即停止，不绕过授权或切换路径重试未知写入。
- 正文编码与比较策略独立：默认 `verbatim`／`strict`，番茄可明确选择自然段排版 v2（去掉开头单个空段），旧 v1 保留原语义。末尾换行数量增加或减少须另选策略；标题、段内文字、空格及其他换行不放宽。冻结原稿、实际编码输入和实际回读各留摘要，等价接受与源稿逐字一致分别报告。
- 偏好按书籍、清单和配置保存在本书内，恢复选择仍需新预览和明确执行，不恢复授权令牌。界面状态重读只轮询原任务，不重复保存；未知结果先只读对账。
- 删除测试草稿的退休仅在明确授权、备份、目录缺失证明和相关工作进程已停止等证据齐全时追加记录；不删改原发送历史、不冒称平台保存成功，记录退休本身不自动发送正文。
- 修复 Windows 跨进程桥接的会话锁竞争，以及编辑器拒绝 POST 时未读请求体造成的响应断连；锁获取仍有时限和身份复核，未授权内容不解析、不执行，不通过重试重放写入。首次失败先发布明确诊断，再发布错误／结束标志，清理 checkpoint 不抹掉 `sdk_setup` 失败阶段；诊断落盘失败仍停止，不重试工具。
- WorkBuddy AI 默认目录修正为 `.workbuddy-ai/skills/`；补充 WorkBuddy AI 与 Qoder CN 的安装、发现及调用说明。Qoder CN 个人目录为 `.qoder-cn/skills/`，项目与国际版共享 `.qoder/skills/`。历史开发调用范围见[脱敏摘要](../../benchmarks/results/v0.6.21/host-compatibility-summary.json)，不是本版完整业务验收。
- 旧版 v0.6.20 清单固定为 62 文件；本版增加两个 worker 文件，为八技能／64 文件。Claude 单入口包 66 成员，Codex 市场包 69 成员／67 插件文件，npm 包 67 成员（64 载荷＋3 包装文件）。双端运行时共 17 个 Python／MJS 文件。

## 平台草稿的实际范围

本轮发行验收使用隔离合成夹具，没有新发起模型会话、连接真实 Chrome 或写入真实作者后台。番茄 2026-10-19 的指定合成稿完成过保存、独立只读全文回读及同清单重复执行不重建；该历史证据仅覆盖单卷完整列表。2026-10-21 另有单篇历史草稿经单独排版修复和只读全文核对，不能视为本版受控自动连接已完成真实整批保存验收。

默认严格比较下的旧末尾 LF 差异与未知尝试继续保留；新规则须另行明确选择，在新一次实际观察中记录，不追认旧失败为源稿逐字一致。七猫、起点保留外部已连接助手方式，尚无已实页验收的生产配置；真实分页和多卷也仍待验收。不提交审核、定时发布、覆盖已发布章节或处理附言配图。[平台流程与规则](../../skills/story-skill-publish/references/platform-drafts.md) · [历史范围](v0.6.20.md#平台草稿的实际范围) · [分层证据说明](../platform-publishing.md)
