# Windows 写作工作台 0.2.4

Windows 0.2.4 使用 C#／WPF／.NET 10／WebView2，内嵌 Story Skill 0.6.25。此源码快照正在完成发行验证，正式附件以独立 Release 页面为准。

本版支持在添加作品和新建作品表单中打开系统目录选择器，并整合工作台保存恢复、书架状态与草稿同步改进，详见 [v0.6.25 说明](v0.6.25.md)。选择目录后仍需确认添加或创建，同名已有目录不会被覆盖。

独立发行提供 x64 安装程序、便携 ZIP 与对应 SHA256。升级前保存全部编辑并退出客户端，安装后重新打开；新安装包不会自动替换仍在运行的旧作品服务。书稿和书架数据沿用原有位置。

Windows 原生构建须验证 0.2.3 → 0.2.4 升级、旧安装备份、回滚、卸载、完整载荷及禁用技术扫描。结果将按实际执行记录补充；本机 Mac 检查不代替 Windows 原生验收。
