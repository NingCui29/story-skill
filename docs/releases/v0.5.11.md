# v0.5.11：离线章节发布准备

**v0.5.11 已于 2026-09-24 15:33:07（北京时间）发布。** 固定标签、Windows／Linux CI、Release 附件公开回下载、官方固定标签隔离安装及 GitHub Packages 工作流均已核验；包回下载的证据边界见下表。[安装指引](../../INSTALL.md) · [逐项发布记录](../github-release.md)

## 主要变化

- 新增第八个同级技能 `story-codex-publish` 和核心共享模块 `story_publish.py`。对已审查的正式章节，可建立本地冻结清单、分页查看章目、回读单章、重新核对正式稿、生成离线材料 ZIP 与包外校验回执，并在交接前复核包和当前稿。[功能与命令边界](../platform-publishing.md)
- 作者自行从作家后台复制的草稿标题、正文及实际可见的“作者的话”，可以与冻结清单逐字段比较；明确要求留痕时，保存本地比较摘要供之后查询。比较结果的来源始终是作者提供的副本，不能证明平台确实保存或发布了对应内容。
- 每本书的发布准备记录独立保存在 `.story/publishing.sqlite3`，使用 schema 1；创作状态库继续使用 schema 2。离线准备不递增创作 revision，也不把发布动作写进剧情事件。已有书库无需重新导入；升级技能不会自动搬迁小说文件。
- 短篇全文合并稿从第 1 章章名开始，只保留各章章名与正文；书名仍在文件名及书籍信息中。旧合并文件在明确重新合并或正式导出刷新时按当前格式更新，外部改动仍按导出冲突处理。

本版发布准备只处理本地材料及作者提供副本的本地核对，**不登录七猫或番茄作家后台，不上传、提交、审核或定时发布章节**。目标账号与作品 ID 是用户声明；离线包、账本和副本比较均不是平台回执。实际投稿还须作者在目标平台核对作品、栏目、权限与内容。完整套件为 8 个技能、38 个载荷文件，运行时要求 Python 3.10 或更新版本。
