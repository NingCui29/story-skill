# Story Skill v0.6.12 发布记录

本版包含八个技能、49 个源载荷文件，书库继续使用 schema 2。发布核验正在进行；本机检查、跨平台 CI、固定标签、Release 附件与 GitHub Packages 分别登记，尚未取得的回执不算通过。

- 新增 Claude 桌面单技能导入包：一个总入口按需读取内嵌八流程，保留完整共享运行时与相对引用。桌面包共51个文件，包含顶层入口和许可证。
- 目录安装器支持 Codex、Claude Code、Antigravity 2.0／IDE 和 Antigravity CLI，区分项目与个人目录，保留更新备份、完整性检查和失败回滚。拒绝把安装目标放入技能源码内部，避免残留锁文件污染打包。
- 每个完整新章、整章候选和整章内容修订默认交付独立作者有话说及一张适合本章的配图；遵循用户明确的省略要求，允许复用适合的已有图片。没有图像工具时明确交付缺口，不把提示词冒充成图。附言与图片不混入正文计数、正式剧情状态或现有投稿ZIP。
- 工作台可显示作者有话说与相对路径图片。修复连续另存超过32次和中断保存恢复后找不到配图的问题，以及括号文件名、可选图片标题的解析错误；保留代码、粗体、普通链接和路径安全边界。
- Intel macOS 实验客户端更新至0.1.1，内含 Story Skill 0.6.12，继续采用临时本地签名。升级前保存需要保留的编辑，已运行进程不会自动加载新文件。
