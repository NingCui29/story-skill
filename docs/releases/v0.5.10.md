# v0.5.10：短篇完整交付与 Windows 导出修复

本版处于发布准备阶段。Windows 导出修复待本版固定源码的原生 CI 验收；固定标签、Release 附件、隔离安装和 GitHub Packages 回下载也须分别核验，当前不宣称发布完成。实际安装目标仍按 [INSTALL.md](../../INSTALL.md) 执行。

## 主要变化

- 短篇完本后，`assemble-short` 将所有连续已提交章节合并到书根的全文文件，保留分卷逐章稿；正式修订、对账、历史修订发布和续章导出会刷新已登记全文。书名含特殊字符或过长时生成合法文件名，完整书名仍保留在正文首行；实际路径以回执为准。路径冲突和外部改动仍须处理，不能用合并覆盖不明文件。[短篇交付流程](../../skills/story-codex-write/references/chapter.md#短篇完本与修订交付)
- 通过 `adopt` 接入的旧短篇可用 `adopt-backfill` 补存缺失原章，再合并完整成品；先核对真实原稿，不覆盖已有章、不回退续写进度，也不补造旧章审查。[旧短篇补章](../../skills/story-codex/references/project-state.md#旧短篇补齐原章)
- 明确要求完整短篇成品时，交付全文、实际封面和现行总纲或等效规划；审稿修订后首次交付也适用。所有长短篇正式总纲记录目标平台及原生分类，完本时核对终稿依据、来源日期和确认状态；普通单章任务不自动扩为首次完本交付。[分类字段](../../skills/story-codex/references/project-state.md#大纲中的作品类型与平台分类)
- 长短篇统一核对全书主线、人物选择、主要阅读承诺和结局；场景指导区分信息揭露与人物行动造成的局势逆转，允许有既定叙述规则和可回看依据的延迟揭露。中文校对补充语法、指代、搭配和标点判断，保留有依据的人物口语与叙述表达。[全书审查](../../skills/story-codex-write/references/chapter.md#全书完本审查) · [中文场景指导](../../skills/story-codex-write/references/drama.md)
- ZIP 验证拒绝目录、链接及特殊文件成员；npm 包从本版起使用 Windows、macOS、Linux 的平台说明，保留 v0.5.1—v0.5.9 历史包装文件字节和原平台范围。

套件仍为 7 个技能、34 个载荷文件，schema 2 不变。升级不会自动搬迁既有正文或更新本机安装；已有书与技能均应保留完整备份。

## 验证与限制

Windows 原生 CI、Linux CI、本版最终源码的工程检查、容量与迁移、旧版隔离升级、ZIP 与 npm 构建，以及发布后的回下载与固定标签安装均以本版实际回执为准；目前待完成发布验收。历史成功记录不能代替本版验证，也不据本机 macOS 检查宣称 Windows 已通过。

全书审查和中文表达规则属于指导修订，尚无本轮新文学实测。静态 token 计数、固定稿件重放和合成容量检查不代表实际账户用量、文学质量提升或真实长篇持续创作验收。
