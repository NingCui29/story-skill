# v0.5.10：短篇完整交付与 Windows 导出修复

> **历史名称遮盖：** 本页记录 v0.5.10 发布时的结果，但当时的固定标签、附件和包身份并未更名。下文名称替换后的路径仅供阅读，不能当作该版本可执行的安装地址；记录中的来源路径与哈希可能无法用遮盖后的文件复验。实际旧版资源请到[该版本 Release 页面](https://github.com/NingCui29/story-skill/releases/tag/v0.5.10)核对。

v0.5.10 已发布，Windows、Linux CI 和本机 macOS 工程检查通过。固定标签、Release 附件、官方隔离安装和 GitHub Packages 回下载均已核验；三平台统一按 [INSTALL.md](../../INSTALL.md) 升级。[完整验证记录](../../benchmarks/results/v0.5.10/README.md)。

## 主要变化

- 修复 Windows 正文与报告导出的 `WinError 32`：目录固定期间允许正常重命名，以不可移除的临时守卫保留目录替换防护；首次导出、跨目录备份、恢复、中文及非 BMP 文件名、外部文件冲突保护均有原生回归。
- 短篇完本后，`assemble-short` 将所有连续已提交章节合并到书根的全文文件，保留分卷逐章稿；正式修订、对账、历史修订发布和续章导出会刷新已登记全文。书名含特殊字符或过长时生成合法文件名，完整书名仍保留在正文首行；实际路径以回执为准。路径冲突和外部改动仍须处理，不能用合并覆盖不明文件。[短篇交付流程](../../skills/story-skill-write/references/chapter.md#短篇完本与修订交付)
- 通过 `adopt` 接入的旧短篇可用 `adopt-backfill` 补存缺失原章，再合并完整成品；先核对真实原稿，不覆盖已有章、不回退续写进度，也不补造旧章审查。[旧短篇补章](../../skills/story-skill/references/project-state.md#旧短篇补齐原章)
- 明确要求完整短篇成品时，交付全文、实际封面和现行总纲或等效规划；审稿修订后首次交付也适用。所有长短篇正式总纲记录目标平台及原生分类，完本时核对终稿依据、来源日期和确认状态；普通单章任务不自动扩为首次完本交付。[分类字段](../../skills/story-skill/references/project-state.md#大纲中的作品类型与平台分类)
- 长短篇统一核对全书主线、人物选择、主要阅读承诺和结局；场景指导区分信息揭露与人物行动造成的局势逆转，允许有既定叙述规则和可回看依据的延迟揭露。中文校对补充语法、指代、搭配和标点判断，保留有依据的人物口语与叙述表达。[全书审查](../../skills/story-skill-write/references/chapter.md#全书完本审查) · [中文场景指导](../../skills/story-skill-write/references/drama.md)
- ZIP 验证拒绝目录、链接及特殊文件成员；npm 包从本版起使用 Windows、macOS、Linux 的平台说明，保留 v0.5.1—v0.5.9 历史包装文件字节和原平台范围。

套件仍为 7 个技能、34 个载荷文件，schema 2 不变。升级不会自动搬迁既有正文或更新本机安装；已有书与技能均应保留完整备份。

## 验证与限制

本机 605 项测试中 589 通过、16 个 Windows 专用检查跳过；原生 Windows 与 Linux 的完整工作流均通过，9 项新增 Windows 目录保护测试全部通过。平台条件跳过项、失败后修正记录、容量迁移及分发验收详见本版验证目录。Windows 仅在本次 GitHub 托管环境验收，不推定其他文件系统或网络共享已实测。

全书审查和中文表达规则属于指导修订，尚无本轮新文学实测。静态 token 计数、固定稿件重放和合成容量检查不代表实际账户用量、文学质量提升或真实长篇持续创作验收。
