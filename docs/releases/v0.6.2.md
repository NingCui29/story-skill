# Story Skill v0.6.2

本版包含 8 个技能、39 个载荷文件。

- 工作台默认导出三栏正文阅读页；旧式概览使用 `--overview-only`。
- 新增 `workbench-serve` 本地候选编辑，保存为独立草稿，不替换正式正文；正式内容变化时拒绝使用旧快照保存。
- 阅读与编辑区域隐藏匹配的开头章名，保存时恢复原章名。
- 完善语义分段、移动阅读、开篇处境、对白重复、配角反应和修订停止条件。
- 防止压缩成摘要、以无效小动作替代人物行动，不把平台样本段长当硬标准。

本地回归 746 项：729 通过、17 条件跳过；CLI、中文稿件与历史修订回放、八技能格式校验及隔离安装通过。首次回归因测试硬编码旧版本失败，已改为读取实际版本并完整重跑通过。

发布验证正在进行；最终远端 CI、附件与 Packages 状态以 main 上补录的回执为准。旧版本标签和附件保持不变。

本地编辑只监听回环地址，服务退出后页面无法保存；候选采用仍须审稿提交。未进行真实 Windows 桌面浏览器人工验收；文学吸引力不由工程测试证明。
