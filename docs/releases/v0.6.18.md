# Story Skill v0.6.18

本版正在发布验证中。最终固定标签为 `v0.6.18`，版本分支为 `version-0.6.18`。

## 变化

- 写前交接与偏好召回：已绑定的新章优先读取写前简报；完整保留本书偏好的适用范围、例外、来源和指纹，不改变正式稿、候选和审查状态。
- 关键情节点覆盖与新增事实分级：检查事件是否真正呈现，区分自然补充、需要依据和改变既定约束的新增事实。
- 精简执行路径：正文入口按任务条件读取，已有预算上限不提高。
- 短篇平台化设计：按平台与入口处理阅读期待、选择、后果和完整结局，平台未定仍能推进独立构思。
- 纳入小说改编剧本规划、小说／剧本拆分镜能力，保留来源对照和材料边界。

题材写法卡、文风统一裁决、兑现归属、事务提交、历史依赖、世界状态、采用细纲绑定和语义审查继续沿用。长篇附言配图为9:16、突出单一视觉重点，附言Markdown只保留文字；短篇默认无附言和配图。书库仍使用schema 2。
