# Story Skill v0.6.18

v0.6.18已正式发布。固定标签 `v0.6.18` 指向 `0df4880e884086cbfed04be0bf4902e8149062f3`；`main` 与 `version-0.6.18` 同步，分支可随后续文档与回执前进，固定标签不移动。

## 变化

- 写前交接与偏好召回：已绑定的新章优先读取写前简报；完整保留本书偏好的适用范围、例外、来源和指纹，不改变正式稿、候选和审查状态。
- 关键情节点覆盖与新增事实分级：检查事件是否真正呈现，区分自然补充、需要依据和改变既定约束的新增事实。
- 精简执行路径：正文入口按任务条件读取，已有预算上限不提高。
- 短篇平台化设计：按平台与入口处理阅读期待、选择、后果和完整结局，平台未定仍能推进独立构思。
- 纳入小说改编剧本规划、小说／剧本拆分镜能力，保留来源对照和材料边界。

题材写法卡、文风统一裁决、兑现归属、事务提交、历史依赖、世界状态、采用细纲绑定和语义审查继续沿用。长篇附言配图为9:16、突出单一视觉重点，附言Markdown只保留文字；短篇默认无附言和配图。书库仍使用schema 2。

## 分发与验证

本版包含标准55文件、Claude桌面57文件、Codex归档60成员（58插件文件）、npm58成员内容包及Mac工作台0.1.6/build 7（运行时0.6.18）。Release提供四个ZIP及各自校验文件，共八个附件。各项实际摘要、回归、CI、固定源码安装、附件与注册表回下载现均已核对，见下列回执。

[开发验证](../../benchmarks/results/development-20261018-execution-handoff/assessment.md)保留实际前向试用、失败与适用限制，不替代本轮发布检查。文件、CLI和事务验证不证明所有宿主GUI、实际生成图像、平台审核或稳定文学效果。Mac客户端采用本地临时签名，未经Apple公证；本轮仅验证Intel Mac。
