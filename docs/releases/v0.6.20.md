## 变化

- **分类的两种状态分开记录。** 本地建议、已选定或内容待定，与后台菜单、本书实际设置的核验分开。本地方案已经采用且依据充分时，不因尚未查看后台而反复降回“拟选”；菜单快照也不能证明本书已保存。沿用已有选择，不跨作品替换状态、自动采用候选或覆盖后台实际值。
- **分类结构检查兼容新旧记录。** `outline-audit` 继续接受旧逐值状态，也接受同一平台块内明确的“本地分类决策＋后台核验”；缺少状态轴不能从其他平台或普通备注借用。起点只有菜单快照却声称本书已确认／保存时，保留来源缺口。检查仍只证明结构，不核验真实后台或内容适配。
- **大量材料不再阻断正式进度。** 工作台独立返回正式章节、计划和下一章信息，材料目录每批最多检查 5000 个节点，显示累计加载量、未覆盖提示和“继续加载材料”。游标十分钟过期、最多八个会话，单会话上限十万节点；达到上限仍明确报告不完整，不删除或搬移历史文件。
- **单文件打开与候选来源。** 候选、恢复稿、待核对保存记录、明确关联材料及 Markdown 来源按相同准入规则定点读取，不为打开一个文件重复扫描全树。保留隐藏路径、链接、目录身份、元数据及书籍身份检查；保存仍产生候选，正式采用继续走审稿与修订流程。全文搜索仍有工作量限制，部分材料未扫描时不称全书搜索完整。
- **阅读与审稿范围。** 整书内容审稿默认顺序读完目标正文，逐章记录覆盖和断点；抽样、结构或完本核对按实际范围报告。区分人物知情、读者已知和作者资料；商业连载分别核对本章期待的实际兑现与下一场追更理由，不以事实无误、未知问题或自评代替阅读效果。
- **发行版本核对。** 安装、打包及 Windows 草稿上传按当前源码版本核对，避免后续版本继续使用上一版的固定版本值。标准套件、Claude 单入口 r2、Codex 本地市场、npm 内容包和双端客户端分别构建与验证。

八技能的职责保持不变，书库仍使用 schema 2。升级不会迁移真实书稿、采用候选或自动停止正在运行的书架／作品服务；安装桌面应用与安装助手技能分别进行。
