# Story Skill v0.6.3

本版包含8个技能、39个载荷文件。已发布；固定标签、Release附件、隔离安装及Packages回下载均已核验。

- 工作台按章节关联计划、正文、细纲与候选，显示当前进度、前章衔接及审查记录；仅有计划的书也能直接打开计划。
- 增加按章计划口径的实际字数及选中文字数、Markdown材料预览、差异高亮、全文搜索、阅读设置与明确登记的多书切换。
- 审稿入口生成绑定文件与校验值的可复制任务，交给助手执行，不自动调用模型或采用候选。
- 完善多文件未保存提醒、自动恢复、待核对保存记录、外部修改保护和服务状态检查。材料候选、恢复稿与正文分别识别；刷新保留目录折叠和滚动状态。
- 合并番茄、七猫商业连载规则与新写、续写、改稿任务模板；加强人物尝试、回应、后果与阅读期待，避免把小说写成记录流程或场景摘要。
- 更新工程说明、工作台用法和隔离试用记录；历史测量保留原范围。

创作库仍为schema 2，不迁移或覆盖已有小说。工作台只监听本机回环地址；候选保存不替换正式稿，采用仍须审稿流程。全文搜索有覆盖上限、多书目录须明确登记。离线发布准备不执行七猫或番茄上传。工程检查不能证明文学质量；尚未进行本轮真实Windows桌面浏览器人工验收。

本地整包核验：794项回归，777通过、17条件跳过；CLI、中文稿件与长篇历史修订回放、八技能格式、39文件隔离安装与ZIP一致性通过。四组400／4000章合成容量、三类旧库迁移及托管安装升级通过。容量探针并行运行，初次汇总时尚未生成报告，完成后已单独重新核对并确认源码未变化；两次记录均保留。
