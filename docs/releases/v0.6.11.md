# Story Skill v0.6.11 发布记录

本版包含八个技能、49 个载荷文件，书库继续使用 schema 2。发布准备日期为 2026-10-06（北京时间）；固定标签、远端 CI、Release 和 Packages 完成后在本页补录实际结果，不以本地构建替代远端验收。

- 独立书架使用固定本机入口，可登记、搜索、筛选和切换作品；支持本地连载／完本标记，核对作品身份后写入书架记录。本地状态不代表平台已发布或文学验收通过。
- 工作台增加作品分类与更新时间展示、紧凑编辑布局、旧服务登记恢复和更严格的文件／作品身份保护。保存候选仍与正式采用分开，更新不会主动停止已有编辑服务。
- 新增 macOS 桌面客户端 0.1.0：同一主窗口缓存书架和作品页面，单实例启动，保留各页编辑会话，并携带 Python 3.12 与工作台运行时。
- 强化可读细纲与结构化章计划同步、细纲位置审查、历史修订版本保护及中断恢复；不从示例或旧材料误采纳规划状态。
- 补齐选题与阅读反馈、简介、标题与封面看点、人物对白、用词和标点指导。完整章的作者附言独立保存为 Markdown，可选配图；附言及配图不混入正文、正式状态或现有离线投稿 ZIP。
- 新增技能执行验收工具和隔离合成案例，区分文件与命令检查、执行过程复核及文学质量判断。真实书目、私人路径和截图保留在本地，公开工程证据已脱敏。
