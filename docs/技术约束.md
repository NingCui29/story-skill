# 项目技术约束

项目的业务代码、桌面客户端、构建依赖及发行包禁止使用 Qt、PySide、PyQt、Shiboken、Qt WebEngine 及 PHP。不得引入对应解释器、运行库、框架或包装层。

Windows 桌面层使用 C#、WPF、.NET 10 和 Microsoft WebView2；Mac 使用 Swift / AppKit / WKWebView。Python 作品服务与既有 HTML、CSS、JavaScript 界面继续复用，书稿、候选、恢复稿与正式状态格式保持兼容。

## 浏览器执行模型

工作台自动连接固定请求 `gpt-6.1-terra`，禁止供应端模型回退，并在启动浏览器任务前核验会话返回的模型。模型身份缺失、不匹配、不可用或发生模型重定向时停止，不自动改用其他模型，也不修改用户的默认模型配置。旧的页面健康回执不能替代自有执行会话的模型核验。

模型回执、浏览器连接和平台内容核验分别记录。模型正确不代表 Chrome 已连接；执行会话正常结束也不代表执行了浏览器任务。错误诊断只保留受限的模型与错误枚举，不保存任意模型回复、账号凭据或网页正文。实际平台验收须由符合模型限制的执行会话完成。

桌面宿主的自动接回仍须先验证公开的授权交接契约。历史线程的 `model`、消息入队成功、上游客户端 attestation、浏览器心跳与助手填写的布尔标记都不能替代实时执行模型和浏览器授权证明。2026-10-29 的本机公开协议核验尚未确认该完整契约；当前不能据此开放手工健康回执到工作台自动执行的通路，也不能通过改变进程来源、复制私有通道凭据或放宽权限处理宿主拒绝。

明确的“当前助手协助”任务与上述自动接回分开：实际执行者须先依据运行环境确认自己为 `gpt-6.1-terra`，再通过官方浏览器工具操作；模型无法确认时不得执行。工作台只提供绑定作品、批次、配置、目标、内容版本与操作范围的任务，以及生产执行核心、目标锁和独立全文回读校验。该来源记录为 `execution_origin=assistant_session`，模型核验责任记录为 `executor_runtime_required`，不冒充工作台独立认证模型，也不将外部会话标成自动连接就绪。复制交接说明只代表准备任务，不代表连接、检查或保存已经开始。

助手任务先只读检查或对账；生成写入任务须明确确认，并绑定有效、未消费的同批检查结果。任务只能认领一次，准备、检查与保存分别记录；取消、过期、崩溃或未知结果不能自动重放。停止任务只请求本任务在安全边界结束，不停止外部助手、Chrome 或共享宿主。该流程沿用既有桥接和生产核心，不新增直接填表捷径、任意成功回执入口或私有浏览器通道。

开发源码对已核验 Terra 会话的启动期故障增加重试暂停：只有 `sdk_setup`／`browser_inventory` 阶段的 `native_pipe_closed`、完成请求数为零，且从未观察到连接就绪或队列执行，才暂停当前作品服务的新自动连接。暂停跨批次、范围和面板重开保持；不终止已有健康会话，也不把中途失联的保存结果改成未写入。该暂停仅存在于本次服务生命周期，重启不构成连接恢复证明；目前没有公开的解除暂停或桌面会话自动接回接口。

## 自动检查

- 源码：`python scripts/check_forbidden_technologies.py --source`。检查导入、依赖声明、构建命令及实现文件名。
- 安装目录：`python scripts/check_forbidden_technologies.py --root <安装目录>`。递归检查完整发行载荷；禁止的组件或无法检查的链接会阻止验收。
- Windows 构建与分发验证都会执行载荷检查，源码 CI 执行源码检查。

历史发布记录中的旧技术描述、测试中的拒绝样例、资料引用中的 `.php` 外部网址不代表项目使用对应技术。历史证据不作为本版构建输入。检查不能代替人工审查；间接依赖仍须在还原、发布和安装后核对完整文件清单。

## Windows 迁移验收

0.2.0 将桌面窗口、更新检查、下载及关闭保护移到 C#。旧 Python 桌面实现及其框架模拟测试移除，回归直接执行新的 C# 安全与更新代码（`tests/windows`），原生 WebView2 窗口在 Windows runner 验证。Python 作品服务测试继续运行。

安装包内置 .NET 和 Python；WebView2 使用微软签名的 Evergreen x64 离线安装程序，已有可用运行时时复用，缺失时由安装向导安装。完整清单、SHA256、禁用组件检查、中文及空格路径安装、窗口渲染、浅深主题、编辑状态保护和卸载分别记录结果。未取得 Windows 执行证据前不将本机交叉编译当成运行验收。

Windows 0.3.0 开发源码另生成精简更新包，只移除上述 WebView2 离线安装程序，保留 .NET、Python、全部许可与完整宿主。该包要求已有可用的 WebView2；缺失时在停止作品服务前拒绝继续，并提示使用完整离线包。分块下载仅还原官方完整安装包，继续执行大小、摘要、文件身份和来源核对。完整与精简发布／安装目录均须通过载荷禁用技术扫描。具体范围见[快速更新](工作台快速更新.md)。
