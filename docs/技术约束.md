# 项目技术约束

项目的业务代码、桌面客户端、构建依赖及发行包禁止使用 Qt、PySide、PyQt、Shiboken、Qt WebEngine 及 PHP。不得引入对应解释器、运行库、框架或包装层。

Windows 桌面层使用 C#、WPF、.NET 10 和 Microsoft WebView2；Mac 使用 Swift / AppKit / WKWebView。Python 作品服务与既有 HTML、CSS、JavaScript 界面继续复用，书稿、候选、恢复稿与正式状态格式保持兼容。

## 自动检查

- 源码：`python scripts/check_forbidden_technologies.py --source`。检查导入、依赖声明、构建命令及实现文件名。
- 安装目录：`python scripts/check_forbidden_technologies.py --root <安装目录>`。递归检查完整发行载荷；禁止的组件或无法检查的链接会阻止验收。
- Windows 构建与分发验证都会执行载荷检查，源码 CI 执行源码检查。

历史发布记录中的旧技术描述、测试中的拒绝样例、资料引用中的 `.php` 外部网址不代表项目使用对应技术。历史证据不作为本版构建输入。检查不能代替人工审查；间接依赖仍须在还原、发布和安装后核对完整文件清单。

## Windows 迁移验收

0.2.0 将桌面窗口、更新检查、下载及关闭保护移到 C#。旧 Python 桌面实现及其框架模拟测试移除，回归直接执行新的 C# 安全与更新代码（`tests/windows`），原生 WebView2 窗口在 Windows runner 验证。Python 作品服务测试继续运行。

安装包内置 .NET 和 Python；WebView2 使用微软签名的 Evergreen x64 离线安装程序，已有可用运行时时复用，缺失时由安装向导安装。完整清单、SHA256、禁用组件检查、中文及空格路径安装、窗口渲染、浅深主题、编辑状态保护和卸载分别记录结果。未取得 Windows 执行证据前不将本机交叉编译当成运行验收。
