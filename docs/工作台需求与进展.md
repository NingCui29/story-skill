# 工作台需求与实现进展

本表承接“稿件安全、创作流程、Mac／Windows 日常使用”三个方向。当前发布运行时为 **0.6.19**，客户端为 Mac **0.1.18 / build 19**、Windows **0.1.9**；下载及实际验证范围见 [v0.6.19 发布记录](releases/v0.6.19.md)。更新源码或应用不会自动替换已启动的编辑服务。

## 已实现的操作

| 场景 | 入口及行为 | 核对与恢复 |
|---|---|---|
| 新建作品 | 书架“新建作品”，明确填写新目录、书名和长篇／短篇／分析类型 | 仅创建不存在的目录；创建成功但登记失败时保留作品并返回目录 |
| 移出书架 | 作品卡“管理作品 → 移出书架” | 文件和原编辑服务保留；可撤销，或重新添加原目录 |
| 删除作品 | “管理作品 → 删除至回收站”，显示书名、完整目录和范围，输入完整书名并核对保存状态 | 核对作品身份、目录身份、嵌套作品、链接、编辑服务和写入锁；只调用系统废纸篓／回收站，不回退永久删除 |
| 重新定位 | 作品搬迁后用“重新定位”填写新目录 | 必须是同一作品身份；不按书名合并，也不搬文件 |
| 整书备份 | “管理作品 → 备份”，填写作品外的新 ZIP 路径 | SQLite 在线快照、文件清单和 SHA-256 核验；文件／状态变化则中止；不包含未保存输入、外部关联材料或服务令牌 |
| 从备份恢复 | 书架“书架工具 → 从备份恢复”，填写备份 ZIP 路径及新的恢复目录 | 检查清单、路径、大小、重复项、哈希和数据库身份；禁止覆盖。恢复副本保留原身份，核对后决定使用哪份 |
| 恢复中心 | 书架“书架工具 → 恢复中心”或编辑页“设置 → 恢复中心” | 列出已写入的自动恢复与待核对保存记录，打开核对后保存新候选；不自动采用 |
| 保存全部候选 | 编辑页“设置 → 保存全部候选” | 顺序保存所有已打开文稿；出错立即停止，其余缓冲区保留；保存期间新增输入仍提示待保存 |
| 两稿比较 | 编辑页“更多 → 选择两稿对照” | 可选择正式稿、候选或材料；使用当前缓冲区中的未保存文字；保留原编辑与位置，不改变采用关系 |
| 继续下一章 | 编辑页“更多 → 继续下一章” | 复用只读 `writing-brief`，绑定正式断点、revision 和已采用细纲；缺计划、未绑定、漂移时阻止。生成任务后复制给助手执行 |
| 安全停止与更新 | 作品卡“管理作品 → 保存与停止” | 显示当前服务及代码状态；作者核对所有页面已保存／下载后，正常停止本书服务，再打开加载新代码 |
| 界面层级 | 天空蓝主色、紧凑搜索筛选、移除书架大标题、紧凑顶栏与编辑页工具条 | 卡片保留书名、题材、已核验进度与状态和打开入口；完整更新时间、分类依据、目录位置及本地作品状态设置收进“管理作品”。书架刷新在“书架工具”，编辑刷新在“设置”；完整进度在“作品信息”，无分页时收起翻页条，原节点与事件保留 |
| 交互反馈 | 筛选空态、菜单收起、返回书架刷新、备份／恢复执行状态 | 分析类型重置不适用状态；清除筛选；菜单互斥、外部点击与 Esc 收起；返回刷新保留条件并避开未保存输入；备份恢复显示计时与不确定进度，结果未知时先核对不自动重试 |
| 外观 | 书架右上方“外观”；编辑页顶栏“外观” | 浅色、深色、跟随系统；记住选择，保留未保存文字 |
| 更新检测与下载进度 | Mac 应用菜单／Windows 工具栏“检查更新” | 匹配本平台正式客户端附件；下载百分比、大小、速度、预计剩余、取消、重试及 SHA256 校验；缺少完整性证据不交给安装程序 |
| 安装交接 | 校验通过后打开 Mac 安装包／Windows 安装程序；便携包打开目录 | 明确提示手工安装和重启，不虚报升级完成；不自动停止书架或作品服务，详见[更新流程](工作台更新流程.md) |
| 大材料目录 | 正式目录与进度独立返回，材料区提供“继续加载材料” | 每批最多检查5000个节点，明确标出尚未加载的材料；游标过期或目录变化时提示刷新。候选、恢复稿和指定材料可直接安全读取，不再为单个文件扫描全树；不删除、搬移或按备份名称隐藏文件 |
| Windows 关闭保护 | 标签关闭、窗口退出、重新载入及页面跳转 | 异步核对所有标签及隐藏文稿；保存中或状态不明阻止关闭；未保存文字需返回保存或导出完整 ZIP；重复打开复用原标签 |
| 重新打开作品 | 书架“书架工具 → 重新打开上次作品” | 只保存书架 key，打开时重验身份；不持久化带令牌的编辑地址。记录依赖当前浏览器存储，清空或隐私会话退出后可能失效 |

删除前须先保存所有页面、停止本书编辑服务。服务不可达不视为已退出，不按 PID 强杀。系统回收站成功、书架登记更新失败时，页面报告两者的实际状态；可移出失效登记。恢复时使用系统废纸篓／回收站的“放回／还原”，再添加作品目录；工作台不清空回收站。

备份是已保存文件的快照。恢复发布中断会保留 `.story-restore-incomplete.json` 和已恢复文件，这种目录不会作为完整作品打开；保留它供核对，并重新恢复到另一个新目录。备份不覆盖外部关联材料，应单独备份原目录。

停止服务的勾选是作者对所有页面的明确确认，不等于浏览器跨进程自动汇总。Mac 保留原有全部缓存页面的关闭核对；Windows 新增同等范围的异步检查。浏览器崩溃前尚未写入恢复文件的输入无法保证找回。

## 继续推进的验收项

以下是需求清单，不表示已经实现。

| 优先级 | 需求 | 完成判据 |
|---|---|---|
| P0 | 跨窗口与浏览器统一未保存状态 | 停止／升级前自动汇总全部页面；断线、后台挂起、未知旧页明确阻止，无隐式丢稿 |
| P0 | 原生目录选择与路径迁移体验 | 两端新建、备份、恢复、定位均可用系统面板；替换目录及身份变化有可恢复提示 |
| P1 | 规划采用与细纲绑定面板 | 显示候选、采用、绑定、漂移；有来源和版本证据，不依据文件名推定采用 |
| P1 | 助手任务与结果回流 | 区分已生成、已交给助手、执行中、失败、待核对及已应用；有真实执行回执，缺证据保持未核验 |
| P1 | 审稿问题逐项处理 | 审稿结果绑定稿件哈希，可定位引文、确认处理、复查；过期结果不得直接采用 |
| P1 | 正式采用与历史修订 | 复用 prepare／commit、history 及依赖哈希；显示影响章节；候选不能越过审查直接写正式稿 |
| P1 | 多候选版本管理 | 版本来源、生成时间、标签、采用状态和任意比较；归档与清理均可恢复 |
| P1 | 人物、设定和伏笔证据视图 | 能定位正式证据及生效章节，区分规划与正文已成立事实 |
| P1 | 离线交付流程 | 页面串联正式章节选择、检查、导出和 ZIP 回读，平台发布状态独立标示 |
| P1 | 自动保存平台草稿（番茄、七猫、起点） | 只存草稿；工作台已接本地预览、异步整批保存、本次完整回读进度和只读对账，保留编辑缓冲。番茄 `host_assisted_cua` 已使用既有已登录 Chrome 完成第 13 章独立 81 字符功能稿首次完整链路：冻结清单→预览→生产新建→独立只读预览全文一致，保留首行换行及内部空段；同清单再次执行确认已有一致草稿 1/1、未重建；草稿仍三篇，非草稿十条含三条排期与基线一致。原 83 字符稿额外尾 LF 丢失，保留冲突和旧未知历史，不裁剪或重建；编辑页仅打开／重载曾出现正文增长，原因未确定，不能用作本轮只读回读。缺少助手工作进程或番茄只读预览配置时阻断，不是无人值守发布。实页仅单卷完整表格，真实分页、多卷、七猫及起点暂未验收；Mac／Windows 客户端及本轮发行验收见 [v0.6.19 发布记录](releases/v0.6.19.md)。见[草稿保存范围](../skills/story-skill-publish/references/platform-drafts.md) |
| P1 | 平台目标自助配置（番茄） | 源码已开发并通过真实浏览器本地表单验收：填写番茄小说网 ID、粘贴官方章节管理网址并选正式章节范围，本机生成受控页面配置和不可变清单；走现有审查资格及修订核对，同输入幂等，原未知日志不改。配置成功不等于后台已核验或草稿已保存，实际执行仍需当前助手连接既有 Chrome。 |
| P1 | 稳定会话恢复 | 跨应用重启保存作品身份、文件、光标和布局；重新核对来源，不保存能力令牌或冒认未保存正文已找回 |
| P1 | 安装和升级交付后续 | Apple 公证、Windows 代码签名、安装结果回执与重启后确认、自动回退及更多用户系统验收；现有进度及校验不能代替这些验收 |
| P2 | 可复制的诊断包 | 脱敏后导出版本、服务和错误信息；书稿与路径由作者明确选择 |
| P2 | 大书库性能 | 大量章节／候选／恢复文件下分页、搜索、比较和取消操作有明确覆盖范围与响应目标 |
| P2 | 跨设备及可选模型配置 | 冲突副本、离线恢复、密钥安全和费用边界验证后再启用；不默认上传正文 |

回收站、备份及交互验收使用隔离合成作品，不替作者删除、迁移或恢复真实作品。

平台草稿完整链路同样使用独立的合成测试书与指定测试作品，测试收据不代表原小说已完成正式审稿。番茄原功能测试草稿已做多段、连续空行及首尾换行采样并恢复；这些 DOM 与输入观察不等于工作台生产执行器已完成保存和全文核对。本轮源码改动尚未作为新版本安装或发布。
