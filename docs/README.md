## 开始使用

需要安装或升级时，可在当前应用中发送以下请求；安装时继续核对 v0.6.2 固定标签、Release 附件和本地已有修改；检查不符则保留现有安装：

```text
$skill-installer 按 https://github.com/NingCui29/story-skill/blob/main/INSTALL.md 安装或升级 Story Skill
```

## 当前实现与证据

下表是功能与历史证据导航；v0.5.10 的工程验收、平台结果和分发文件以 [版本说明](releases/v0.5.10.md) 与 [当版验证目录](../benchmarks/results/v0.5.10/README.md) 为准。作品分析的程序核验与文学评阅分别报告，不用测试通过替代解释是否成立。

| 内容 | 已完成的范围与入口 |
|---|---|
| 开篇点评、完整深读与分析修订 | [深读入口与评估汇总](作品深读与评估.md)，可直接通过 `story-skill-analyze` 使用 |
| 合成短文与完整真实短篇 | [第一轮](../benchmarks/results/analysis-depth/README.md) 和 [第二轮](../benchmarks/results/analysis-real/README.md) 保留匿名模型评阅、分歧及原始材料 |
| 分析稿修订和迁移试用 | [语义修订](../benchmarks/results/analysis-revision/README.md) 与 [恢复试用](../benchmarks/results/analysis-followup/README.md) 保留旧定稿及独立新稿 |
| 完整九章的跨章分析 | [《阿Q正傳》试用](../benchmarks/results/analysis-crosschapter/README.md)：14 块、64 条逐块引文核对通过；独立模型评阅未提出必须修改项，两项可选措辞另存澄清稿 |
| 长篇状态与历史修订 | [超长篇实操](超长篇实操.md) 和 [按版本保存的验收](超长篇验收.md) |
| 阅读承诺、正文详略和跨章审稿的开发比较 | [三题实际结果](../benchmarks/results/quality-focus-2026-09-11/README.md)：规划持平、正文略偏初版候选、跨章审稿略偏旧版；最终措辞仅语义复核，不证明稳定提升 |
| 人物选择指导续修 | [2026-09-19 独立试用](../benchmarks/results/quality-followup-2026-09-19/README.md)：补充欲望与性情对选择的影响，保留新旧原始稿件与适用边界 |
| 连续章节写作试用 | [三章执行记录](../benchmarks/results/writing-sequence-2026-09-26/assessment.md)：保存规划、连续正文、独立评阅、实测计数与提交导出回执；程序正确性和文学表现分别报告 |
| 试写、局部设计与修订分流 | [独立试写](../benchmarks/results/standalone-writing-2026-09-19/README.md)与[审稿分流](../benchmarks/results/review-routing-2026-09-19/README.md)：区分独立片段、新章草稿和已提交章节，沿本次授权处理 |
| 正文纯文本与对白分段 | [成稿格式](../skills/story-skill-write/references/drama.md#成稿格式)：段间空一行，换人默认换段，紧密动作与短对白可同段；[章节流程](../skills/story-skill-write/references/chapter.md)保留 `.md` 文件名，旧章不自动转换 |
| 番茄与七猫商业连载 | [采用的商业写作规则及任务模板](../skills/story-skill-write/references/drama.md#番茄与七猫商业连载)：开中尾推进、爽点反馈、可追踪悬念、手机段落、续写和内容改稿；用户创作规范，不是平台官方审核规则 |
| 短篇完整交付与后续修订 | [完整短篇流程](中文小说上手.md#写完整短篇)：全文、实际封面和现行总纲分类；已有全文随正式导出同步，纯审稿不自动写入 |
| 章节离线发布准备 | [发布准备流程](中文小说上手.md#章节离线发布准备)：冻结已审查正式章、导出并复核本地材料包；作者副本比较仍不代表平台已保存 |
| 本地工作台 | [实现状态与命令](本地工作台分析.md)：三栏浏览正式章节与创作材料；本机服务可另存候选和自动恢复稿，静态导出只读；支持按章关联、字数核对、大纲预览、差异高亮、审稿任务、全文搜索和登记多书切换；服务可检查、复用与停止，不执行平台操作 |
| 全书审查与中文校对 | [本版指导修订](中文冲突与看点.md#v0510-指导修订)：区分完本审查、普通单章和局部校对，保留叙述规则及有依据的人物口语；尚无本轮新文学实测 |
| v0.5.10 静态指令计数 | [逐场景 token 报告](../benchmarks/results/v0.5.10/tokens.md)：只统计当版冷加载指令，不等于 v0.5.11 用量或文学质量 |
| 文学评阅和实际用量的比较方法 | [评估方法](evaluation.md) |

《阿Q正傳》试用是固定单版本、单作品、一次完整生成及独立模型评阅，没有旧版对照、重复采样或人类编辑。前两轮与后续修订也未证明“大师级”认证、稳定质量提升或实际账户成本下降。各轮冻结技能与输入哈希独立保存，旧输出不追认为最终版生成。

## 已发布历史快照

v0.5.5 于 2026-09-12 发布，补齐历史修订决定回读、关联后文复核和世界状态衔接；Release、Packages 与平台范围保留在 [v0.5.5 说明](releases/v0.5.5.md)和[原验证记录](../benchmarks/results/v0.5.5/README.md)。

v0.5.4 已于 2026-09-11 发布，补充阅读承诺、正文详略和跨章审稿。固定标签、Release 附件、官方隔离安装及 Packages 回下载已核验，Linux 通过，Windows 保留已知导出失败；实际范围见 [v0.5.4 说明](releases/v0.5.4.md)和[原验证记录](../benchmarks/results/v0.5.4/README.md)。

v0.5.3 于 2026-09-11 发布，补齐书名目录与从拆书到原创开书的指引。本机 443 项测试中 436 项通过、7 项跳过，12 项整包检查通过；远端 Linux 通过，Windows 保留已知导出失败。Release、官方固定标签安装与 Packages 已核验。[v0.5.3 版本说明](releases/v0.5.3.md) 与 [原验证记录](../benchmarks/results/v0.5.3/README.md) 保留当次范围。

v0.5.2 于 2026-09-11 发布，补齐大纲层级与规划同步，修复状态保护、世界判定、历史修订和分析恢复。本机 443 项测试中 436 项通过、7 项跳过，12 项整包检查通过；远端 Linux 通过，Windows 保留已知导出失败。[v0.5.2 版本说明](releases/v0.5.2.md) 与 [原验证记录](../benchmarks/results/v0.5.2/README.md) 保留当次结果。

v0.5.1 于 2026-09-10 发布，增加作品深读、分析示范与修订续跑；本地 397 项测试中 390 项通过、7 项跳过，12 项整包检查及四组合合成容量通过。远端 Linux 通过，Windows 保留已知导出失败。完整范围见 [v0.5.1 版本说明](releases/v0.5.1.md) 与 [原验证记录](../benchmarks/results/v0.5.1/README.md)。

v0.5.0 的 macOS／Python 3.12 本地回归为 379 项测试，其中 372 项通过、7 项平台专用测试跳过；12 项整包检查、四组合合成容量与 v0.4.0 → v0.5.0 的 18 项升级检查通过。Linux 远端检查通过，Windows 当时存在导出失败。[v0.5.0 版本说明](releases/v0.5.0.md) 保留当时的初始化、迁移与发布证据。其普通／多线写作冷加载指令为 **5,324／7,091 tokens**，只统计固定指令。

v0.4.0 已归档结果：干净检出 **311 项测试、12 项整包检查通过**；多线修订演练完成 **77 次 CLI 检查、28 项断言**；四章中文试写共 **9,297 字**；普通／多线写作冷加载指令为 **4,509／6,149 tokens**。[全仓审查与优化](全仓审查与优化.md) 与 [逐文件计数](../benchmarks/results/v0.4.0/tokens.md) 保留原始范围。

百万与千万字规模通过的是合成容量测试。以上旧版结果不作为新版自动通过的依据；文学质量、容量、静态指令与实际账户消耗分别评价。
