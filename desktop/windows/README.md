# 写作工作台 · Windows

本目录对应 Windows 客户端 **0.2.4** 使用 **C# / WPF / .NET 10 / Microsoft WebView2**，内嵌 Story Skill **0.6.25** Python 作品服务。项目禁止使用 Qt 系列及 PHP，构建和安装验收包含对应检查。界面沿用 HTML、CSS 与 JavaScript，作品数据无需转换。

## 获取和安装

本版本发行文件使用以下名称，以独立 Release 页面实际可见附件为准；下载后先核对同名校验文件。[EXE 安装包](https://github.com/NingCui29/story-skill/releases/download/windows-v0.2.4/story-workbench-0.2.4-windows-x86_64-setup.exe)及同名 [SHA256 校验文件](https://github.com/NingCui29/story-skill/releases/download/windows-v0.2.4/story-workbench-0.2.4-windows-x86_64-setup.exe.sha256)。固定发行页为 [windows-v0.2.4](https://github.com/NingCui29/story-skill/releases/tag/windows-v0.2.4)。

建议使用受支持的 Windows 11 x64。原生 CI 使用 Windows Server 2025 runner，各轮实际结果见发布记录；不能由该环境推定 Windows 10/11 所有用户设备均已验收。安装前保存工作台及外部浏览器中的编辑，退出旧客户端。双击安装程序，按向导为当前用户安装，从开始菜单启动“写作工作台”；系统应用列表支持卸载。应用未做代码签名。应用目录不用于存放书稿。

在下载目录的 PowerShell 中执行以下命令，与 `.sha256` 文件中的摘要比较：

```powershell
Get-FileHash .\story-workbench-0.2.4-windows-x86_64-setup.exe -Algorithm SHA256
```

从 0.2.0 或更早版本升级，请使用固定下载链接。0.2.1 起，应用内检查独立的 `windows-v*` 正式发行版，并复用重新校验通过的已下载包。

安装包自带 .NET 与 Python，无需另行安装这两者。WebView2 运行时已有时复用，缺失时使用随包微软签名的 Evergreen x64 离线安装程序安装；安装失败会明确中止。便携 ZIP 需完整解压并保留 `runtime`、`Scripts`、`Prerequisites` 及其余文件；如系统缺少 WebView2，先运行 `Prerequisites` 中的微软安装程序。

## 日常使用

- 书架搜索、筛选、新建、添加、移出、重新定位、回收站删除、整书备份与恢复仍使用原作品服务。
- 编辑页在应用标签中打开；重复打开复用原标签。返回书架不会重新载入未保存的编辑页。
- “外观”支持浅色、深色、跟随系统并保存偏好；主题色为天空蓝。
- 关闭标签、退出、刷新及启动更新前核对所有页面及隐藏文稿。保存中、恢复中、输入法组合中或状态未知时阻止操作；待保存文字可返回保存或导出完整 ZIP。
- “添加已有作品”和“新建作品 → 存放位置”中的“选择文件夹…”直接打开系统文件夹选择器并回填路径；选择目录后仍须确认添加或创建。新建作品在所选位置下创建独立文件夹，不覆盖已有目录。顶部“复制作品目录”仍可复制路径；导出与下载使用系统保存面板。
- “检查更新”查询官方正式 Windows x64 附件，显示下载进度、大小、速度、预计剩余时间，支持取消和重试；大小、SHA256 与文件身份通过后才允许启动安装程序。

本版恢复中心先选择作品，再分批读取恢复记录，每页最多100条，支持继续加载和重新读取。目录尚未扫描完时保留未完成提示，读取失败时已列记录仍可打开核对。整书恢复保留原作品身份，备份中的 Chrome 桥接会话仅作为证据保留；使用平台草稿前须重新连接。

平台草稿分别显示当前正式稿范围与已生成批次，章节变化时自动刷新本地范围。选择“同步更新已有草稿（章名和正文）”后，按所选范围的最新正式稿预览，再点击执行；修改前备份原稿，保留草稿 ID，保存后独立回读。已核实的错字标记按原文读取，完整重填正文后清理；默认保存和只读对账不覆盖已有内容，已发布章节不修改。同步记录显示最近持久化状态及时间，不将历史记录当成本次远端核验。页面变化或结果未知时停止并先对账。

内嵌研究命令保留静态来源解析、重复标签抽样与历史研究材料兼容检查；完整研究和试读设计通过所用助手中的 Story Skill 进行，不增加专用原生操作面板。

保存候选、自动恢复副本和导出文件不等于正式采用。平台草稿流程及外部助手依赖保持原边界，不执行提交审核或定时发布。

## 升级、卸载和异常恢复

安装或卸载前保存工作台及外部浏览器中的全部编辑，退出客户端。在向导中确认已保存后，安装器先认证相关后台服务、正常停止并等待文件释放；身份无法核对或仍有未知占用时停止操作。静默安装不会代替用户确认，须提前正常停止相关服务。

覆盖安装会将已核对的完整旧安装目录保留为同级 `<原目录>.previous-<唯一标识>`；安装失败时尝试恢复旧目录，未完成的新目录另行保留；若因占用、权限或身份核对失败无法自动恢复，会提示并保留备份。成功后备份继续保留，确认新版正常后可手工清理。书稿应始终存放在安装目录之外，卸载只处理当前应用。

异常退出后，客户端通过只读进程检查、原记录一致性和现存文件锁确认服务已退出，再重新启动。无法核对的状态会保留并提示，不按旧 PID 强制结束进程。首次打开失败的空标签可安全移除；已完成保存检查后加载失败的页面可重试。仍无法确认的编辑状态继续受到保护。

“上次打开作品”、阅读设置、布局和书架筛选跨启动保存；仅持久化经校验的作品标识和普通偏好，不保存正文、作品目录或含访问凭证的地址。网页与原生窗口共同响应浅色、深色及系统主题。

## 构建与验证

需要 Windows x64、完整 Python 3.12、.NET 10 SDK 和 Inno Setup 6。WebView2 SDK 版本固定在 `StoryWorkbench/StoryWorkbench.csproj`。

```powershell
python scripts/check_forbidden_technologies.py --source
dotnet run --project tests/windows/StoryWorkbench.Tests.csproj
python scripts/build_desktop_windows.py --output dist/story-workbench-windows-x86_64
```

GitHub Actions 工作流覆盖 C# 测试、作品服务安全探针、独立发布、安装器构建、中文及空格目录安装、原生窗口与外观验证、完整清单校验及卸载。安装包、校验文件、便携 ZIP 和验收回执作为 Actions 产物保存；常规构建不创建或公开 Release。Windows 正式分发独立使用 `windows-v0.2.4`，提供安装程序、便携 ZIP 与各自 `.sha256`，共四附件；Story Skill 技能包与 Mac 使用主版本发行，保留主版本的 latest 入口。

每次正式发布的实际构建来源、Windows 执行记录和验证边界见 [0.2.4 发布记录](../../docs/releases/windows-v0.2.4.md)。

随包第三方许可来自实际还原的 WebView2 SDK、.NET 与 Python 分发载荷，并记录来源与摘要。完整文件清单包含自带的运行库与先决条件安装器。验收截图中的合成更新进度不代表真实网络升级成功；Windows runner 验收与不同用户系统的人工验收分别记录。
