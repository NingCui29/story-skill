# 写作工作台 · macOS 桌面版

> 公开记录说明：历史开发记录的作品名称、目录及运行实例标识已一致匿名化，个人路径已通用化，相关真实作品截图仅本地保留。新版验收使用隔离合成书架；实际截图、执行来源和通过范围以对应发布记录为准。

`写作工作台.app` 将本地书架和作品编辑页面放进独立的 macOS 窗口。应用包内携带 Python 运行时与作品服务，无需另装 Python。完整创作与研究流程通过所用助手中的 Story Skill 进行。

版本更新遵循[统一版本管理规则](../../docs/版本管理.md)。Mac 客户端与内置 Story Skill 分别记录版本；正式重新分发有变化的应用时，同时提高客户端版本和 build，不能只升 build。

本版为 **0.1.37 / build 38**，内嵌 **Story Skill 0.6.25** 和20个运行时文件。随 v0.6.25 正式发布，ZIP、DMG及各自校验文件齐全。变化与验收范围见 [v0.6.25 发布记录](../../docs/releases/v0.6.25.md)。

下载 [DMG](https://github.com/NingCui29/story-skill/releases/download/v0.6.25/story-workbench-0.1.37-macos-x86_64.dmg)及[校验文件](https://github.com/NingCui29/story-skill/releases/download/v0.6.25/story-workbench-0.1.37-macos-x86_64.dmg.sha256)，或 [ZIP](https://github.com/NingCui29/story-skill/releases/download/v0.6.25/story-workbench-0.1.37-macos-x86_64.zip)及[校验文件](https://github.com/NingCui29/story-skill/releases/download/v0.6.25/story-workbench-0.1.37-macos-x86_64.zip.sha256)。核对摘要后，挂载 DMG 或解压 ZIP，将“写作工作台.app”复制到 Applications。升级前保存桌面窗口和外部浏览器中的全部编辑，退出旧客户端，安装后重新打开。

工作台支持浅色、深色及跟随系统。书架可新建、选择目录、移出／撤销、重新定位、删除至系统废纸篓、备份和恢复作品；编辑页提供保存状态、恢复中心、保存全部候选、两稿对照与继续编辑。候选和正式稿的身份分别保留。操作说明见[需求与进展](../../docs/工作台需求与进展.md)。

应用菜单中的“检查更新…”按本机架构比较 GitHub 最新正式客户端。下载窗口显示进度、大小、速度和预计剩余时间，支持取消与重试；通过大小和 SHA256 核对后打开安装包，提示保存、手动安装及重新打开。下载完成与安装完成分别处理，不自动替换运行中的应用或停止作品服务。详见[更新流程](../../docs/工作台更新流程.md)。

平台草稿通过“同步草稿（更新已有，补齐缺失）”，按预览范围更新已有草稿的章名和完整正文、补齐缺失草稿，并只读核对原已一致的章节。修改前备份远端原稿，保留已有草稿 ID，保存后独立全文回读；不修改已发布章节。新保存固定去掉正文全部空白行，保留非空行的文字、标点、缩进和空格，其余行之间保留一次换行。本地原稿不改，独立回读的标题与全文必须和转换后的输入逐字一致，额外空行或末尾换行也算差异。

番茄可显式启动受控 Codex 会话连接既有、已登录的 Chrome，使用账户额度，并依赖已登录的外部 Codex CLI、官方 Chrome 插件（含 SDK）及已连接的 Chrome 会话。权限拒绝即停止；已知读取超时最多恢复一次，创建和保存动作不重放，未知结果先只读对账。七猫、起点沿用外部已连接助手流程。平台功能的本轮软件验收使用合成材料，不代表真实多平台、多卷或整批作者作品已验收；不执行审核提交或定时发布。见[平台草稿范围](../../skills/story-skill-publish/references/platform-drafts.md)。

客户端使用临时本地签名，未做 Apple 公证。本轮验证目标为 Intel Mac；最低 macOS 13 是构建配置，Apple Silicon 及其他 macOS 用户环境仍需分别验证。安装包与已运行服务分别更新，替换应用不会让旧服务自动加载新代码。

## 从源码构建

构建需要可运行的 Python 3.12，以及提供 `swiftc` 和 macOS SDK 的 Apple 命令行开发工具。`--python` 指向要随应用携带的本机 Python；`--output` 指向生成的完整 `.app` 路径。请在仓库根目录运行：

```sh
"$HOME/.local/bin/python3.12" scripts/build_desktop_macos.py \
  --python "$HOME/.local/bin/python3.12" \
  --output "dist/release-v0.6.25-candidate/写作工作台.app"
```

不要将输出路径设为现有作品目录。构建输出与源代码、真实作品数据分开保存；本地构建不包含远程发布、应用商店上架或发行验收。

应用包的主要布局：

```text
写作工作台.app/
└── Contents/
    ├── Info.plist
    ├── MacOS/                  # 原生窗口程序
    └── Resources/
        ├── runtime/            # Python 运行时与标准库
        ├── Scripts/            # story.py 与配套工作台模块
        ├── editor-appearance.js # 已核对旧编辑页的展示兼容
        ├── editor-safety.js     # 已核对旧编辑页的保存与关闭保护
        └── backend_runner.py   # 核对、复用或启动本地书架
```

首次构建后的验收应覆盖实际启动、同一书架的复用、独立作品窗口、候选保存、当前文字下载、未保存编辑的关闭与退出提示，以及更新时保留原编辑。这里列出的是验收要求，不是未经执行的通过声明。

## 实现依据

Python 会根据解释器位置与标准库目录确定模块路径，也支持通过 `PYTHONHOME` 指定运行时位置。使用 `PYTHONHOME` 时须注意 `-I`、`-E` 会忽略这些环境变量。见 [Python 模块搜索路径初始化](https://docs.python.org/3.12/library/sys_path_init.html)与 [Python 命令行和环境变量](https://docs.python.org/3.12/using/cmdline.html)。

作品的新窗口使用 [Apple WKUIDelegate 新建 WebView 接口](https://developer.apple.com/documentation/webkit/wkuidelegate/webview(_:createwebviewwith:for:windowfeatures:))。下载由 [WKDownloadDelegate](https://developer.apple.com/documentation/webkit/wkdownloaddelegate/download(_:decidedestinationusing:suggestedfilename:completionhandler:))提供保存目标；WebKit 要求下载目标文件尚不存在，覆盖旧文件必须另行处理。窗口关闭和应用退出还需要客户端核对未保存编辑，不能只依赖网页关闭事件。

本地书架使用回环地址 HTTP。相关网络配置依据 [Apple NSAllowsLocalNetworking](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowslocalnetworking)与 [NSExceptionDomains](https://developer.apple.com/documentation/BundleResources/Information-Property-List/NSAppTransportSecurity/NSExceptionDomains)，应将工作台的本地连接与外部网页分别处理。
